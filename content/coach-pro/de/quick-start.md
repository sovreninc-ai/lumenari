# Quick Start — Coach / Trainer / Therapist Pack

Sie sind in unter einer Minute startklar.

## ChatGPT, Claude (Web) oder Gemini

1. Öffnen Sie das Tool
2. Fügen Sie den Inhalt von `optimization-pack.md` in das System-Prompt- / Custom-Instructions- / Project-Knowledge-Feld ein
3. Sagen Sie ihm Ihren Praktiker-Typ und bitten Sie es, zu draften, was Sie brauchen (Session-Note, Client-E-Mail, Marketing-Copy)

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Öffnen Sie das Terminal (oder Ihren Code-Editor)
2. Legen Sie den Kit-Ordner in `~/.claude/skills/coach-pro/` (Claude Code) ab oder fügen Sie `SKILL.md` in Ihrem Projekt-Root ein (Cursor / Codex)
3. Tippen Sie, was Sie wollen — Claude greift den Skill automatisch auf

## Testen, ob es funktioniert

Fügen Sie ein: "Ich bin ein Life Coach. Schreibe eine SOAP-style Session-Note aus diesem groben Material: 45-Min-Video-Session mit Client J.K., Session 4. Sie sprach über Boundary-Struggles mit ihrer Schwester und committet zu einem direkten Gespräch diese Woche."

Wenn Sie eine Note zurückbekommen, gelabelt als **Observations** (nicht Assessment), unter 400 Wörter, mit einem Disclaimer am Ende und keiner klinischen Diagnose-Sprache — ist das Kit korrekt geladen.

Wenn Sie eine SOAP-Note mit einer "Assessment"-Sektion bekommen, die eine klinische Condition benennt, ist das Kit nicht geladen — fügen Sie `optimization-pack.md` erneut ein.
