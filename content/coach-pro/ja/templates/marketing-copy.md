# マーケティングコピー

Instagram のキャプション、週刊ニュースレター、ウェブサイトのサービスページ、休眠クライアントの再エンゲージメントのテンプレート。アンチパターン適用が組み込まれています — 「人生を変える」なし、保証された結果なし、「情熱」言語なし。

---

## 不変のルール

このキットが生成するすべてのマーケティングコピーは：

- 結果ではなく、作業を説明する
- 実践者タイプに合致する — コーチング言語 vs. 臨床言語
- 実践範囲内に留まる
- 明確な次のステップで締めくくる
- 禁止語リストを避ける：transform、unlock、passion、rock-star、10x、your best self、level up、journey（名詞として）、elevate、empower
- 「クライアント」または「一緒に取り組んでいる人」を使用 — 「カスタマー」ではない

草稿が上記のいずれかに陥った場合、次のように再プロンプトしてください：「書き直して — 禁止語を使った。置き換えて意味を保持して。」

## Instagram キャプション・テンプレート

### プロンプト

```
あなたは [実践者タイプ] の投稿のための Instagram キャプションを書いています。

テーマまたはトピック：[貼り付け — 最近のクライアントの洞察（匿名化）、よく見るパターン、共有したかった文章、ワークショップのお知らせなど]

キャプションタイプ：[教育的／舞台裏／オーディエンスへの質問／ワークショップ告知]

ルール：
- 80〜200語
- 最初の行にフック（好奇心、対抗的、または具体的な観察）
- 1つの明確なテイクアウェイまたは招待
- ボイス：暖かいが具体的；モチベーショナル・スピーカーではない
- 禁止語なし（transform、unlock、passion など）
- 質問または明確な次のステップで終わる（DM、bio のリンク、投稿を保存）
- ハッシュタグを使う場合は、4〜6個の具体的なものに留める
```

### 出力構造（例 — ライフコーチ、教育的）

```
初回セッションで最も多く見ること：クライアントが「明確さが欲しいだけ」と言い、実際に意味しているのは「答えがすでに明らかであることを否定するのをやめる許可が欲しい」ということ。

明確さが欠けているピースであることはまれ。欠けているピースは、すでに明確なものをその名前で呼ぶ意欲。

3か月同じ決定でぐるぐる回っているなら、作業は分析的ではない。すでに知っていることに基づいて行動する準備ができているかどうか、ということ。

50分のセッションは答えをくれない — あなたが持っている。それを認める余地をくれるかもしれない。

これが響いたら、投稿を保存。響かなければ、私はおそらく適切な相手ではない、それで構わない。

#coaching #clarity #decisionmaking
```

それがバー。具体的、意見のある、範囲を尊重した、禁止語彙なし、偽の親密さなし。

## 週刊ニュースレター・イントロ・テンプレート

### プロンプト

```
あなたは [実践者タイプ] の個人実践のための週刊ニュースレターのイントロ段落を書いています。

今週のトピック：[貼り付け]
気づいている最近のクライアントパターン（匿名化）：[貼り付け、任意]

ルール：
- イントロは100〜180語
- ボイス：暖かく、具体的、若干説明不足（読者を信頼する）
- 禁止語なし
- フックで始まる — 観察、質問、または短い物語
- イントロの終わりまでに1つのテイクアウェイ
- 明確な移行でニュースレターの本文に引き継ぐ
```

### 出力構造（例 — パーソナルトレーナー）

```
今週3人のクライアントが、異なる言葉で同じことを伝えました：「大丈夫、ただ疲れているだけ」。

「大丈夫で疲れている」は状態ではない。何かが長すぎる間、延期されてきたという信号。あるクライアントにとってそれは睡眠だった — 彼は1か月間慢性的に6時間未満で、それを普通と呼んでいた。別のクライアントにとってはストレングス — 忙しい仕事の期間中にセッションを減らし、ストレングスの低下が追いついた。3人目にとっては栄養。

「大丈夫」はほぼ常にこの3つのうちの1つ。

今週、自分自身に問うべきいくつかの質問＋それぞれのための10分間のドリル。残りは下にざっと目を通してください。
```

## ウェブサイト・サービスページ・テンプレート

### プロンプト

```
あなたは個人 [実践者タイプ] のウェブサイトのメインサービスページを書いています。

私の実践について：
- 実践者タイプ：[ライフコーチ／パーソナルトレーナー／資格を持つライセンスセラピスト]
- 管轄区域：[該当する場合、ライセンスを持つ場所]
- 実際に行っていること：[2〜3文を貼り付け]
- 一緒に取り組む対象：[オーディエンス]
- 料金：[表示する場合] / 「お問い合わせ」 / 「Pay-what-works」
- 形式：[対面／ビデオ／電話／ミックス]

ルール：
- 全体350〜500語
- セクション：(1) ヒーロー — 1文、誰を何で助けるか；(2) 私と取り組むとはどのようなものか — 一般論ではなく具体性；(3) コストと形式；(4) これが合わない人；(5) 次のステップ
- ボイス：具体的、暖かい、セールス的でない
- 禁止語なし
- 「これが合わない人」セクションは必須 — 信頼を構築し、事前に資格を確認する
- 1つの CTA で終わる
- セクション4に実践範囲行を含める
```

### 出力構造（例 — ライセンスセラピスト）

```
# 「あらゆることを試した」と感じる大人のためのセラピー

[名前]、[管轄区域] における [資格]。これまでにセラピーを経験し、より地に足の着いた、現在に焦点を当てた、具体的なものを求めている大人と取り組んでいます。

## 私と取り組むとはどのようなものか

セッションは毎週または隔週、50分、ビデオまたは対面。

初回セッションはほとんどが聴くことです — 何が大変だったか、過去に何が機能したか、何を違うやり方でやりたいかについて多くの質問をします。終わるまでに、私が合うかどうかわかるでしょう。

その後、セッションは一部会話、一部スキル構築です。役立つものに応じて、[訓練を受けた2〜3のモダリティ — CBT、ACT、IFS、EMDR など] から引き出します。台本は得られません。あなたに特化した取り組み方が得られます。

セッション間に、私は時折試すべきことを提案します — 気づきの実践、ジャーナリングのプロンプト、行うべき会話。作業をしているのはあなたで、私の仕事はそれを実際に動かすのに十分具体的にすることです。

## コストと形式

50分のセッションあたり [$X]。スライディングスケール利用可能 — お尋ねください。セッションはビデオ（Zoom または Doxy）または [近隣] の私のオフィスでの対面。保険のネットワーク外です。部分的な払い戻しのために提出できる領収書を提供します。

## これが合わない人

私は次のような場合には適切な相手ではありません：
- 進行中の危機にあり、より高強度のケア（DBT-IOP、部分入院）が必要な場合。紹介をお手伝いできます。
- 投薬管理を求めている場合。私は処方者ではありません。
- タイムラインで具体的な目標に向けて押してくれるコーチを求めている場合。それは私の働き方ではありません。

これらのいずれかがイエスの場合、おそらくより適した方をご紹介できます。

## 次のステップ

[無料の15分間コンサルテーションを予約] — 短くお話しし、フィットするかどうかわかります。

*セラピーは [管轄区域] において規制されています。私は [委員会／カレッジ] のライセンスを保有しています。危機にある場合は、988（米国／カナダ）、または日本ではよりそいホットライン 0120-279-338 やいのちの電話、最寄りの救急部門にご連絡ください。*
```

## 休眠クライアントへの再エンゲージメント・メール

4週間以上不在で、連絡すべきかわからないクライアント向け。

### プロンプト

```
あなたは休眠した [コーチング／トレーニング／セラピー] クライアントへの再エンゲージメント・メールを起草しています。

関係履歴：
- セッション数：[N]
- 最終セッション：[日付／どのくらい前]
- どのように終わったか：[中立／突然／相互の一時停止／不明確]
- 実践者タイプ：[コーチ／トレーナー／セラピスト]

ルール：
- 80〜150語
- 暖かく、プレッシャーなし
- 時間のギャップを認めるが、変な感じにしない
- 低摩擦の次のステップを提供する（1つの質問、短いチェックイン）
- 「戻るべき」または遅れているとほのめかさない
- 自律性を尊重する — 戻らない権利がある
- 免責事項のフッターを含める
```

### 出力構造（例 — ライフコーチ）

```
こんにちは A. さん、

最後のセッションから約6週間が経ちました。追いかけているわけではありません — チェックインだけです。

人生が違う方向に引っ張ったなら、完全に問題ありません。セッションを再開することを考えているけれども、その瞬間を見つけていないなら、それも普通で、いつでもここにいます。

中断したところから再開するのが理にかなっているか、それとも何か違うことから始めるべきかについて10分間話したい場合は、このメールに返信していただければ、いくつかの時間をお送りします。

いずれにせよ、お元気で。

— [コーチ名]

*コーチングは医療またはメンタルヘルスケアの代替ではありません。危機にある場合は、988（米国／カナダ）、または日本ではよりそいホットライン 0120-279-338 やいのちの電話、お住まいの地域の緊急回線にご連絡ください。*
```

## 良いマーケティングコピーが行わないこと

- **結果を約束する。** 「気分が良くなる」。「15ポンド減る」。結果は人それぞれ。コピーは作業を説明する。
- **実践者が誰にでも合うふりをする。** 明確な「これが合わない人」セクションは、曖昧な「準備ができている誰とでも取り組む」よりも信頼できる。
- **資格なしに臨床言語を使用する。** ライフコーチが「トラウマを処理する」と言うと、法的な露出を生み、クライアントを失望に向かわせる。
- **「passion」をデフォルトにする。** その言葉はマーケティングコピーで意味がない。実際に行っていることを説明する。
- **親密さを偽造する。** 「あなたを見ています」。「あなたは一人ではありません」。実践者が読者とその行を獲得していない場合、偽物に見える。
- **免責事項を省略する。** すべての公開向けピースには免責事項が含まれる。編集は問題ない；削除には理由が必要。
