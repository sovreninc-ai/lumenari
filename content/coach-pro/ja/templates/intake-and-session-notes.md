# インテークフォーム＋セッションノート

3つのフォーマットをカバー：インテークフォーム、SOAP ノート、DAP ノート、ナラティブノート。あなたの資格とユースケースに合うフォーマットを選んでください。

---

## インテークフォーム・テンプレート

初回セッションのオンボーディング用。デジタルフォーム（Google Forms / Typeform / Practice Better / Jane / SimplePractice）として使用するか、クライアントポータルに貼り付けます。

### プロンプト

```
あなたは [管轄区域] における [実践者タイプ] のクライアント・インテークフォームを作成しています。以下を含む完全なインテークフォームを生成してください：

1. クライアント識別情報（名前、代名詞、希望の連絡方法、タイムゾーン）
2. 緊急連絡先＋業務時間外の指示
3. [コーチング／トレーニング／セラピー] を求める理由
4. 私の実践範囲に適したレベルでの関連する経歴（私がライセンスを持っていない限り、医療履歴は含めない）
5. 目標 — 3か月後の成功はどのように見えるか
6. [コーチング／トレーニング／セラピー] の過去の経験
7. 実務的事項（頻度の希望、モダリティ、スケジュール）
8. 料金の確認＋キャンセルポリシー
9. 実践範囲のステートメント — 私が行うことと行わないこと
10. インフォームドコンセント — 秘密保持、秘密保持の限界、該当する場合は強制通報の認識
11. クライシスライン確認

クリーンな番号付きフォームとして出力してください。各質問は1〜3文で回答可能であるべきです。

私の実践の詳細：
- 実践者タイプ：[ライフコーチ／パーソナルトレーナー／資格を持つライセンスセラピスト]
- 管轄区域：[州／道府県]
- 提供サービス：[実際に行っていること]
- 料金：[あなたの料金]
- キャンセルポリシー：[あなたのポリシー]
- セッション形式：[対面／ビデオ／電話／ミックス]
```

### 出力構造（ライフコーチの例）

```
# [実践名] — 新規クライアント・インテーク

初回セッションの設定ありがとうございます。少なくともお会いする24時間前までにこのフォームを記入してください。

## 1. あなたについて
- 氏名
- 希望される呼び名（異なる場合）
- 代名詞
- メール
- 電話（スケジューリング以外で使用するときはお伝えします）
- タイムゾーン

## 2. 緊急連絡先
- 氏名＋あなたとの関係
- 電話

注：私は定期的なセッション時間（火-金、午前9時-午後5時 MT）を維持しています。その時間外にはクライシスサポートを提供していません。危機にある場合は、988（米国／カナダ）、または日本では「いのちの電話」やよりそいホットライン 0120-279-338 にご連絡いただくか、最寄りの救急部門へお越しください。

## 3. 今コーチングに来ている理由は何ですか？
取り組みたいことについて数文。回顧録を書く必要はありません — 一緒に深めていきます。

## 4. 3か月後に「良い」状態はどのように見えますか？
イメージが明確であるほど、初回セッションがより有用になります。

## 5. これまでコーチやセラピストと取り組んだことはありますか？
- はい／いいえ
- はいの場合 — あなたにとって何が機能し、何が機能しなかったですか？

## 6. 実務的事項
- 希望頻度（毎週／隔週／月次）
- 希望モダリティ（ビデオ／電話／対面）
- 知っておくべきスケジュールの制約

## 7. 料金とキャンセル
私の料金はセッションあたり [$X] です。キャンセルポリシー：24時間前の通知が必要。欠席または遅いキャンセルは全額請求されます。

このフォームを送信することにより、料金とキャンセルポリシーを承認します。

## 8. 私が行うことと行わないこと
私はライフコーチであり、ライセンスを持つメンタルヘルス専門家ではありません。コーチングは現在の目標、説明責任、パターン認識に焦点を当てます。セラピーや医療ケアの代替ではありません。

私の範囲外であることに気づいた場合、いつでもお伝えし、紹介について話し合うことができます。それは私の働き方の一部であり、問題ではありません。

## 9. インフォームドコンセント
このフォームを送信することにより、以下を確認します：
- 自発的にコーチングに参加していること
- コーチングはセラピーや医療ケアではないことを理解していること
- セッションは秘密保持されますが、以下の制限があります：あなたまたは他者が差し迫った危険にあると信じる合理的な理由がある場合、または法的に開示が強制される場合、私は秘密保持を破ることがあります
- あなたが自身の決定と、セッション外で行う行動に責任を負うこと

## 10. 初回セッション前に知っておくべきことはありますか？
任意。何か思いつくことがあれば数文。
```

ライセンスセラピストの場合、インテークフォームはより長く、臨床履歴を含みます。パーソナルトレーナーの場合、目標／履歴をフィットネス評価＋健康スクリーニング（PAR-Q+）＋負傷履歴に置き換えてください。

## SOAP ノート・テンプレート

ライセンスを持つ臨床医および関連医療実践者向け。

### プロンプト

```
あなたは大まかなセッション内容から SOAP ノートを作成しています。

実践者タイプ：[LCSW / RP / LPC / 心理士 / PT / OT など]
クライアント：[イニシャルまたは仮名]
セッション番号：[番号]
日付：[日付]
モダリティ：[対面／ビデオ／電話]
時間：[分]

大まかな内容（セッションで出てきたこと）：
[大まかなノートを貼り付ける — クライアントの言葉、あなたの観察、テーマ]

ルール：
- 全体の長さ200〜400語
- Subjective = クライアントが報告した経験（引用は控えめに）
- Objective = あなたが観察した行動、感情、提示、測定可能な項目
- Assessment = 観察言語によるあなたの臨床的印象。私が明示的に提供しない限り、DSM-5 診断名を挙げてはいけません
- Plan = 次のステップ、セッション間の作業、次回セッションの焦点
- クライシス信号や範囲境界イベントは明示的にフラグを立てる
- 臨床医の署名行＋資格で終わる
```

### 出力構造（例）

```
# SOAP ノート — クライアント J.K. — セッション4
**日付：** 2026-05-14 | **モダリティ：** ビデオ | **時間：** 50分

**S (Subjective)：**
クライアントは「厳しい一週間」だったと報告し、妹との2つの境界対立を説明、そのうち1つで「子どもの頃に戻ったような気がした」と述べた。今週の睡眠は1晩5〜6時間（先週の7〜8時間から減少）と報告。直接尋ねた際、SI/HI を否定。週中の不安の若干の増加を報告、金曜までに解消。

**O (Objective)：**
クライアントは見当識 x3 を提示、以前のセッションと比較してわずかに制限された感情。発話速度は正常範囲内。セッションの後半は問題解決に積極的に従事。精神運動性興奮なし。ビデオ越しに適切なアイコンタクト。

**A (Assessment)：**
家族との境界作業が引き続き主要テーマ。クライアントはパターンをリアルタイムで識別する能力の向上を示しており、境界の実装には若干の遅れがある。今週の不安は状況的で自己制限的に見える。現時点で安全上の懸念はなし。

**P (Plan)：**
次週、同時刻にセッション5を継続。セッション間に、クライアントは（1）私たちが取り組んだスクリプト化された境界フレーズを練習し、（2）反応する前にパターンに気づいた1つの状況をジャーナルする。次回セッションの焦点：境界スクリプトを深め、適切であれば価値観の明確化作業を導入する。臨床上の懸念フラグなし。

— [臨床医名]、[資格]
```

## DAP ノート・テンプレート

カウンセリング、ソーシャルワーク、およびワークフローで DAP を使用する実践者向け。

### プロンプト

```
あなたは大まかなセッション内容から DAP ノートを作成しています。

[SOAP と同じ入力ヘッダー]

ルール：
- 長さ150〜300語
- Data = 結合された subjective + objective（クライアントの報告＋あなたの観察）
- Assessment = 観察言語による臨床的印象
- Plan = 次のステップ＋セッション間の作業
- クライシス信号や範囲境界イベントにフラグを立てる
```

### 出力構造（例）

```
# DAP ノート — クライアント M.R. — セッション8
**日付：** 2026-05-14 | **モダリティ：** 対面 | **時間：** 45分

**D (Data)：**
クライアントは生産的な一週間を説明。職場での高不安の瞬間に3回グラウンディング・エクササイズを使用し、「実際に役立った」と感じたと報告。前回のセッションよりも明るい感情、よりオープンな姿勢、全体を通して関与。ルーティン・チェックインで SI/HI を否定。今後の家族イベントを潜在的ストレッサーとして挙げた。

**A (Assessment)：**
不安管理の継続的進展。クライアントはグラウンディング技法を内面化し、積極的に使用していることを示す。家族イベントに関する予期不安を記録。次回セッションプランニングに統合する。安全上の懸念なし。

**P (Plan)：**
次週セッション9。セッション間に、クライアントは毎日グラウンディングを練習し、家族イベントの予期されるストレッサーを1つジャーナルする。次回セッション：イベントの構造化された準備、境界設定言語を含む。

— [臨床医名]、[資格]
```

## ナラティブ・セッションノート（コーチおよびトレーナー向け）

臨床フォーマットが実践に合わない場合。

### プロンプト

```
あなたは大まかな内容からナラティブ・セッションノートを作成しています。

実践者タイプ：[ライフコーチ／パーソナルトレーナー／栄養コーチなど]
クライアント：[イニシャルまたは仮名]
セッション番号：[番号]
日付：[日付]
モダリティ：[対面／ビデオ／電話]
時間：[分]

大まかな内容：
[大まかなノートを貼り付ける]

ルール：
- 長さ150〜300語
- 臨床フォーマットではない（「Assessment」は使わず、「Observations」または「気づいたこと」を使用）
- コーチング範囲内に留まる — 臨床的印象ではなく、作業を説明する
- クライアントがセッション間にコミットしたことを特定する
- 紹介を検討すべき瞬間にフラグを立てる（メンタルヘルス、医療、その他のライセンス範囲の領域とパターンマッチするもの）
```

### 出力構造（例 — ライフコーチ）

```
# セッションノート — クライアント A.L. — セッション6
**日付：** 2026-05-14 | **モダリティ：** ビデオ | **時間：** 50分

**取り組んだこと：**
A.L. はビジネスパートナーとの避けていた会話から始まりました — 火曜日にそれを行いました。彼女はそれを「予想したほどひどくはなかったが、お金の部分についてはフォローアップが必要」と説明しました。前半は何が機能したか（オープニングの明確さ、トピックを維持したこと）と何が機能しなかったか（パートナーがタイムラインに反発したときに折れたこと）の整理に費やしました。

**気づいたこと：**
A.L. は3セッション前よりも速く自身のパターンを名指ししています。彼女はプロンプトなしで物語の途中で折れたことを捉えました。反発があるときに依然として依頼を和らげる傾向があります。これは引き続き取り組みます。

**セッション間のコミットメント：**
彼女は金曜日までにお金の部分に関するフォローアップメールを送信します。一人で起草し、私からの編集はなし。

**次回セッションの焦点：**
メールと、パートナーからの返信があればそれをレビュー。反発の下で依頼を保持する作業を継続。

**紹介ノート：**
なし。今回のセッションでコーチング範囲外としてフラグを立てたものはなし。

— [コーチ名]

*コーチングは医療またはメンタルヘルスケアの代替ではありません。危機にある場合は、988（米国／カナダ）、または日本ではよりそいホットライン 0120-279-338 やいのちの電話、お住まいの地域の緊急回線にご連絡ください。*
```

## フォーマットを間違って選んだとき

- **コーチに SOAP** — 臨床的すぎる；擁護できないアセスメントを書くことになる
- **保険に請求するライセンス臨床医にナラティブ** — 文書化要件を満たさない
- **パーソナルトレーナーに DAP** — オーバーキル；ナラティブを使用
- **免責事項なしのフォーマット** — 再プロンプト；キットはデフォルトで免責事項を生成すべき
