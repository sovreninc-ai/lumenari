# 免責事項とクライシスフラグ

完全なライブラリ。実践者タイプ別の免責事項テキスト、クライシスフラグのルールセット、強制通報の認識のためのフレームワーク、そしてすべての実践がポリシーに含めるべきボイラープレート。

## クライシスプロトコル・フラグ

### トリガーリスト

AIは、ユーザーが貼り付けたクライアントコンテンツ（インテークの回答、セッション準備ノート、メッセージの抜粋、サマリーの草稿）からこれらの兆候を監視します：

**自殺念慮：**
- 受動的：「ここにいたくない」「目が覚めなくても気にしない」「生きているのに疲れた」
- 能動的：「どうやってやるか考えた」「計画がある」「[手段] にアクセスがある」、明確な意図の表明

**自傷行為：**
- 最近または継続中と説明される現在の行動
- 計画または手段の明示
- 過去のパターンからのエスカレーション

**他者への危害：**
- 特定の人物に対する明確な意図
- 計画、手段、またはタイムライン
- クライアントから報告された脅迫（クライアントが脅迫した場合、または受けた場合のいずれも）

**急性精神病症状の指標：**
- 現実として説明され、それに基づいて行動された幻覚
- 内容の重度の混乱
- 安全に影響する形で、外部の力に支配・監視・危害を受けているという信念の表明

**進行中の虐待の開示：**
- 児童虐待（疑いまたは目撃）— ほとんどの管轄区域で強制通報が適用されます
- 高齢者虐待 — 多くの管轄区域で強制通報が適用されます
- 親密なパートナー間暴力 — 現在進行中かつ急性

**薬物の過剰摂取または急性医療上の危険：**
- 現在または最近のものとして説明されている
- 他のリスク要因と組み合わさっている

### 応答テンプレート

AIがいずれかのトリガーを検出すると、以下を出力します：

```
クライシスフラグ — [兆候の種類]

このコンテンツには [具体的な兆候 — 例：「手段へのアクセスへの言及を伴う受動的自殺念慮」] が含まれています。これに関する通常の出力は継続しません。

推奨されるアクション：
1. これを臨床的優先事項として扱ってください。まだであれば、クライアントとの直接の人的コンタクト — 電話、ビデオ、または対面 — を可能な限り早く計画してください。
2. [既知であれば管轄区域] における強制通報の義務を確認してください。閾値が満たされているかどうかをお伝えすることはできません。それはあなたが規制当局およびスーパーバイザーと判断することです。
3. 標準のインシデントプロトコルに従って、開示と対応を文書化してください。

クライアントに送るために調整できる短いメッセージの提案（送信前に確認してください）：

> こんにちは [名前] さん、
>
> あなたが書いてくれた内容を読んで、直接お話ししたいと思いました。今日か明日、短い電話でつながれますか？今すぐ差し迫った危機にある場合は、988（米国／カナダ）に電話またはテキスト、または日本では「いのちの電話」やよりそいホットライン 0120-279-338 にご連絡いただくか、最寄りの救急部門へお越しください。
>
> あなたが支えられていることを確認したいのです。— [実践者]

すでに臨床的アクションを取り、起きたことと対応を記録した臨床インシデントノートを起草してほしい場合は、明示的にお求めください。
```

AIは、クライシスコンテンツに関して通常のセッションノートやコーチングコピーの生成を継続しません。フラグはワークフローを停止します。

### フラグが行わないこと

- 診断
- 実践者に秘密保持を破るべきかどうかを伝えること
- 強制通報の閾値が満たされているかどうかを判断すること
- 臨床判断を代替すること
- クライアントへの電話を代替すること

これは停止標識です。臨床業務は実践者が行います。

## 強制通報の認識

AIは強制通報が存在することを認識しています。AIが知らないこと：
- すべての管轄区域における具体的な法令
- 各種開示の閾値
- 通報のタイムライン（24時間、48時間、即時）
- 実践者の地域における指定機関またはホットライン

強制通報の領域に触れる場合、AIは実践者に管轄区域固有のルールを確認するよう促します。トリガーの例：

- クライアントによる児童虐待またはネグレクトの開示（クライアントが子ども、親、傍観者のいずれであっても）
- 高齢者虐待の開示
- 自身が強制通報者であるクライアントが、未成年者の虐待を含む職場のインシデントを開示する場合
- 特定可能な第三者への差し迫った危害（米国管轄区域における Tarasoff 基準、他地域の類似ルール）

AIのライン：

> 「これはあなたの管轄区域で強制通報を引き起こす可能性があります。決定する前に、規制当局、スーパーバイザー、またはコンサルテーショングループと一緒に、[管轄区域] 固有の法令とタイムラインを確認してください。私はあなたの代わりにこの判断を下すことはできません。」

## 「私たちは合わない場合」— すべての実践が持つべきポリシーのボイラープレート

これをウェブサイトのサービスページ、インテーク返信メール、初回コンサルテーションの話のポイントに記載してください。

### コーチおよびトレーナー向け

```
私は次のような場合には適切な相手ではありません：

- 進行中のメンタルヘルスの危機にあり、より高強度のサポートが必要な場合。コーチング／トレーニングは危機ケアではありません。
- メンタルヘルス状態の診断、投薬、または治療を求めている場合。ライセンスを持つセラピストや医師への紹介をお手伝いできます。
- 特定のタイムラインで保証された結果を期待している場合。コーチング／トレーニングは協働の作業であり、あなたが持ち込むものに応じて結果は異なります。
- 医療ケアの代替を求めている場合。健康状態がある場合は、チームに医師が必要です — それは私の役割ではありません。

上記のいずれかに該当する場合は、より適した方を通常ご紹介できます。
```

### ライセンスを持つセラピスト向け

```
私は次のような場合には適切な相手ではありません：

- より高レベルのケア（DBT-IOP、部分入院、入院）が必要な場合。紹介をお手伝いできます。
- 投薬管理を求めている場合 — 私は処方者ではありません。それが必要な一部であれば、精神科医と連携します。
- 私がトレーニングを受けていない特定のエビデンスベース・プロトコルを求めている場合。EMDR／CPT／特定のモダリティが必要と言われ、それが私の専門でない場合、紹介できます。
- 定期的な毎週の作業を行うのに十分安定した状況にない場合（住居、即時の安全）。まず安定化させましょう。
```

## 業務時間外およびクライシスラインのボイラープレート

すべてのウェルカムメール、インテークフォーム、サービスページは、「セッション時間外に危機にある場合、私は何をすべきか？」という問いに答えるべきです。

### 標準ブロック

```
業務時間外およびクライシスサポート

私は通常のセッション時間外にはクライシスサポートを提供していません。危機にある場合：

- 988 — 自殺・クライシスライフライン（米国およびカナダ — 電話またはテキスト）
- 1.866.585.0445 — Hope for Wellness ヘルプライン（カナダ、英語、フランス語、クリー語、オジブウェイ語、イヌクティトゥット語で利用可能）
- 日本にいる場合：よりそいホットライン 0120-279-338 / いのちの電話
- 最寄りの救急部門
- 911（米国） / 911（カナダ） / 119（日本：救急） — 差し迫った危険にある場合

セッション間の非緊急の質問については、メールで連絡いただければ [標準の応答期間 — 例：「1営業日」] 以内に返信します。
```

具体的なラインは管轄区域に合わせて調整してください。上記の番号は、北米において2026年時点で有効です。

## ノーショー／キャンセルポリシーのボイラープレート

これをインテークフォームおよび料金確認書に記載してください。

```
キャンセルポリシー

キャンセルまたは再スケジュールには24時間前の通知が必要です。24時間以内のセッション欠席またはキャンセルは、医療的緊急事態またはその他の特別な事情（私の裁量による）を除き、セッション料金の全額が請求されます。

ノーショーの場合、私から一度連絡を取って確認します。1週間以内に返信がない場合は、私たちの作業が一時停止されたものとみなし、セッション枠を再びローテーションに戻します。再開する準備ができたら、いつでもご連絡ください。
```

## 結論

免責事項が存在する理由：
1. クライアントが何を得ているかを明確化することで彼らを保護する
2. 行き過ぎの主張から実践者を保護する
3. 範囲を明示することで、必要なときの紹介が容易になる
4. 信頼を構築する — 境界が見えるとき、読者はより参加しやすくなる

AIはデフォルトで適切なものを含めます。実践者は編集できます。AIは、明示的な指示と理由の表明がない限り、それらを削除しません。
