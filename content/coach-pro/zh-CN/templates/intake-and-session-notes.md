# Intake 表 + Session Notes

覆盖三种格式:intake 表、SOAP notes、DAP notes、narrative notes。挑与你执照和用例匹配的格式。

---

## Intake 表模板

用于首次 onboarding。作为数字表(Google Forms / Typeform / Practice Better / Jane / SimplePractice)或粘进客户门户。

### 提示词

```
你在为 [从业者类型] 在 [管辖地] 起草客户 intake 表。生成完整 intake 表,包括:

1. 客户身份识别(姓名、代词、首选联系方式、时区)
2. 紧急联系人 + 工作时间外指引
3. 寻求 [教练 / 训练 / 治疗] 的原因
4. 与我执业范围相符的相关历史(除非我持牌,**不涉**医疗史)
5. 目标 —— 3 个月后"成功"长什么样
6. 过往 [教练 / 训练 / 治疗] 经验
7. 形式安排(频次偏好、形式、排期)
8. 收费承认 + 取消政策
9. 执业范围声明 —— 我**做**与**不做**什么
10. 知情同意 —— 保密、保密限制、若适用的强制报告意识
11. 危机线承认

输出为干净的编号表。每个问题用 1-3 句可答。

我的执业细节:
- 从业者类型:[生命教练 / 私教 / 持牌治疗师 + 执照]
- 管辖地:[省/州]
- 提供的服务:[我实际做什么]
- 收费:[你的费用]
- 取消政策:[你的政策]
- Session 形式:[面对面 / 视频 / 电话 / 混合]
```

### 输出结构(生命教练范例)

```
# [执业名] —— 新客户 Intake

谢谢你预约第一次 session。请在见面前至少 24 小时完成此表。

## 1. 关于你
- 全名
- 首选称呼(如不同)
- 代词
- 邮箱
- 电话(仅用于排期,除非你另外告知)
- 时区

## 2. 紧急联系人
- 姓名 + 与你的关系
- 电话

注:我有固定 session 时间(周二-周五,MT 9am-5pm)。我**不**在此时段外提供
危机支援。若你在危机中,请联系 988(美国/加拿大)或前往最近的急诊。

## 3. 是什么让你现在来做教练?
几句话讲讲你希望处理什么。**不用**写自传 —— 我们会一起进入。

## 4. 3 个月后"好"长什么样?
画面越清晰,我们第一次 session 越有用。

## 5. 过去你与教练或治疗师合作过吗?
- 是 / 否
- 如是 —— 什么对你有效或无效?

## 6. 形式安排
- 偏好频次(每周 / 双周 / 每月)
- 偏好形式(视频 / 电话 / 面对面)
- 我应知道的排期限制

## 7. 收费与取消
我的收费是每 session [$X]。取消政策:需提前 24 小时通知;
缺席或晚取消按全额收费。

提交此表即表示你承认收费与取消政策。

## 8. 我做什么和不做什么
我是生命教练,**不是**持牌心理健康专业人士。教练聚焦当下目标、问责与
模式识别。**不能**替代治疗或医疗护理。

如果我在任何时刻注意到超出我范围的内容,我会告诉你,我们可以谈推荐。
这是我工作方式的一部分,不是问题。

## 9. 知情同意
提交此表即表示你确认:
- 你**自愿**进入教练辅导
- 你理解教练**不是**治疗或医疗护理
- session 保密,有以下限制:若我有理由相信你或他人处于迫在眉睫的危险,
  或我被法律强制披露时,我**可能**违反保密
- 你对自己 session 外的决定与行动**负责**

## 10. 第一次 session 前还有什么我该知道?
可选。如有想到的几句话。
```

对持牌治疗师,intake 表更长,包含临床历史。对私教,用 fitness 评估 + 健康筛查(PAR-Q+) + 受伤史替换目标/历史。

## SOAP note 模板

用于持牌临床医生与辅助医疗从业者。

### 提示词

```
你在从粗略 session 内容起草 SOAP note。

从业者类型:[LCSW / RP / LPC / 心理学家 / PT / OT / 等]
客户:[首字母或化名]
Session #:[编号]
日期:[date]
形式:[面对面 / 视频 / 电话]
时长:[分钟]

粗略内容(session 出现的内容):
[粘你的粗略 notes —— 客户的话、你的观察、主题]

规则:
- 长度 200-400 字
- Subjective = 客户报告的体验(慎用引用)
- Objective = 你观察的行为、情感、呈现、可测量项
- Assessment = 你以**观察性语言**给的临床印象;**不**点名 DSM-5 诊断,
  除非我**明确**提供
- Plan = 下一步、session 间功课、下次重点
- 显式标注任何危机信号或范围边界事件
- 以临床医生签名行 + 执照收尾
```

### 输出结构(范例)

```
# SOAP Note —— 客户 J.K. —— Session 4
**日期:** 2026-05-14 | **形式:** 视频 | **时长:** 50 分钟

**S(Subjective):**
客户报告 "rough week" —— 描述了与姐姐的两次边界冲突,其中一次让她
"觉得自己又像个孩子"。报告本周睡眠每晚 5-6 小时,从上周 7-8 下降。
被直接询问时否认 SI/HI。报告周中焦虑略增,周五缓解。

**O(Objective):**
客户呈现 oriented x3,情感较以往 session 轻度受限。语速在正常范围内。
后半段积极参与问题解决。无精神运动激越。视频中有合适的眼神接触。

**A(Assessment):**
家庭原生边界工作仍是主要主题。客户展现出实时识别模式的能力提升,
执行边界仍有滞后。本周焦虑似乎情境性且自限。**当前无安全顾虑。**

**P(Plan):**
下周 Session 5,同一时间。session 间客户将(1)练习我们演练过的
边界话术、(2)就在反应**之前**注意到模式的一个情境写日记。下次重点:
深化边界话术 + 在合适时引入价值澄清。**无临床顾虑被标记**。

— [临床医生姓名]、[执照]
```

## DAP note 模板

用于咨询、社工与任何采用 DAP 工作流的从业者。

### 提示词

```
你在从粗略 session 内容起草 DAP note。

[同 SOAP 的输入头]

规则:
- 长度 150-300 字
- Data = 主观 + 客观合并(客户报告 + 你的观察)
- Assessment = 以观察性语言的临床印象
- Plan = 下一步 + session 间功课
- 显式标注任何危机信号或范围边界事件
```

### 输出结构(范例)

```
# DAP Note —— 客户 M.R. —— Session 8
**日期:** 2026-05-14 | **形式:** 面对面 | **时长:** 45 分钟

**D(Data):**
客户描述了一个高效周。报告在工作中高焦虑时刻使用了 3 次 grounding 练习,
觉得 "actually helpful"。情感较以往 session 更明亮,坐姿更开放,全程投入。
常规 check-in 否认 SI/HI。提到一项即将到来的家庭活动是潜在压力源。

**A(Assessment):**
焦虑管理持续进展。客户展现出 grounding 技术的内化,并主动使用。
对家庭活动的预期焦虑已注;将纳入下次 session 计划。**无安全顾虑**。

**P(Plan):**
下周 Session 9。session 间客户将每日练习 grounding,并就家庭活动预期
压力源写一项日记。下次重点:结构化为活动做准备,包括边界设置话术。

— [临床医生姓名]、[执照]
```

## Narrative session notes(教练与训练师)

当临床格式不合你执业时。

### 提示词

```
你在从粗略内容起草 narrative session notes。

从业者类型:[生命教练 / 私教 / 营养教练 / 等]
客户:[首字母或化名]
Session #:[编号]
日期:[date]
形式:[面对面 / 视频 / 电话]
时长:[分钟]

粗略内容:
[粘粗略 notes]

规则:
- 长度 150-300 字
- **不**用临床格式(**不要** "Assessment" —— 用 "Observations" 或 "我注意到的")
- **留在教练范围内** —— 描述工作,不写临床印象
- 标出客户做出的 session 间承诺
- 标记任何应考虑转介的时刻(任何与心理健康、医疗或其他持牌范围相匹配的)
```

### 输出结构(范例 —— 生命教练)

```
# Session Notes —— 客户 A.L. —— Session 6
**日期:** 2026-05-14 | **形式:** 视频 | **时长:** 50 分钟

**我们处理了什么:**
A.L. 开场谈了她一直回避的那次与生意伙伴的对话 —— 她周二谈了。她描述
为 "less terrible than I expected, but I still need to follow up on the
money piece"。我们前半段拆解了什么有效(她开场清晰、紧扣主题)和
什么无效(伙伴推回时她在时间表上让步)。

**我注意到的:**
A.L. 比三次 session 前**更快**地命名她的模式。她在故事中途**未经提示**地
抓到了让步那一刻。在推回下,她仍倾向**软化要求**;我们会继续处理。

**Session 间承诺:**
她将在周五前发关于钱那部分的跟进邮件。**独立**起草,不要我修改。

**下次重点:**
看那封邮件 + 伙伴的回应(若已来)。继续做在推回下守住要求的工作。

**转介注:**
无。本次 session 没有任何在教练范围之外的内容被标记。

— [教练姓名]

*教练**不能**替代医疗或心理健康护理。若你在危机中,请联系 988
(美国/加拿大)或当地紧急电话。*
```

---

## 选错格式时

- **教练用 SOAP** —— 太临床;你会写出**辩护不了**的 assessment
- **持牌临床医生开保险账单时用 narrative** —— **不满足**文档要求
- **私教用 DAP** —— 用力过猛;用 narrative
- **任何不带免责声明的格式** —— 重新提示;工具包**默认**应产生
