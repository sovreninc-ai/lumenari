# 营销文案

Instagram 标题、周报、网站服务页、沉睡客户重激活的模板。反模式强制内嵌 —— 不写 "transform your life"、不保证结果、不写 "passion" 话术。

注:本模板不构成法律建议;请遵守你管辖地的广告法与执业范围。

---

## 立规

本工具包产出的每条营销文案:

- 描述**工作**,不描述**结果**
- 匹配从业者类型 —— 教练语言 vs. 临床语言
- **留在执业范围内**
- 以**清晰下一步**收尾
- 避免禁用词:transform、unlock、passion、rock-star、10x、your best self、level up、journey(作名词)、elevate、empower
- 用 "client" 或 "我合作的人" —— **不**用 "customer"

若草稿落入以上任何一项,重新提示:"重写 —— 你用了禁用词。替换并保留意思。"

## Instagram 标题模板

### 提示词

```
你在为 [从业者类型] 的帖子写 Instagram 标题。

主题或话题:[粘 —— 可以是近期客户洞察(去标识)、你看到的常见模式、
想分享的文字、workshop 公告]

标题类型:[教育 / behind-the-scenes / 抛给受众的问题 / workshop 推广]

规则:
- 80-200 字
- 第一行钩子(好奇、反主流或具体观察)
- 一个清晰带走点或邀请
- 语气:温暖但具体;**不**是励志演讲者腔
- 不写禁用词(transform、unlock、passion 等)
- 以问题或清晰下一步结尾(DM、bio 链接、保存帖子)
- 用 hashtag 的话,保持 4-6 个具体的
```

### 输出结构(范例 —— 生命教练,教育型)

```
我在首次 session 里最常见的事:客户说 "I just want clarity",而他们**实际**的意思是
"I want permission to stop pretending the answer isn't already obvious"。

清晰**很少**是缺失的那块。**缺**的那块是**愿意**把已经清晰的事直呼其名。

如果你已经在同一个决定上空转了三个月,工作**不是**分析性的。是你是否准备
**对你已经知道的事采取行动**。

50 分钟 session **不会**给你答案 —— **你已经有了**。它**可能**给你**承认**它的空间。

如果这句打中,**保存这条帖**。如果没有,我可能就**不是**对的那个,**没关系**。

#coaching #clarity #decisionmaking
```

就是这个标准。具体、有观点、尊重范围、无禁用词、无虚假亲昵。

## 周报开头模板

### 提示词

```
你在为 [从业者类型] 的独立执业写每周 newsletter 的开头段。

本周话题:[粘]
我近期注意到的客户模式(去标识):[粘,可选]

规则:
- 开头段 100-180 字
- 语气:温暖、具体、略**少**解释(信任读者)
- 不写禁用词
- 用钩子开头 —— 观察、问题或短故事
- 开头段末尾给一个带走点
- 用清晰过渡交到 newsletter 主体
```

### 输出结构(范例 —— 私教)

```
本周三位客户用不同的话告诉我同一件事:"I'm fine, I'm just tired."

Fine 和 tired **不是**一种状态。它们是某件被推迟太久的事的**信号**。
一位客户是睡眠 —— 他长期低于 6 小时一个月,自称正常。另一位是力量 ——
她在忙碌工作期间减少了 session,力量流失追上来。第三位是营养。

"Fine" 几乎**总是**这三件之一。

本周几个问自己的问题 + 每件事的 10 分钟练习。其余在下面浏览。
```

## 网站服务页模板

### 提示词

```
你在为独立 [从业者类型] 的网站写主服务页。

关于我的执业:
- 从业者类型:[生命教练 / 私教 / 持牌治疗师 + 执照]
- 管辖地:[若适用,我的执照]
- 我**实际**做什么:[粘 2-3 句]
- 我与谁合作:[受众]
- 收费:[若展示] / "Inquire" / "Pay-what-works"
- 形式:[面对面 / 视频 / 电话 / 混合]

规则:
- 总长 350-500 字
- 段落:(1) hero —— 一句,你帮谁做什么;(2) 与我合作长什么样 —— 具体,
  非泛泛;(3) 费用 + 形式;(4) **这不适合谁**;(5) 下一步
- 语气:具体、温暖、**不**销售腔
- 不写禁用词
- "这不适合谁" 段是**必需** —— 它建立信任并预筛选
- 以**一个** CTA 收尾
- 第 4 段含执业范围说明
```

### 输出结构(范例 —— 持牌治疗师)

```
# 给觉得自己 "tried everything" 的成年人的治疗

我是 [姓名],[管辖地] 的 [执照]。我与做过一些治疗、寻求更接地气、
当下导向、具体的方式的成年人合作。

## 与我合作长什么样

session 每周或双周,50 分钟,视频或面对面。

首次 session 主要是听 —— 我会问很多关于近来什么难、过去什么有效、
你希望做得不一样的东西。结束时,你会知道我**合不合适**。

之后,session 一部分是对话,一部分是技能建设。我会基于 [列出你
受训过的 2-3 个模式 —— CBT、ACT、IFS、EMDR 等] 根据有用程度取用。
你**不会**拿到稿子。你会拿到**针对你**的工作方式。

session 间,我偶尔会建议一件事去试 —— 一个 noticing 练习、日记提示、
要做的对话。**你**在做工作;我的工作是让它**具体**到能动起来。

## 费用 + 形式

每 50 分钟 session [$X]。可滑动收费 —— 可以问。session 是视频(Zoom 或 Doxy)
或在 [街区] 我办公室面对面。保险方面我不在 in-network;我提供你可提交
**部分报销**的发票。

## 这不适合谁

我**不是**对的那个,如果:
- 你处于活跃危机,需要更高强度照护(DBT-IOP、partial hospitalization)。
  我能帮转介。
- 你在找药物管理。我**不是**处方者。
- 你想要一位会按时间表推你向具体目标的教练。**那不是**我的工作方式。

如果以上任一是"是",我大概率能帮你指向更合适的人。

## 下一步

[预约 15 分钟免费咨询] —— 我们简短聊,你会知道感觉对不对。

*治疗在 [管辖地] 受监管。我在 [board / college] 持牌。
若你在危机中,请联系 988(美国/加拿大)或最近的急诊。*
```

## 沉睡客户重激活邮件

针对离开 4+ 周、不确定要不要联系的客户。

### 提示词

```
你在为沉睡的 [教练 / 训练 / 治疗] 客户起草重激活邮件。

关系背景:
- session 数:[N]
- 上次 session:[date / 多久之前]
- 怎么结束的:[中性 / 突然 / 双方暂停 / 不明]
- 从业者类型:[教练 / 训练师 / 治疗师]

规则:
- 80-150 字
- 温暖、**无压**
- 承认时间间隔但**不要做得很别扭**
- 提供**低摩擦**下一步(一个问题、快速 check-in)
- **绝不**暗示他们"应该"回来或他们"落后了"
- 尊重他们的**自主权** —— 他们有**不**回来的权利
- 含免责声明 footer
```

### 输出结构(范例 —— 生命教练)

```
Hi A.,

距上次 session 大约六周了。**没有在追** —— 只是 check-in。

如果生活把你带去另一个方向,完全可以。如果你一直在想重新开始 session
但没找到时机,**这很正常**,我随时都在。

如果你想 10 分钟聊聊从我们停下的地方继续是否合适,或者我们该从不同
的地方开始,直接回复这封邮件,我会发几个可选时间。

无论如何,希望你好。

— [教练姓名]

*教练**不能**替代医疗或心理健康护理。若你在危机中,请联系 988
(美国/加拿大)或当地紧急电话。*
```

## 好营销文案不做什么

- **承诺结果。** "你会感觉更好。"、"你会减 15 磅。" 结果**因人而异**。文案描述**工作**。
- **假装从业者适合所有人。** 一段清晰的 "这不适合谁",比模糊的 "I work with anyone who's ready" **更可信**。
- **没有执照却使用临床语言。** 生命教练说 "we'll process the trauma" 会制造**法律敞口**并让客户失望。
- **默认用 "passion"。** 这个词在营销文案里**没意义**。描述你**实际**做什么。
- **制造亲昵。** "I see you."、"You're not alone." 若从业者尚未对读者**赢得**这一句,读起来就**假**。
- **跳过免责声明。** 每条公开文案都包含。可编辑,删除需要理由。
