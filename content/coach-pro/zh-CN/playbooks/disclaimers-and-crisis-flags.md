# 免责声明 + 危机标记

完整库。按从业者类型的免责声明文本、危机标记规则集、强制报告意识脚手架,以及每家执业政策里都该有的样板。

注:本文档不构成法律或临床建议。请遵守你管辖地的执业范围、监管与广告法。

## 免责声明库

### 教练 / 私教 —— 客户面沟通

```
教练 / 私教辅导**不能**替代医疗、心理健康或精神科治疗。
若你正在经历心理健康危机,请联系 988(美国/加拿大)或当地紧急电话。
```

用于:欢迎邮件、session 提醒、营销页、intake 表、session 间消息。

### 持牌治疗 —— 客户面沟通

```
本沟通是你与 [从业者姓名、执照、license #] 之间治疗关系的一部分。
它**不构成**紧急心理健康服务。若你在危机中,请联系 988(美国/加拿大)
或前往最近的急诊。
```

用于:常规客户消息、recap 邮件、远程医疗平台嵌入、与客户分享的 session 间笔记。

### 营销文案 / 网站 —— 所有从业者类型

```
[服务类型] 在 [管辖地] 受监管。我在 [board / college / 监管机构] 持牌
(license #[X])。

本网站**不构成**临床关系。结果因人而异,我**不保证**具体结果。
若你在危机中,请联系 988(美国/加拿大)或当地紧急电话。
```

用于:执业网站上的**每个**公开页面。

### Intake 表 —— 所有从业者类型

```
提交此表即表示你承认:

- 你**自愿**进入 [教练 / 训练 / 治疗]
- 你理解上述描述的服务范围
- session 保密,有以下限制:[从业者**可能**违反保密,若有理由相信你或
  他人迫在眉睫的危险;被法律强制披露;强制报告义务适用]
- 你对 session 外的决定与行动**负责**
- 你已被告知如何在 [从业者] 工作时间外取得紧急支援
```

请将保密限制调整为你管辖地与执照适用的版本。

## 危机协议标记

### 触发清单

AI 警惕用户粘贴的任何客户内容(intake 答复、session 准备笔记、消息节选、recap 草稿)中以下信号:

**自杀意念:**
- 被动:"wish I weren't here"、"wouldn't mind if I didn't wake up"、"tired of being alive"
- 主动:"thought about how I'd do it"、"have a plan"、"have access to [手段]"、明示意图

**自伤:**
- 当前被描述为近期或正在进行
- 计划或手段已指定
- 较以往模式升级

**伤害他人:**
- 对特定人的明确意图
- 计划、手段或时间表
- 客户报告的威胁(无论他们发出或接收)

**急性精神病征象:**
- 被描述为真实并据此行动的幻觉
- 内容呈现严重 disorganization
- 关于被外部力量控制、监视或伤害的陈述影响到安全

**当前虐待披露:**
- 儿童虐待(怀疑或目睹)—— 多数管辖地强制报告**适用**
- 老人虐待 —— 许多管辖地强制报告**适用**
- 亲密伴侣暴力 —— 当前且急性

**药物过量或急性医疗危险:**
- 被描述为当前或近期
- 与其他风险因素组合

### 回应模板

AI 检测到任意触发时,输出:

```
CRISIS FLAG —— [信号类型]

本内容包含 [具体信号 —— 例如 "被动自杀意念,且提到可获得手段"]。
我**不会**在此内容上继续常规输出。

建议动作:
1. 把这件事当**临床优先级**对待。如尚未做,计划尽快与客户**直接的人类
   接触** —— 电话、视频或面对面。
2. 审视 [若已知,管辖地] 你的强制报告义务。我**不能**告诉你阈值是否
   达到;那是你与监管机构和督导之间的决定。
3. 按你的标准事件协议记录披露与你的回应。

供你给客户的建议短消息(发出前请审阅):

> 嗨 [姓名],
>
> 读到你写的内容,我想**直接**和你 check-in。今天或明天能简短通话吗?
> 若你**当下**处于紧急危机,请拨打或短信 988(美国/加拿大),
> 或前往最近的急诊。
>
> 我希望确保你获得支持。— [从业者]

如果你已采取临床行动,想让我起草记录所发生事件和你应对的临床事件 note,
请明确请求。
```

AI **不会**在危机内容上继续产出常规 session notes 或教练文案。**这个标记停止工作流。**

### 标记**不**做什么

- 诊断
- 告诉从业者是否违反保密
- 决定强制报告阈值是否达到
- 替代临床判断
- 替代给客户的一通电话

**它是一个停止信号**。临床工作由从业者做。

## 强制报告意识

AI 知道强制报告存在。它**不**知道:
- 每个管辖地的具体法令
- 每类披露的阈值
- 报告时间窗(24 小时、48 小时、立即)
- 从业者所在地区的具名机构或热线

当触及强制报告地带时,AI 提示从业者去核对管辖地特定规则。触发例子:

- 客户披露儿童虐待或忽视(无论客户是儿童、父母或旁观者)
- 老人虐待被披露
- 一位本身是 mandated reporter 的客户披露涉及未成年人虐待的工作场所事件
- 对可识别第三方的迫在眉睫伤害(美国管辖地的 Tarasoff 阈值;其他地方类似规则)

AI 的措辞:

> "这**可能**在你管辖地触发强制报告。在决定前,与你的监管机构、督导
> 或咨询小组核对 [管辖地] 的具体法令与时间窗。**这个判断不能由我替你做**。"

## "我们可能不合适如果……" —— 每家执业都该有的政策样板

放在网站服务页、intake 回执邮件,以及初次咨询的谈话要点里。

### 教练与训练师

```
我**不是**对的那个,如果:

- 你处于**活跃**心理健康危机,需要更高强度支援。教练 / 训练**不是**危机照护。
- 你在找心理健康状况的诊断、药物或治疗。我能帮转介到持牌治疗师或医生。
- 你希望在特定时间表上获得**保证**结果。教练 / 训练是协作工作;结果
  视你带入的内容而异。
- 你在找医疗护理的替代品。如果你有健康状况,你需要团队里有一位医生 —— **我不是**。

如果以上任一适用,我通常能为你指向更合适的人。
```

### 持牌治疗师

```
我**不是**对的那个,如果:

- 你需要更高级别照护(DBT-IOP、partial hospitalization、住院)。我能帮转介。
- 你在找药物管理 —— 我**不是**处方者;如果那是你需要的一部分,我们会
  与精神科医生协调。
- 你在寻求我未受训的特定循证流程。如果你被告知需要 EMDR / CPT / 特定模式,
  而那**不是**我的专长,我能转介。
- 你处于不够稳定的状态以做规律的每周工作(住房、即时安全)。
  **先稳定**。
```

## 工作时间外与危机线样板

每封欢迎邮件、intake 表与服务页都应回答:"如果我在危机中且不是 session 时段怎么办?"

### 标准块

```
工作时间外与危机支援

我**不**在常规 session 时段外提供危机支援。若你在危机中:

- 988 —— Suicide and Crisis Lifeline(美国 & 加拿大 —— 拨打或短信)
- 1.866.585.0445 —— Hope for Wellness Helpline(加拿大,提供英、法、克里、
  奥吉布瓦、因纽特语)
- 最近的急诊
- 911(美国)/ 911(加拿大),若你处于即时危险

session 间的非紧急问题,给我发邮件,我会在 [你的标准回复窗 —— 例如
"1 个工作日"] 内回复。
```

请将具体行调整为你管辖地。上述号码截至 2026 年北美地区有效。

## No-show / 取消政策样板

放在 intake 表和你的费用承认里。

```
取消政策

取消或改期需提前 24 小时通知。错过的 session 或 24 小时内取消按 session
全额收费,除非属于医疗紧急或其他经我自由裁量的特殊情况。

如果你 no-show,我会主动 check-in 一次。若一周内未收到回音,我会视
我们的工作为暂停,并将 session 名额放回轮转。你准备好回来时随时联系。
```

## 底线

免责声明存在,因为:
1. 它们**保护客户**,说清他们将得到什么
2. 它们**保护从业者**免受越权指控
3. 它们让范围**明确**,在需要时让转介更容易
4. 它们**建立信任** —— 边界可见时,读者更愿参与

AI **默认**包含合适的。从业者欢迎编辑。**没有明确指令和说明的理由**,AI **不会**删除它们。
