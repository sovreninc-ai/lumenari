# Quick Start — Brand Voice Builder

Você vai estar rodando em menos de um minuto.

## ChatGPT, Claude (web) ou Gemini

1. Abra a ferramenta
2. Cole o conteúdo de `optimization-pack.md` no campo de system prompt / custom instructions / project knowledge
3. Cole 3-5 amostras de escrita e peça para ele extrair um perfil de voz

## Claude Code, Cursor ou Codex (caminho do SKILL.md)

1. Abra o Terminal (ou seu editor de código)
2. Jogue a pasta do kit em `~/.claude/skills/brand-voice/` (Claude Code) ou cole `SKILL.md` na raiz do seu projeto (Cursor / Codex)
3. Digite o que você quer — o Claude pega a skill automaticamente

## Teste se funciona

Cole isto: "Extraia um perfil de voz destas três amostras: (1) 'Hard pass na demo. Não definiriam sucesso.' (2) 'Três semanas de silêncio. Desculpa. Voltei.' (3) 'Você não precisa de um framework. Entregue a coisa.'"

Se você receber de volta um perfil com quatro pontuações de atributo de voz (1-5), uma assinatura de vocabulário, uma lista de banimento e um dispositivo de framing nomeado — com cada alegação citando uma amostra — o kit está carregado certo.
