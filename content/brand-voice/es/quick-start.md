# Inicio rápido — Brand Voice Builder

Vas a estar corriendo en menos de un minuto.

## ChatGPT, Claude (web) o Gemini

1. Abre la herramienta
2. Pega el contenido de `optimization-pack.md` en el campo de system prompt / custom instructions / project knowledge
3. Pega 3-5 samples de escritura y pídele que extraiga un perfil de voz

## Claude Code, Cursor o Codex (camino SKILL.md)

1. Abre Terminal (o tu editor de código)
2. Suelta la carpeta del kit en `~/.claude/skills/brand-voice/` (Claude Code) o pega `SKILL.md` en la raíz de tu proyecto (Cursor / Codex)
3. Escribe lo que quieras — Claude levanta el skill automáticamente

## Prueba que funciona

Pega esto: "Extrae un perfil de voz de estos tres samples: (1) 'Hard pass en la demo. No quisieron definir el éxito'. (2) 'Tres semanas de silencio. Perdón. De vuelta'. (3) 'No necesitas un framework. Shippea la cosa'".

Si recibes un perfil con cuatro scores de atributos de voz (1-5), una firma de vocabulario, una lista de prohibidas, y un dispositivo de framing nombrado — con cada claim citando un sample — el kit está bien cargado.
