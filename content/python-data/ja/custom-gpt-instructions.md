# 統計テストの選択

| 質問 | テスト |
| --- | --- |
| 2 群、平均が異なる? | Welch の t 検定；非正規なら Mann-Whitney |
| 同一群の前後? | 対応のある t 検定；非正規なら Wilcoxon |
| 3+ 群、平均が異なる? | 一元配置 ANOVA；非正規なら Kruskal-Wallis |
| 2 つのカテゴリ変数、関連? | カイ二乗；期待度数が小さければ Fisher の正確 |
| 線形関係? | Pearson + OLS；非線形単調なら Spearman |

常に含める: サンプルサイズ、効果量（Cohen's d、R²、オッズ比、η²）、信頼区間、普通の日本語による解釈。
