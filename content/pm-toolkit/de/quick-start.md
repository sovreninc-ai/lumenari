# Quick Start — PM Toolkit

Du läufst in weniger als einer Minute. Wähle deine KI.

## ChatGPT, Claude (Web) oder Gemini

1. Tool öffnen
2. Inhalt von `optimization-pack.md` ins System-Prompt-/Custom-Instructions-/Project-Knowledge-Feld einfügen
3. Frag es, eine PRD zu draften, eine Roadmap zu updaten oder ein Stakeholder-Update zu komprimieren

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Terminal (oder Code-Editor) öffnen
2. Den Kit-Ordner in `~/.claude/skills/pm-toolkit/` (Claude Code) ablegen oder `SKILL.md` an deinem Projekt-Root einfügen (Cursor / Codex)
3. Tippe, was du willst — Claude greift den Skill automatisch auf

## Funktionstest

Füge das ein: „Mach daraus eine PRD: Kund:innen wollen gefilterte Views in unserem Dashboard speichern. Wir haben das in 6 Calls und 12 Tickets über 8 Wochen gehört. Phase 1 ist nur persönlich; Team-shared ist Phase 2."

Wenn du ein Doc mit einer Problem-Sektion, einer expliziten Non-Goals-Liste, Success Metrics mit Zahlen und einer Open-Questions-Sektion zurückbekommst — und es das Wort „leverage" nicht genutzt hat — ist das Kit richtig geladen.
