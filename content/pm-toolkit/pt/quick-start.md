# Quick Start — PM Toolkit

Você vai estar rodando em menos de um minuto. Escolha sua IA.

## ChatGPT, Claude (web) ou Gemini

1. Abra a ferramenta
2. Cole o conteúdo de `optimization-pack.md` no campo de system prompt / custom instructions / project knowledge
3. Comece pedindo um draft de PRD, atualização de roadmap ou compressão de update de stakeholder

## Claude Code, Cursor ou Codex (caminho do SKILL.md)

1. Abra o Terminal (ou seu editor de código)
2. Jogue a pasta do kit em `~/.claude/skills/pm-toolkit/` (Claude Code) ou cole `SKILL.md` na raiz do seu projeto (Cursor / Codex)
3. Digite o que você quer — o Claude pega a skill automaticamente

## Teste se funciona

Cole isto: "Transforme isto num PRD: clientes querem salvar views filtradas no nosso dashboard. Ouvimos em 6 calls e 12 tickets em 8 semanas. Fase 1 é só pessoal; team-shared é Fase 2."

Se você receber de volta um doc com uma seção Problem, uma lista explícita de Non-goals, success metrics com números e uma seção Open Questions — e não usou a palavra "alavancar" — o kit está carregado certo.
