# Quick Start — PM Toolkit

Vous serez opérationnel en moins d'une minute. Choisissez votre IA.

## ChatGPT, Claude (web) ou Gemini

1. Ouvrez l'outil
2. Collez le contenu de `optimization-pack.md` dans le system prompt / custom instructions / champ de connaissance du project
3. Commencez à lui demander de rédiger un PRD, mettre à jour une roadmap ou compresser un update stakeholders

## Claude Code, Cursor ou Codex (chemin SKILL.md)

1. Ouvrez le Terminal (ou votre éditeur de code)
2. Déposez le dossier du kit dans `~/.claude/skills/pm-toolkit/` (Claude Code) ou collez `SKILL.md` à la racine de votre projet (Cursor / Codex)
3. Tapez ce que vous voulez — Claude récupère le skill automatiquement

## Vérifier que ça marche

Collez ceci : « Transforme ça en PRD : les clients veulent sauvegarder des vues filtrées dans notre dashboard. On l'a entendu dans 6 appels et 12 tickets sur 8 semaines. Phase 1 c'est personnel-seulement ; team-shared c'est Phase 2. »

Si vous récupérez un doc avec une section Problème, une liste Non-objectifs explicite, des métriques de succès avec chiffres et une section Questions ouvertes — et qu'il n'a pas utilisé le mot « leverage » — le kit est chargé correctement.
