# Quick Start — PM Toolkit

आप एक minute से कम में running होंगे। अपना AI चुनें।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. एक PRD draft करने, एक roadmap update करने, या एक stakeholder update compress करने को कहें

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/pm-toolkit/` (Claude Code) में drop करें या `SKILL.md` को अपने project root पर paste करें (Cursor / Codex)
3. जो चाहें type करें — Claude automatically skill pick करता है

## Test करें कि काम कर रहा है

यह paste करें: "इसे एक PRD में बदलें: customers हमारे dashboard में filtered views save करना चाहते हैं। हमने 8 हफ्तों में 6 calls और 12 tickets में सुना है। Phase 1 personal-only है; team-shared Phase 2 है।"

अगर आपको एक doc वापस मिले जिसमें एक Problem section, एक explicit Non-goals list, numbers के साथ success metrics, और एक Open Questions section है — और जिसमें word "leverage" use न हुआ — kit right loaded है।
