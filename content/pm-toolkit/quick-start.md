# Quick Start — PM Toolkit

You'll be running in under a minute. Pick your AI.

## ChatGPT, Claude (web), or Gemini

1. Open the tool
2. Paste the contents of `optimization-pack.md` into the system prompt / custom instructions / project knowledge field
3. Start asking it to draft a PRD, update a roadmap, or compress a stakeholder update

## Claude Code, Cursor, or Codex (SKILL.md path)

1. Open Terminal (or your code editor)
2. Drop the kit folder into `~/.claude/skills/pm-toolkit/` (Claude Code) or paste `SKILL.md` at your project root (Cursor / Codex)
3. Type what you want — Claude picks up the skill automatically

## Test it works

Paste this: "Turn this into a PRD: customers want to save filtered views in our dashboard. We've heard it in 6 calls and 12 tickets over 8 weeks. Phase 1 is personal-only; team-shared is Phase 2."

If you get back a doc with a Problem section, an explicit Non-goals list, success metrics with numbers, and an Open Questions section — and it didn't use the word "leverage" — the kit is loaded right.
