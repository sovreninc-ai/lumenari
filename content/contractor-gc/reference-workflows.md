## 1. Bid letter + scope of work (residential reno)

```
PROPOSAL — 142 Cedar Crescent, Kitchen + Main Bath Remodel
Acme Construction | Date: 2026-05-15 | Valid 30 days

Bid price: $96,400 CAD
Payment schedule:
- 15% deposit at contract signing ($14,460)
- 25% at demo complete ($24,100)
- 25% at rough-in inspections passed ($24,100)
- 25% at substantial completion ($24,100)
- 10% holdback released 45 days after substantial completion per Alberta Builders' Lien Act ($9,640)

SCOPE OF WORK — INCLUDED
Kitchen:
- Demo existing cabinets, counters, flooring (to subfloor), backsplash
- Reframe and relocate cased opening on north wall to widen by 18"
- Supply and install owner-selected cabinets (allowance $14,000)
- Supply and install quartz counters, 3cm, eased edge (allowance $4,500)
- New electrical: 2x dedicated 20A appliance circuits, undercabinet LED, 4x recessed lights on dimmer
- Plumbing rough-in for new island sink location, supply lines and drain
- Supply and install owner-selected backsplash tile (allowance $800)
- Engineered hardwood, install only (flooring supplied by owner)
- Paint walls, ceiling, trim — two coats Benjamin Moore Regal Select

Main Bath:
- Demo to studs (tub, surround, vanity, flooring, toilet)
- New 60" tub-shower combo, Kohler Archer or equivalent
- New vanity (allowance $1,800), undermount sink, single-handle faucet
- Porcelain tile floor, install only (tile supplied by owner)
- Subway tile tub surround to 72", install only
- New 50CFM bath fan, vented to exterior
- Paint walls, ceiling, trim

EXCLUDED — NOT IN THIS PRICE
- Asbestos, lead paint, or mold abatement if discovered (priced as CO)
- Knob-and-tube or aluminum wiring replacement beyond 10 LF
- Hidden structural issues uncovered during demo
- Service panel upgrade (we'll assess at rough-in)
- Permits and permit fees (estimated $850, billed at cost)
- Appliances (supplied by owner)
- Window coverings, hardware, accessories

ASSUMPTIONS
- Site access weekdays 7 AM – 6 PM, Saturdays 9-5
- Owner makes all selections (cabinets, counters, tile, fixtures) by 2026-06-01 or schedule slips day-for-day
- Existing electrical service (200A) is adequate; if upgrade needed it's a CO
- Floor framing under bath is sound; if not, joist sistering is a CO

CONDITIONS
- Change orders signed before work proceeds
- Progress invoices due within 14 days; 1.5%/month on overdue balances
- 10% holdback per Alberta Builders' Lien Act
- Warranty: 1 year on labor, manufacturer warranty on materials
- Acme Construction carries $5M CGL and is in good standing with WCB Alberta

Target start: 2026-06-15 | Target substantial completion: 2026-08-08

Signed (Owner): ____________________  Date: __________
Signed (Acme): ____________________   Date: __________
```

## 2. Change order — field condition (knob-and-tube)

```
CHANGE ORDER #003 — 142 Cedar Crescent — 2026-06-22

What changed:
During soffit demo above the upper cabinets, we found knob-and-tube wiring running across about 12 linear feet, plus an open junction box buried in blown-in insulation. Original scope assumed modern wiring throughout the kitchen ceiling. K&T can't legally remain in service after we close drywall back in, and the buried J-box is a code violation we'd be re-burying.

What we're doing:
Disconnect K&T at both ends, remove it where accessible, run new 14/2 NMD90 in its place. Pull the buried J-box, relocate to an accessible spot in the basement ceiling, install new cover. Sub: Northstar Electric (your file).

Cost:
Materials (wire, box, cover, connectors): $185
Sub labor (Northstar): $690 (6 hrs @ $115)
OH&P (18% per contract): $158
TOTAL: $1,033 CAD

Schedule:
Adds 1 day. New substantial completion target: 2026-08-09 (was 08-08).

Authorization:
Please sign and return before electrical proceeds. If you'd rather we keep moving, verbal go-ahead by text works — I just need this signed within 48 hours so the file is clean.

Signed: ______________________  Date: __________
```
