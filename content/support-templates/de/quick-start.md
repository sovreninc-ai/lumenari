# Quick Start — Customer Support Templates

Sie sind in unter einer Minute startklar.

## ChatGPT, Claude (Web) oder Gemini

1. Öffnen Sie das Tool
2. Fügen Sie den Inhalt von `optimization-pack.md` in das System-Prompt- / Custom-Instructions- / Project-Knowledge-Feld ein
3. Beginnen Sie, es zu bitten, Refund-Antworten, Eskalations-Acknowledgments, Lost-Order-Replies oder NPS-Detractor-Outreach zu draften — in Formal-, Friendly- oder Warm-Tonalität

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Öffnen Sie das Terminal (oder Ihren Code-Editor)
2. Legen Sie den Kit-Ordner in `~/.claude/skills/support-templates/` (Claude Code) ab oder fügen Sie `SKILL.md` in Ihrem Projekt-Root ein (Cursor / Codex)
3. Tippen Sie, was Sie wollen — Claude greift den Skill automatisch auf

## Testen, ob es funktioniert

Fügen Sie ein: "Schreibe eine Denied-Refund-Antwort in Warm-Tonalität. Customer hat einen Annual-Plan vor 47 Tagen gekauft, unser Window ist 30 Tage, er will einen vollen Refund. Biete 3 Alternativen an."

Wenn Sie eine Antwort zurückbekommen, die:
- Im ersten Absatz Nein sagt
- Keine Policy-Klausel zitiert
- Drei konkrete Alternativen anbietet (Pause, Monthly-Downgrade, Setup-Call, Account-Credit — diese Art von Sachen)
- Mit einem Ask und einem echten Namen endet
- Die Wörter "sincerely apologize for any inconvenience" nicht enthält

— ist das Kit korrekt geladen.
