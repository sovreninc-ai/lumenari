# Quick Start — Customer Support Templates

आप एक minute से कम में running होंगे।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. Refund responses, escalation acknowledgements, lost-order replies, या NPS detractor outreach draft करने को कहें — formal, friendly, या warm tone में

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/support-templates/` (Claude Code) में drop करें या `SKILL.md` को अपने project root पर paste करें (Cursor / Codex)
3. जो चाहें type करें — Claude automatically skill pick करता है

## Test करें कि काम कर रहा है

यह paste करें: "Warm tone में एक denied refund response लिखें। Customer ने 47 दिनों पहले एक annual plan खरीदा, हमारी window 30 days है, वे एक full refund चाहते हैं। 3 alternatives offer करें।"

अगर आपको एक reply वापस मिले जो:
- पहले paragraph में no कहती है
- एक policy clause quote नहीं करती
- तीन concrete alternatives offer करती है (pause, monthly downgrade, setup call, account credit — उस तरह की चीज़)
- एक ask और एक real name के साथ end होती है
- "sincerely apologize for any inconvenience" words contain नहीं करती

— kit right loaded है।
