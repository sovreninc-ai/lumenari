## 2. Debt payoff comparison — avalanche vs snowball

**The principle:** show both methods side-by-side. Don't declare one right.

### Your debts

| # | Type | Balance | APR | Min payment |
|---|---|---|---|---|
| 1 | | $______ | ____% | $______ |
| 2 | | $______ | ____% | $______ |
| 3 | | $______ | ____% | $______ |
| 4 | | $______ | ____% | $______ |
| **Totals** | | $______ | | $______ |

### What you can throw at debt monthly (above minimums)

$______ extra each month.

### Avalanche method

Order debts highest APR to lowest. Pay minimums on all. Throw the extra at the top of the list.

| Order | Debt | Months to clear | Interest paid on this debt |
|---|---|---|---|
| 1st target | ____ (highest APR) | ___ | $______ |
| 2nd target | ____ | ___ | $______ |
| 3rd target | ____ | ___ | $______ |
| 4th target | ____ | ___ | $______ |
| **Total** | | ___ months | $______ |

### Snowball method

Order debts smallest balance to largest. Pay minimums on all. Throw the extra at the top of the list.

| Order | Debt | Months to clear | Interest paid on this debt |
|---|---|---|---|
| 1st target | ____ (smallest balance) | ___ | $______ |
| 2nd target | ____ | ___ | $______ |
| 3rd target | ____ | ___ | $______ |
| 4th target | ____ | ___ | $______ |
| **Total** | | ___ months | $______ |

### The tradeoff

**Avalanche saves you:** $______ in interest over snowball.
**Snowball gets you to first-debt-cleared:** ___ months earlier than avalanche.

### The question

Which one will you actually stick to?

- If you need momentum (paying off the first debt fully and feeling that win) to keep going, snowball.
- If you can stay disciplined without that win, avalanche.
- If you're not sure, snowball for the first 1-2 debts to build momentum, then switch to avalanche.

The kit doesn't tell you which to pick. The right one is the one you'll do.

### Not in scope for this template (talk to a Licensed Insolvency Trustee in Canada, or a bankruptcy attorney in the US)

- Consumer proposal
- Bankruptcy
- Debt consolidation loan terms
- Negotiating with creditors directly

**The principle:** named, dollar amount, target date. Automatic transfer. Separate from spending account.

### Goal 2 (fund alongside or next)

- Name: ____________________
- Target: $______
- Current: $______
- Gap: $______
- Date: ____________ (months: ___)
- Monthly: $______
- Where: ____________
- Automation: ____________

### Goal 3 (fund with leftover)

[Same structure]

### The hierarchy question

Are these in priority order? If money gets tight, which goes first? The decision is easier now than in the moment.

### Common goal hierarchies (one possible order; not advice)

1. Starter emergency fund ($1,000-$2,000) — fund this FIRST
2. Employer retirement match (if applicable) — never leave free money on the table
3. High-interest debt payoff (over 7-8%)
4. Full emergency fund (3-6 months expenses)
5. Other named goals
6. Long-term investing (this is where you talk to a fee-only CFP)

This is one common ordering. Yours may differ. For investment-strategy decisions and retirement timing, talk to a fee-only CFP.

## 4. Monthly money check-in checklist

The 20-minute review. Once a month. Calendar reminder helps.

### Step 1: Reconcile (5 min)

- [ ] Open last month's actual spending (your bank/credit card app, or spreadsheet)
- [ ] Compare to budgeted amounts category by category
- [ ] Note which categories were over and which were under

### Step 2: Notice (3 min)

- [ ] Biggest overage this month: ___________ ($______ over)
- [ ] Biggest underage: ___________ ($______ under)
- [ ] Anything surprising: ___________

### Step 3: Update next month (3 min)

- [ ] Does any category need to be adjusted up or down for next month?
- [ ] Is there an irregular expense coming next month I need to plan for?
- [ ] Has any fixed expense changed (rent increase, insurance renewal, subscription price)?

### Step 4: Goal check (3 min)

- [ ] Did the automatic transfers happen?
- [ ] Are goal balances on track for target dates?
- [ ] Any goal that needs the transfer amount adjusted?

### Step 5: Debt check (3 min)

- [ ] Are debt balances dropping?
- [ ] Any debt minimum that changed (often credit card minimums shift slightly)?
- [ ] Anything I can throw extra at this month?

### Step 6: One question (3 min)

- [ ] Any subscription, recurring charge, or expense category I want to cancel or reduce?
- [ ] Pick ONE thing. Cancel it or reduce it today.

### Done.

Don't try to optimize everything every month. One thing. Compound that across 12 months.
