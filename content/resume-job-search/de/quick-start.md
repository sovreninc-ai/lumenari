# Quick Start — Resume + Job Search Pack

Du läufst in weniger als einer Minute. Wähle deine KI.

## ChatGPT, Claude (Web) oder Gemini

1. Tool öffnen
2. Inhalt von `optimization-pack.md` in das System-Prompt-/Custom-Instructions-/Project-Knowledge-Feld einfügen
3. Frag es, ein Lebenslauf-Bullet zuzuschneiden, ein Anschreiben zu entwerfen oder eine STAR-Antwort zu prepen

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Terminal (oder Code-Editor) öffnen
2. Den Kit-Ordner in `~/.claude/skills/resume-job-search/` (Claude Code) ablegen oder `SKILL.md` an deinem Projekt-Root einfügen (Cursor / Codex)
3. Tippe, was du willst — Claude greift den Skill automatisch auf

## Funktionstest

Füge das ein: „Schneide dieses Bullet auf eine JD zu, die nach Payments + Stripe-Erfahrung fragt: 'An Performance-Verbesserungen für die Plattform gearbeitet.'"

Wenn du ein umgeschriebenes Bullet zurückbekommst, das Stripe erwähnt, ein spezifisches Outcome liefert und das Wort „passionate" nicht enthält, ist das Kit richtig geladen.
