# Inicio rápido — Resume + Job Search Pack

Vas a estar corriendo en menos de un minuto. Elige tu IA.

## ChatGPT, Claude (web) o Gemini

1. Abre la herramienta
2. Pega el contenido de `optimization-pack.md` en el campo de system prompt / custom instructions / project knowledge
3. Empieza pidiéndole que tailoree un bullet de résumé, redacte una cover letter o prep una respuesta STAR

## Claude Code, Cursor o Codex (camino SKILL.md)

1. Abre Terminal (o tu editor de código)
2. Suelta la carpeta del kit en `~/.claude/skills/resume-job-search/` (Claude Code) o pega `SKILL.md` en la raíz de tu proyecto (Cursor / Codex)
3. Escribe lo que quieras — Claude levanta el skill automáticamente

## Prueba que funciona

Pega esto: "Tailorea este bullet a una JD pidiendo experiencia en payments + Stripe: 'Trabajé en mejoras de rendimiento para la plataforma.'"

Si recibes un bullet reescrito que menciona Stripe, da un outcome específico y no incluye la palabra "apasionado", el kit está bien cargado.
