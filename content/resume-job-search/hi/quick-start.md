# Quick Start — Resume + Job Search Pack

आप एक मिनट से कम में running होंगे। अपना AI चुनें।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. एक résumé bullet tailor करने, एक cover letter draft करने, या एक STAR answer prep करने को कहें

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/resume-job-search/` (Claude Code) में drop करें या `SKILL.md` को अपने project root पर paste करें (Cursor / Codex)
3. जो चाहें type करें — Claude automatically skill pick करता है

## Test करें कि काम कर रहा है

यह paste करें: "इस bullet को payments + Stripe experience के लिए पूछ रहे एक JD पर tailor करें: 'Worked on performance improvements for the platform.'"

अगर आपको एक rewritten bullet मिले जो Stripe mention करता है, एक specific outcome देता है, और "passionate" word include नहीं करता, kit right loaded है।
