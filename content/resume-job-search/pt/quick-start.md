# Quick Start — Pack de Currículo + Busca de Emprego

Você vai estar rodando em menos de um minuto. Escolha sua IA.

## ChatGPT, Claude (web) ou Gemini

1. Abra a ferramenta
2. Cole o conteúdo de `optimization-pack.md` no campo de system prompt / custom instructions / project knowledge
3. Comece pedindo para customizar um bullet do currículo, fazer um draft de cover letter ou preparar uma resposta STAR

## Claude Code, Cursor ou Codex (caminho do SKILL.md)

1. Abra o Terminal (ou seu editor de código)
2. Jogue a pasta do kit em `~/.claude/skills/resume-job-search/` (Claude Code) ou cole `SKILL.md` na raiz do seu projeto (Cursor / Codex)
3. Digite o que você quer — o Claude pega a skill automaticamente

## Teste se funciona

Cole isto: "Customize este bullet para uma JD pedindo experiência em payments + Stripe: 'Trabalhei em melhorias de performance para a plataforma.'"

Se você receber de volta um bullet reescrito que menciona Stripe, dá um resultado específico e não inclui a palavra "apaixonado", o kit está carregado certo.
