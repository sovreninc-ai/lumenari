# Quick Start — Pack CV + Job Search

Vous serez opérationnel en moins d'une minute. Choisissez votre IA.

## ChatGPT, Claude (web) ou Gemini

1. Ouvrez l'outil
2. Collez le contenu de `optimization-pack.md` dans le system prompt / custom instructions / champ de connaissance du project
3. Commencez à lui demander de tailler une puce de CV, rédiger une lettre de motivation ou préparer une réponse STAR

## Claude Code, Cursor ou Codex (chemin SKILL.md)

1. Ouvrez le Terminal (ou votre éditeur de code)
2. Déposez le dossier du kit dans `~/.claude/skills/resume-job-search/` (Claude Code) ou collez `SKILL.md` à la racine de votre projet (Cursor / Codex)
3. Tapez ce que vous voulez — Claude récupère le skill automatiquement

## Vérifier que ça marche

Collez ceci : « Taille cette puce à un JD qui demande de l'expérience payments + Stripe : "Worked on performance improvements for the platform." »

Si vous récupérez une puce réécrite qui mentionne Stripe, donne un outcome spécifique et n'inclut pas le mot « passionate », le kit est chargé correctement.
