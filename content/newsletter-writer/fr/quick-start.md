# Quick Start — Newsletter Writer

Vous serez opérationnel en moins d'une minute. Choisissez votre IA.

## ChatGPT, Claude (web) ou Gemini

1. Ouvrez l'outil
2. Collez le contenu de `optimization-pack.md` dans le system prompt / custom instructions / champ de connaissance du project
3. Commencez à lui demander d'outliner une issue, générer des variantes de ligne de sujet ou réécrire vos deux premières lignes

## Claude Code, Cursor ou Codex (chemin SKILL.md)

1. Ouvrez le Terminal (ou votre éditeur de code)
2. Déposez le dossier du kit dans `~/.claude/skills/newsletter-writer/` (Claude Code) ou collez `SKILL.md` à la racine de votre projet (Cursor / Codex)
3. Tapez ce que vous voulez — Claude récupère le skill automatiquement

## Vérifier que ça marche

Collez ceci : « Donne-moi 5 variantes de ligne de sujet pour une issue intitulée "comment trouver vos 100 premiers lecteurs". Ma liste fait 1 400, 48 % d'ouvertures saines. »

Si vous récupérez cinq variantes, chacune labellisée avec un pattern (nombre / contraire / curiosité / identité / urgence), chacune avec un call d'ouverture prédite et un flag de risque — et que les variantes n'incluent pas la phrase « vous n'allez pas croire » — le kit est chargé correctement.
