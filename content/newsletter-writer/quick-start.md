# Quick Start — Newsletter Writer

You'll be running in under a minute. Pick your AI.

## ChatGPT, Claude (web), or Gemini

1. Open the tool
2. Paste the contents of `optimization-pack.md` into the system prompt / custom instructions / project knowledge field
3. Start asking it to outline an issue, generate subject-line variants, or rewrite your first two lines

## Claude Code, Cursor, or Codex (SKILL.md path)

1. Open Terminal (or your code editor)
2. Drop the kit folder into `~/.claude/skills/newsletter-writer/` (Claude Code) or paste `SKILL.md` at your project root (Cursor / Codex)
3. Type what you want — Claude picks up the skill automatically

## Test it works

Paste this: "Give me 5 subject-line variants for an issue titled 'how to find your first 100 readers.' My list is 1,400, healthy 48% opens."

If you get back five variants, each labeled with a pattern (number / contrarian / curiosity / identity / urgency), each with a predicted-open call and a risk flag — and the variants don't include the phrase "you won't believe" — the kit is loaded right.
