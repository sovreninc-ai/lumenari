# Quick Start — Newsletter Writer

आप एक minute से कम में running होंगे। अपना AI चुनें।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. एक issue outline करने, subject-line variants generate करने, या अपनी first two lines rewrite करने को कहें

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/newsletter-writer/` (Claude Code) में drop करें या `SKILL.md` को अपने project root पर paste करें (Cursor / Codex)
3. जो चाहें type करें — Claude automatically skill pick करता है

## Test करें कि काम कर रहा है

यह paste करें: "एक issue 'how to find your first 100 readers' के लिए मुझे 5 subject-line variants दें। मेरी list 1,400 है, healthy 48% opens।"

अगर आपको पाँच variants मिलें, हर एक एक pattern (number / contrarian / curiosity / identity / urgency) से labeled, हर एक एक predicted-open call और एक risk flag के साथ — और variants में phrase "you won't believe" शामिल न हो — kit right loaded है।
