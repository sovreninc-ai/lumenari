# Quick Start — Newsletter Writer

Sie sind in unter einer Minute startklar. Wählen Sie Ihre KI.

## ChatGPT, Claude (Web) oder Gemini

1. Öffnen Sie das Tool
2. Fügen Sie den Inhalt von `optimization-pack.md` in das System-Prompt- / Custom-Instructions- / Project-Knowledge-Feld ein
3. Beginnen Sie, es zu bitten, eine Ausgabe zu outlinen, Subject-Line-Varianten zu generieren oder Ihre ersten zwei Zeilen umzuschreiben

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Öffnen Sie das Terminal (oder Ihren Code-Editor)
2. Legen Sie den Kit-Ordner in `~/.claude/skills/newsletter-writer/` (Claude Code) ab oder fügen Sie `SKILL.md` in Ihrem Projekt-Root ein (Cursor / Codex)
3. Tippen Sie, was Sie wollen — Claude greift den Skill automatisch auf

## Testen, ob es funktioniert

Fügen Sie ein: "Gib mir 5 Subject-Line-Varianten für eine Ausgabe mit dem Titel 'how to find your first 100 readers.' Meine Liste ist 1.400, gesunde 48% Opens."

Wenn Sie fünf Varianten zurückbekommen, jede mit einem Pattern beschriftet (Number / Contrarian / Curiosity / Identity / Urgency), jede mit einem Predicted-Open-Call und einem Risk-Flag — und die Varianten nicht die Phrase "you won't believe" enthalten — ist das Kit korrekt geladen.
