# Inicio rápido — Newsletter Writer

Vas a estar corriendo en menos de un minuto. Elige tu IA.

## ChatGPT, Claude (web) o Gemini

1. Abre la herramienta
2. Pega el contenido de `optimization-pack.md` en el campo de system prompt / custom instructions / project knowledge
3. Empieza pidiéndole que haga outline de un issue, genere variantes de subject-line o reescriba tus primeras dos líneas

## Claude Code, Cursor o Codex (camino SKILL.md)

1. Abre Terminal (o tu editor de código)
2. Suelta la carpeta del kit en `~/.claude/skills/newsletter-writer/` (Claude Code) o pega `SKILL.md` en la raíz de tu proyecto (Cursor / Codex)
3. Escribe lo que quieras — Claude levanta el skill automáticamente

## Prueba que funciona

Pega esto: "Dame 5 variantes de subject-line para un issue titulado 'cómo encontrar tus primeros 100 lectores'. Mi lista es de 1,400, saludable 48% aperturas".

Si recibes cinco variantes, cada una etiquetada con un patrón (número / contrarian / curiosidad / identidad / urgencia), cada una con una predicción de apertura y un flag de riesgo — y las variantes no incluyen la frase "no vas a creer" — el kit está bien cargado.
