# Início Rápido — Newsletter Writer

Você vai estar rodando em menos de um minuto. Escolha sua IA.

## ChatGPT, Claude (web) ou Gemini

1. Abra a ferramenta
2. Cole o conteúdo de `optimization-pack.md` no campo de system prompt / instruções personalizadas / project knowledge
3. Comece pedindo para fazer outline de uma edição, gerar variantes de subject line ou reescrever suas duas primeiras linhas

## Claude Code, Cursor ou Codex (caminho do SKILL.md)

1. Abra o Terminal (ou seu editor de código)
2. Coloque a pasta do kit em `~/.claude/skills/newsletter-writer/` (Claude Code) ou cole o `SKILL.md` na raiz do seu projeto (Cursor / Codex)
3. Digite o que você quer — o Claude pega a skill automaticamente

## Teste se está funcionando

Cole isto: "Me dá 5 variantes de subject line para uma edição com o título 'como encontrar seus primeiros 100 leitores.' Minha lista tem 1.400 inscritos, 48% de abertura saudável."

Se você receber de volta cinco variantes, cada uma rotulada com um padrão (número / contrarian / curiosidade / identidade / urgência), cada uma com uma previsão de abertura e um sinalizador de risco — e as variantes não incluírem a frase "você não vai acreditar" — o kit está carregado certo.
