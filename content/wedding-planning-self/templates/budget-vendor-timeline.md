# Budget, Vendor Outreach, and Timeline Templates

Three working docs in one file. Copy what you need into your own notes.

---

## 1. Budget allocation template

**Step 1: Confirm the basics**

- Total budget: $______ (CAD / USD)
- Who's contributing: ____________
- Guest count target: ______
- Date or season: ______

**Step 2: Rank what you care about**

Order these from "this matters most" to "I don't really care." Skip anything that's not happening.

- Photo / video
- Food and drink
- Venue
- Music / band / DJ
- Florals / decor
- Attire / hair / makeup
- Cake / dessert
- Stationery / invites
- Transportation
- Officiant
- Rentals (tents, chairs, etc.)

**Step 3: Allocate by percentage first**

Start from these ranges. Then re-weight based on your ranking. Things you ranked highest get more; things you ranked lowest get cut close to zero.

| Category | Standard range | Your % | Your $ |
|---|---|---|---|
| Venue + rentals | 25-35% | | |
| Food + beverage | 25-35% | | |
| Photo + video | 10-15% | | |
| Attire + hair/makeup | 5-10% | | |
| Music | 5-10% | | |
| Florals + decor | 5-10% | | |
| Misc (cake, officiant, stationery, transport) | 5-10% | | |
| **Buffer** | **5-10%** | | |

**Step 4: The buffer line is non-negotiable**

Wedding costs creep. A $30,000 wedding without a buffer becomes a $33,500 wedding with $3,500 on a credit card. A $30,000 wedding with a $2,000 buffer becomes a $32,000 wedding, paid for.

**Step 5: Pre-decide what to cut if you go over**

Write down — before you start booking — what you'll cut first if you're tracking $2,000 over by month 6. Examples:
- Drop the videographer (or replace with a friend)
- Buffet instead of plated
- Cut welcome bags / favors
- DJ instead of band
- Self-print invitations
- Skip the day-after brunch

When you go over (you will), you don't have to negotiate with yourself in the moment — the decision is already made.

## 2. Vendor outreach email template

Paste, fill in the brackets, send. Adjust for the specific vendor type — same skeleton works for photo, catering, florals, music, venue inquiry.

**Subject:** [Date] inquiry — [service type] for [first names]

Hi [Vendor name or "team"],

We're planning our wedding on **[date]** in **[city / neighborhood]**, with approximately **[guest count]** guests. We're reaching out about your **[service: photography / catering / florals / music / etc.]** packages.

A few specifics:

- **Date:** [date], [start time]
- **Venue:** [venue name, if booked, or "still finalizing"]
- **Hours needed:** [approximate hours, e.g., "8 hours of coverage" or "ceremony + reception, ~6 hours"]
- **What we're looking for:** [1-2 sentences — your style, what matters to you]

Before we go further, could you confirm:

1. **Are you available on our date?** If yes, what's the **total all-in cost**, including any taxes and gratuity?
2. **What's not included in your base package?** (Travel fees, overtime, second shooter, delivery, cleanup, etc. — we'd rather know up front than be surprised later.)
3. **What's your cancellation and rescheduling policy?** Deposit refund window, postponement terms, what happens if you're sick or unavailable on the date.

If you have a brochure or sample contract, we'd love to see it. Happy to set up a 15-20 minute call if you'd prefer to walk through it live.

Thanks so much,
[Your name]
[Phone]

---

**Why the three asks:**
1. "Starting at $X" is not a real number. The all-in number is what goes in your budget.
2. The "not included" list is where the budget creep lives. Travel + overtime alone can be $800-$2,000.
3. Cancellation policy matters because vendors get sick, weddings get postponed (COVID taught everyone), and deposits are usually non-refundable.

## 3. Timeline templates

### 12-month timeline (for couples 9-18 months out)

**Months 12-10: Decisions**
- [ ] Pick the date (or 2-3 candidate dates)
- [ ] Set the total budget and confirm who's contributing
- [ ] Pick the city / region
- [ ] Draft guest list count (not names yet — just a number for venue sizing)
- [ ] Tour and book the venue
- [ ] Decide on the vibe in 3 words

**Months 9-7: Major vendors**
- [ ] Book photographer
- [ ] Book caterer (or confirm venue catering)
- [ ] Book music (band or DJ)
- [ ] Book officiant
- [ ] Decide on dress / suit / attire approach
- [ ] Send save-the-dates (6-9 months out)

**Months 6-4: Details**
- [ ] Book florist / decor
- [ ] Book hair and makeup
- [ ] Order attire (dress alterations take time)
- [ ] Book rentals (tents, chairs, dance floor)
- [ ] Build full guest list with addresses
- [ ] Design invitations
- [ ] Plan ceremony content / readings / music

**Months 3-1: Logistics**
- [ ] Send invitations (8-10 weeks out)
- [ ] Track RSVPs
- [ ] Final menu / tasting
- [ ] Get marriage license (within license window — usually 30-90 days before)
- [ ] Final headcount to caterer
- [ ] Day-of timeline drafted and shared with vendors
- [ ] Day-of coordinator confirmed (if hired)
- [ ] Pay final balances

**Final week:**
- [ ] Confirm all vendors with a one-line "see you [date], [time], [address]" message
- [ ] Pack day-of emergency kit
- [ ] Designate someone to hold the rings, the marriage license, and the phone

### 6-month timeline (for couples 4-8 months out)

If you're 4-8 months out, compress the above into monthly milestones:

- **Month 6:** Venue + date + total budget + guest count + photographer + caterer
- **Month 5:** Music + officiant + attire + save-the-dates (or skip if too late)
- **Month 4:** Florals + hair/makeup + rentals + full guest list + invitations
- **Month 3:** Send invitations + book day-of coordinator (highly recommended at this pace)
- **Month 2:** Track RSVPs, marriage license window, final menu
- **Month 1:** Final headcount, day-of timeline, vendor confirmations, pay balances

If you're under 4 months out, get a day-of coordinator. That's the highest-leverage decision you can make.

### 1-month timeline (the final 30 days)

**Week 4 out:**
- [ ] Final guest count to caterer
- [ ] Marriage license obtained (verify window)
- [ ] Day-of timeline drafted
- [ ] Seating chart drafted
- [ ] Final dress / suit fitting

**Week 3 out:**
- [ ] Day-of timeline shared with vendors
- [ ] Seating chart finalized
- [ ] Vows written (or at least started)
- [ ] Welcome message to out-of-town guests
- [ ] Vendor final balances reviewed

**Week 2 out:**
- [ ] Confirm with every vendor (one-line message)
- [ ] Pick up rings if needed
- [ ] Final hair / makeup trial if scheduled
- [ ] Day-of emergency kit packed (safety pins, stain pen, bandaids, water, snacks, phone charger, breath mints, tape, extra cash for tips)

**Week of:**
- [ ] Rehearsal and dinner
- [ ] Pay outstanding balances
- [ ] Confirm tip envelopes (vendors who get tipped: catering staff, bartenders, hair/makeup, delivery, sometimes officiant)
- [ ] Hand off coordination to coordinator or designated friend
- [ ] Sleep. Eat. Hydrate. Show up.

**Day-of run-of-show (skeleton):**
- Morning: getting ready, photos, first look (if doing one)
- Pre-ceremony: guest arrival window
- Ceremony
- Cocktail hour (photos)
- Reception: dinner, toasts, dances, cake, open dance floor
- Send-off (or quiet exit)

Adjust to your actual day. Most weddings run 4-7 hours of guest-facing time.

## How to use this with the AI

Paste any section into a conversation with the system prompt loaded and say: "Adapt this for my wedding. Here's the context: [your details]." The AI will re-weight, re-time, and re-cut based on what you actually care about.
