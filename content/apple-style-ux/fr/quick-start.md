# Quick Start — Apple-Style UX Pack

Vous serez opérationnel en moins d'une minute.

## ChatGPT, Claude (web) ou Gemini

1. Ouvrez l'outil
2. Collez le contenu de `optimization-pack.md` dans le system prompt / les instructions personnalisées / la project knowledge
3. Commencez à lui demander de critiquer un écran, d'écrire de la microcopie ou de concevoir un flow

## Claude Code, Cursor ou Codex (voie SKILL.md)

1. Ouvrez le Terminal (ou votre éditeur de code)
2. Déposez le dossier du kit dans `~/.claude/skills/apple-style-ux/` (Claude Code) ou collez `SKILL.md` à la racine de votre projet
3. Tapez ce que vous voulez — Claude charge le skill automatiquement

## Vérifier que ça fonctionne

Collez : « Critique cet écran : une page de réglages avec 14 toggles dans une liste plate, trois boutons bleus pleins "Enregistrer" en bas, et le titre dit "Préférences Utilisateur" en Title Case. »

Si vous récupérez une critique qui nomme les règles violées (une action principale, progressive disclosure, sentence case), recommande des coupes avant des redesigns, et propose des sections « Les plus courants » + « Avancé » — le kit est correctement chargé.
