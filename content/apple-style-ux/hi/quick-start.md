# Quick Start — Apple-Style UX Pack

आप एक minute से कम में चल रहे होंगे।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. एक screen critique करने, microcopy लिखने, या एक flow design करने को कहना शुरू करें

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/apple-style-ux/` (Claude Code) में drop करें या अपने project root पर `SKILL.md` paste करें
3. जो चाहिए वो type करें — Claude skill को automatically pick up करता है

## Test करें कि काम कर रहा है

Paste करें: "Critique this screen: a settings page with 14 toggles in a flat list, three filled blue 'Save' buttons at the bottom, and the heading says 'User Preferences' in Title Case."

अगर आपको एक critique वापस मिले जो violated rules (one primary action, progressive disclosure, sentence case) name करता है, redesigns से पहले cuts recommend करता है, और "Most common" + "Advanced" sections propose करता है — kit सही से loaded है।
