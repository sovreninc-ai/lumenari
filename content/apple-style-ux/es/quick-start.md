# Quick Start — Pack de UX Estilo Apple

Vas a estar corriendo en menos de un minuto.

## ChatGPT, Claude (web) o Gemini

1. Abre la herramienta
2. Pega el contenido de `optimization-pack.md` en el campo de system prompt / custom instructions / project knowledge
3. Empieza a pedirle que critique una pantalla, escriba microcopy o diseñe un flujo

## Claude Code, Cursor o Codex (ruta SKILL.md)

1. Abre Terminal (o tu editor de código)
2. Coloca la carpeta del kit en `~/.claude/skills/apple-style-ux/` (Claude Code) o pega `SKILL.md` en la raíz de tu proyecto
3. Escribe lo que quieras — Claude toma el skill automáticamente

## Probar que funciona

Pega: "Critica esta pantalla: una página de settings con 14 toggles en una lista plana, tres botones azules rellenos de 'Save' al fondo, y el heading dice 'User Preferences' en Title Case."

Si te devuelve una crítica que nombra las reglas violadas (una acción primaria, progressive disclosure, sentence case), recomienda cortes antes que rediseños y propone secciones "Más comunes" + "Avanzado" — el kit está cargado correctamente.
