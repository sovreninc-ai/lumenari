# 妥当なデフォルトのチェックリスト

ルール: 答えが本当に重要で、推測できない場合にのみユーザーに聞く。

## 黙って適用するデフォルト

| 判断 | 妥当なデフォルト |
|---|---|
| 通貨 | ユーザーの IP 検出国、ワンタップ切替付き |
| 言語 | ブラウザの `Accept-Language` ヘッダ、設定で切替 |
| タイムゾーン | ブラウザ検出、表示はするが割り込まない |
| 日付形式 | ロケールに合うもの（ja-JP → YYYY-MM-DD；en-US → MM/DD/YYYY） |
| 初回オンボーディング | ウェルカムカルーセルは飛ばす。空状態に直接着地。 |
| メール頻度 | トランザクショナル + 月次プロダクトアップデート、登録解除リンク付き |
| テーマ | `prefers-color-scheme: dark` に合わせる |
| 通知 | ユーザーが何か通知が役立つことをするまでオフ |
| 自動保存 | オン |
| 破壊的アクションの確認 | オン（ダイアログそのものが摩擦） |
| 保存形式 | 開いた形式（PDF は PDF のまま、.md は .md のまま） |
| ソート順 | 最新順 |
| ページネーション | 1 ページ 20 件 |

UI に「〜してもよろしいですか?」を追加していると気づいたら、自問する: ただやって Undo を提供できないか?

## ユーザーに聞くべきとき

聞くべきは:

1. **アクションが破壊的で簡単に元に戻せない。** アカウント削除、履歴のパージ。
2. **アクションが実際にお金がかかる。** セッション予約、決済処理。
3. **選択がその後の挙動に意味のある影響を与える。** ワークスペース名の選択、最初に始めるチームの選択。
4. **本当に推測できない。** ファーストネーム。役職。プロダクトを使う理由。

画面ごとに 1 つだけ聞く。5 つの質問を 1 つのフォームに束ねない。

## うまく聞く方法

```
[ 見出しでもある 1 文の質問 ]

[ 本文 — 質問にコンテキストが必要な場合のみ ]

[ 選択面 — チップグループ、ラジオ、テキストフィールド ]

[ 続行ボタン — 選択がされるまで無効 ]
```

例:

> **クラブが指導するスポーツは?**
> 正しい年齢区分、ディビジョン、スケジュールデフォルトを設定します。
>
> [ サッカー ] [ ホッケー ] [ バスケットボール ] [ 野球 ] [ その他 ]
>
> [ 続行 → ]

悪い版と比較:

> ☐ 主要スポーツを選択
> ☐ 副次スポーツを選択（任意）
> ☐ 統括団体を選択
> ☐ 典型的なシーズン長を選択
> ☐ 年齢区分を選択（複数選択）
>
> [ 送信 ]

悪い版は、答えの前に 5 つの質問。良い版は 1 つだけ聞いて残りを推測する。

## 最も難しい版

これの最も難しい版は: 「ユーザーの意図が曖昧なとき、この AI は何をすべきか?」

デフォルト: 最も妥当な解釈を選び、それを実行し、何をしたかをユーザーに伝える。解釈の切替を提供する。

```
2026 年春シーズン（アクティブなもの）を意味すると仮定しました。
別のシーズンを意図していた場合は、ここで変更できます。
```

Apple の「もしかして…?」の表面はこの仕組み。ブロックしない、提案する。
