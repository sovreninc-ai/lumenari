## 1. Scope of Work (SOW) template

**Project address:** ________________________________
**Owner:** ________________________________
**Scope finalization date:** ________________________________
**Project type:** Kitchen / Bath / Basement / Addition / Exterior / Other: ____

### Project description (one paragraph, plain English)

Example: "Renovate the main floor kitchen, approximately 180 sqft. Remove existing cabinets and counters. Relocate the gas range from the east wall to the south wall (requires extending gas line and 220V circuit). Install new shaker cabinets, quartz counters, new stainless appliances (owner-supplied), new sink and faucet. Patch and refinish existing hardwood. Repaint walls and ceiling."

### Inclusions (everything this scope covers)

- [ ] Demolition: remove existing cabinets, counters, sink, faucet, dishwasher, range
- [ ] Disposal of demo debris
- [ ] Plumbing rough-in: new sink location, dishwasher hookup
- [ ] Gas line: extend gas line to new range location (licensed gas fitter, permit required)
- [ ] Electrical: relocate 220V range circuit, add 2 outlets on south wall, install under-cabinet LED, install 3 pendant lights over island (permit required)
- [ ] Drywall: patch ceiling and walls as needed
- [ ] Paint: 2 coats walls + ceiling, color TBD by owner
- [ ] Flooring: patch hardwood where stove was relocated, sand + refinish full kitchen floor
- [ ] Cabinet install: new shaker cabinets (contractor-supplied, allowance $12,000)
- [ ] Counter install: quartz (contractor-supplied template + install, allowance $4,500 incl. fab)
- [ ] Backsplash tile install (owner-supplied tile, contractor install + grout)
- [ ] Appliance install: range, dishwasher, range hood (all owner-supplied)
- [ ] Final cleanup, broom clean
- [ ] All required inspections

### Exclusions (NOT in this scope — this prevents disputes)

- [ ] Window replacement
- [ ] Removal of any wall (no walls being removed this scope)
- [ ] Pantry or adjacent dining room work
- [ ] Appliance purchase (owner-supplied)
- [ ] Tile purchase for backsplash (owner-supplied)
- [ ] Cabinet hardware (owner-supplied)
- [ ] Window treatments
- [ ] Any work outside the kitchen footprint

### Owner-supplied vs contractor-supplied

| Item | Supplied by | Notes |
|---|---|---|
| Cabinets | Contractor | Allowance $12,000 |
| Counters | Contractor | Allowance $4,500 |
| Sink | Owner | Stainless under-mount, 32" |
| Faucet | Owner | TBD |
| Backsplash tile | Owner | TBD |
| Appliances | Owner | Range, dishwasher, range hood — make/model in attached spec sheet |
| Cabinet hardware | Owner | TBD |
| Light fixtures | Owner | 3 pendants over island |

### Permits

- Gas: pulled by contractor's licensed gas fitter
- Electrical: pulled by contractor's licensed electrician
- Building (if required): pulled by contractor
- All permit fees paid by: ____ (owner / contractor — confirm)

### Timeline

- Target start: ________________
- Estimated duration: __________ weeks
- Target completion: ________________
- Major milestones: demo complete (week 1), rough-ins complete and inspected (week 2-3), drywall + paint (week 3-4), cabinets installed (week 4-5), counters templated and installed (week 5-6), final fixtures + inspections (week 6-7)

### Quality standards

- All paint: 2 coats over primer where needed, level 4 finish on drywall
- Tile: 1/16" grout lines unless owner specifies otherwise
- Daily cleanup: floors swept, work area broom clean at end of each work day
- Final cleanup: broom clean throughout, no debris, dust contained during work

### Change order procedure

Any modification to this scope after both parties sign requires a written change order (form attached as appendix). No work proceeds on a change order until both parties sign. No exceptions.

### Payment schedule

- Deposit: 15% on signing of contract
- Milestone 1: 25% on completion of rough-ins and passed rough-in inspections
- Milestone 2: 25% on cabinet install complete
- Milestone 3: 25% on counter install complete
- Final: 10% holdback, released 30 days after final inspection passes (Construction Lien Act compliance — see your provincial / state requirements)

### Signatures

Owner: ______________________ Date: __________
Contractor: ______________________ Date: __________

## 2. Contractor outreach email template

Paste, fill in the brackets, send to 2-4 contractors.

**Subject:** Quote request — [project type] at [neighborhood], target start [month]

Hi [contractor name or "team"],

We're planning a **[project type — kitchen / bath / basement / addition]** renovation at our home in **[neighborhood, city]**. We're gathering quotes and would like to include you.

**Project at a glance:**
- Type: [kitchen renovation, no walls removed, stove relocating]
- Size: [approximately 180 sqft]
- Target start: [month]
- Target completion: [month]
- Living in the house during work: [yes / no]

**A draft scope is attached** (or pasted below). It includes inclusions, exclusions, owner-supplied vs contractor-supplied items, and our payment expectations.

Before we move forward, could you confirm or provide the following in writing:

1. **License + insurance:** current trade and business license, liability insurance certificate, and workers comp if you have employees. Policy numbers and certificates appreciated.
2. **References:** 3 recent projects (last 12-18 months), ideally similar in scope, with phone numbers and permission to call.
3. **Timeline + crew:** when could you start, how long do you estimate the work, how many people on site at peak, and which trades you subcontract (and whether those subs are licensed and insured).
4. **Permit handling:** which permits will you pull (electrical, plumbing, gas, building), and who pays the permit fees.
5. **Quote format + payment:** itemized quote (not lump-sum), proposed payment schedule including holdback, and how change orders are handled.

We're looking to make a decision within [3-4 weeks]. Happy to walk the space — we have availability [days/times].

Thanks,
[Your name]
[Phone]

## 3. Change order template

Use one of these every time the scope changes after the contract is signed. No exceptions.

### CHANGE ORDER

**Project:** ______________________________
**Original contract date:** ______________
**CO Number:** CO-________
**Date of this CO:** ______________

### Description of change

(Plain English. What's being added, removed, or modified.)

Example: "Add a pot filler over the range. Includes new water line from existing kitchen supply, valve, pot filler fixture, wall patch and paint to match. Pot filler fixture owner-supplied."

### Cost impact

- Materials: $______
- Labor: $______
- Markup (if applicable): $______
- **Total cost impact:** $______ (increase / decrease — circle)

### Timeline impact

- Additional days: ______
- Revised completion date: ______

### Permit / inspection impact

- New permit required? Y / N
- If yes, who pulls and pays: ______
- Does this change a previously passed inspection? Y / N
- If yes, re-inspection needed: ______

### Payment

- This change order is invoiced: with next milestone / on completion / separately (circle)

### Signatures

Owner: ______________________ Date: __________
Contractor: ______________________ Date: __________

**No work begins on this change order until both signatures are in place.**
