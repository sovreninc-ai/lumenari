# Quick Start — Setup en 60 secondes

Trois paragraphes, un par plateforme. Choisissez le vôtre, collez, testez.

---

## Claude (claude.ai ou Claude dans l'API)

Créez un nouveau Project dans Claude (barre latérale gauche, « Projects » → « New Project »). Nommez-le « Solopreneur Co-Pilot ». Dans le champ **Instructions** du Project, collez l'intégralité du contenu de `optimization-pack.md`. Sauvegardez. Chaque chat que vous démarrez à l'intérieur de ce Project tourne maintenant en mode solopreneur. Pour un usage one-off sans Project, collez juste l'optimization pack comme premier message dans un nouveau chat.

**Testez :** démarrez un nouveau chat dans le Project et collez le prompt de test ci-dessous.

---

## ChatGPT (Custom GPT ou chat one-off)

Pour un Custom GPT (recommandé si vous avez un plan Plus ou Team) : allez sur « My GPTs » → « Create a GPT » → onglet « Configure ». Dans le champ **Instructions**, collez le contenu de `custom-gpt-instructions.md`. Nommez-le « Solopreneur Co-Pilot ». Donnez-lui une courte description du genre « Propositions, SOW, factures et posts de visibilité pour les business à une personne ». Sauvegardez et commencez à discuter. Pour un usage one-off, collez `optimization-pack.md` comme premier message dans n'importe quel thread ChatGPT standard.

**Testez :** ouvrez votre nouveau GPT et collez le prompt de test ci-dessous.

---

## Gemini, Cursor, Codex (ou toute autre IA)

Pour **Gemini Advanced**, créez un nouveau Gem (« Gems » → « Create new Gem »). Collez l'optimization pack dans le champ instructions du Gem, sauvegardez, et utilisez ce Gem pour le travail solopreneur. Pour **Cursor**, ce kit est moins pertinent (Cursor est pour le code), mais vous pouvez coller l'optimization pack dans `.cursorrules` si vous voulez aussi de l'aide côté business dans votre éditeur de code. Pour **Codex / GitHub Copilot Chat / toute autre IA**, collez l'optimization pack comme premier message dans une conversation fraîche et recollez-le au début de tout nouveau thread de conversation.

**Testez :** utilisez le prompt de test ci-dessous pour confirmer que le setup fonctionne.

---

## Prompt de test à coller

Collez ceci exactement dans votre IA configurée :

```
Je suis designer de marque freelance. Principalement des SaaS startups, 5 ans d'expérience. Une fondatrice nommée Priya à un fintech Series A (équipe de 15 personnes, Toronto) vient de m'emailer — elle veut un « refresh de marque » pour son produit. Elle a mentionné un budget « autour de 8K CAD » mais a dit qu'elle est flexible si le scope a du sens. On a un appel de découverte programmé jeudi.

Deux choses dont j'ai besoin :
1. Un formulaire d'intake à 10 questions à lui envoyer avant l'appel.
2. Une proposition à trois tiers que je peux envoyer 24 heures après l'appel. Utilise des placeholders pour tout ce qu'on découvrira en discovery.

Garde chacun sous un écran. Je vais éditer.
```

Vous devriez récupérer un formulaire d'intake propre (10-12 questions, groupées sensément) et une proposition à trois tiers avec le tier du milieu marqué `(la plupart des clients prennent ça)` — pricing autour de 5K / 8K / 14K CAD, avec des placeholders pour les spécifiques de l'appel.

Si vous récupérez un mur de texte corporate ou une proposition à prix unique, l'optimization pack n'est pas chargé correctement. Recollez-le.
