# Quick Start — 60-Sekunden-Setup

Drei Absätze, einer pro Plattform. Wählen Sie Ihren, fügen Sie ein, testen Sie.

---

## Claude (claude.ai oder Claude in der API)

Erstellen Sie ein neues Projekt in Claude (linke Sidebar, "Projects" → "New Project"). Nennen Sie es "Solopreneur Co-Pilot." Im **Instructions**-Feld des Projekts fügen Sie den vollen Inhalt von `optimization-pack.md` ein. Speichern. Jeder Chat, den Sie innerhalb dieses Projekts starten, läuft jetzt im Solopreneur-Modus. Für One-off-Nutzung ohne Projekt, fügen Sie einfach das Optimization-Pack als erste Nachricht in einen neuen Chat ein.

**Testen Sie es:** Starten Sie einen neuen Chat im Projekt und fügen Sie den Test-Prompt unten ein.

---

## ChatGPT (Custom GPT oder One-off-Chat)

Für einen Custom GPT (empfohlen, falls Sie einen Plus- oder Team-Plan haben): gehen Sie zu "My GPTs" → "Create a GPT" → "Configure"-Tab. Im **Instructions**-Feld fügen Sie den Inhalt von `custom-gpt-instructions.md` ein. Nennen Sie es "Solopreneur Co-Pilot." Geben Sie ihm eine kurze Beschreibung wie "Proposals, SOWs, Invoices und Visibility-Posts für One-Person-Businesses." Speichern und starten Sie zu chatten. Für One-off-Nutzung fügen Sie `optimization-pack.md` als erste Nachricht in irgendeinen Standard-ChatGPT-Thread ein.

**Testen Sie es:** Öffnen Sie Ihren neuen GPT und fügen Sie den Test-Prompt unten ein.

---

## Gemini, Cursor, Codex (oder jede andere KI)

Für **Gemini Advanced** erstellen Sie einen neuen Gem ("Gems" → "Create new Gem"). Fügen Sie das Optimization-Pack in das Instructions-Feld des Gems ein, speichern Sie und nutzen Sie diesen Gem für Solopreneur-Work. Für **Cursor** ist dieses Kit weniger relevant (Cursor ist für Code), aber Sie können das Optimization-Pack in `.cursorrules` einfügen, falls Sie auch Business-side-Hilfe innerhalb Ihres Code-Editors wollen. Für **Codex / GitHub Copilot Chat / jede andere KI**, fügen Sie das Optimization-Pack als erste Nachricht in eine frische Konversation ein und fügen Sie es am Anfang jedes neuen Konversations-Threads erneut ein.

**Testen Sie es:** Nutzen Sie den Test-Prompt unten, um zu bestätigen, dass das Setup funktioniert.

---

## Paste-bares Test-Prompt

Fügen Sie das exakt in Ihre konfigurierte KI ein:

```
Ich bin ein Freelance-Brand-Designer. Meist SaaS-Startups, 5 Jahre dabei. Eine Founderin namens Priya bei einem Series-A-Fintech (15-Personen-Team, Toronto) hat mir gerade gemailt — sie will ein "Brand-Refresh" für ihr Produkt. Sie hat ein Budget von "around $8K CAD" erwähnt, aber gesagt, dass sie flexibel ist, falls der Scope Sinn macht. Wir haben einen Discovery-Call am Donnerstag gebucht.

Zwei Dinge brauche ich:
1. Ein 10-Frage-Intake-Formular, um es ihr vor dem Call zu senden.
2. Ein Three-Tier-Proposal, das ich 24 Stunden nach dem Call senden kann. Nutze Placeholder für alles, was wir in der Discovery aufdecken werden.

Halte es unter einem Screen jeder. Ich werde editieren.
```

Sie sollten ein sauberes Intake-Formular zurückbekommen (10-12 Fragen, sinnvoll gruppiert) und ein Three-Tier-Proposal mit dem mittleren Tier markiert mit `(die meisten Kunden wählen das)` — Pricing um $5K / $8K / $14K CAD, mit Placeholdern für die Spezifika aus dem Call.

Falls Sie eine Wand aus Corporate-Text oder ein Single-Price-Proposal zurückbekommen, ist das Optimization-Pack nicht korrekt geladen. Fügen Sie es erneut ein.
