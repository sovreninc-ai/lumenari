# Quick Start — 60-second setup

Three paragraphs, one per platform. Pick yours, paste, test.

---

## Claude (claude.ai or Claude in the API)

Create a new Project in Claude (left sidebar, "Projects" → "New Project"). Name it "Solopreneur Co-Pilot." In the Project's **Instructions** field, paste the full contents of `optimization-pack.md`. Save. Every chat you start inside that Project now runs in solopreneur mode. For one-off use without a Project, just paste the optimization pack as the first message in a new chat.

**Test it:** Start a new chat in the Project and paste the test prompt below.

---

## ChatGPT (Custom GPT or one-off chat)

For a Custom GPT (recommended if you have a Plus or Team plan): go to "My GPTs" → "Create a GPT" → "Configure" tab. In the **Instructions** field, paste the contents of `custom-gpt-instructions.md`. Name it "Solopreneur Co-Pilot." Give it a short description like "Proposals, SOWs, invoices, and visibility posts for one-person businesses." Save and start chatting. For one-off use, paste `optimization-pack.md` as the first message in any standard ChatGPT thread.

**Test it:** Open your new GPT and paste the test prompt below.

---

## Gemini, Cursor, Codex (or any other AI)

For **Gemini Advanced**, create a new Gem ("Gems" → "Create new Gem"). Paste the optimization pack into the Gem's instructions field, save, and use that Gem for solopreneur work. For **Cursor**, this kit is less relevant (Cursor is for code), but you can paste the optimization pack into `.cursorrules` if you also want business-side help inside your code editor. For **Codex / GitHub Copilot Chat / any other AI**, paste the optimization pack as the first message in a fresh conversation and re-paste it at the start of any new conversation thread.

**Test it:** Use the test prompt below to confirm the setup is working.

---

## Paste-able test prompt

Paste this exactly into your configured AI:

```
I'm a freelance brand designer. Mostly SaaS startups, 5 years in. A founder named Priya at a Series A fintech (15-person team, Toronto) just emailed me — she wants a "brand refresh" for her product. She mentioned a budget of "around $8K CAD" but said she's flexible if scope makes sense. We have a discovery call booked Thursday.

Two things I need:
1. A 10-question intake form to send her before the call.
2. A three-tier proposal I can send 24 hours after the call. Use placeholders for anything we'll uncover in discovery.

Keep it under one screen each. I'll edit.
```

You should get back a clean intake form (10-12 questions, grouped sensibly) and a three-tier proposal with the middle tier marked `(most clients pick this)` — pricing around $5K / $8K / $14K CAD, with placeholders for the specifics from the call.

If you get back a wall of corporate text or a single-price proposal, the optimization pack isn't loaded correctly. Re-paste it.
