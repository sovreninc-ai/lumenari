# クイックスタート — 60 秒セットアップ

3 段落、プラットフォーム 1 つにつき 1 つ。自分のを選び、貼り付け、テスト。

---

## Claude（claude.ai または API での Claude）

Claude で新しいプロジェクトを作成（左サイドバー、「Projects」 → 「New Project」）。「個人事業主コーパイロット」と名付ける。プロジェクトの **Instructions** 欄に `optimization-pack.md` の全内容を貼り付ける。保存。そのプロジェクト内で開始するすべてのチャットが今や個人事業主モードで動く。プロジェクトなしでの単発使用には、最適化パックを新しいチャットの最初のメッセージとして貼り付けるだけ。

**テスト:** プロジェクト内で新しいチャットを開始、下のテストプロンプトを貼り付け。

---

## ChatGPT（カスタム GPT または単発チャット）

カスタム GPT（Plus または Team プランがあれば推奨）: 「My GPTs」 → 「Create a GPT」 → 「Configure」タブへ。**Instructions** 欄に `custom-gpt-instructions.md` の内容を貼り付け。「個人事業主コーパイロット」と名付ける。「1 人ビジネスのための提案書、SOW、請求書、可視性投稿」のような短い説明を与える。保存してチャット開始。単発使用には、`optimization-pack.md` を標準 ChatGPT スレッドの最初のメッセージとして貼り付け。

**テスト:** 新しい GPT を開き、下のテストプロンプトを貼り付け。

---

## Gemini、Cursor、Codex（その他の AI）

**Gemini Advanced** には、新しい Gem を作成（「Gems」 → 「Create new Gem」）。最適化パックを Gem の instructions 欄に貼り付け、保存、個人事業主作業にその Gem を使う。**Cursor** には、このキットはあまり関連しない（Cursor はコード用）が、コードエディタ内でビジネス側の助けも欲しければ、最適化パックを `.cursorrules` に貼り付けられる。**Codex / GitHub Copilot Chat / その他の AI** には、最適化パックを新鮮な会話の最初のメッセージとして貼り付け、新しい会話スレッドの開始時に再度貼り付け。

**テスト:** 下のテストプロンプトを使ってセットアップが動作することを確認。

---

## 貼り付け可能なテストプロンプト

これを正確に、設定された AI に貼り付け:

```
私はフリーランスブランドデザイナーです。主に SaaS スタートアップ、5 年目。Priya という創業者が Series A フィンテック（15 人チーム、トロント）からメールしたばかり — 彼女のプロダクトの「ブランドリフレッシュ」が欲しい。「約 $8K CAD」の予算を言及したが、スコープが意味をなせば柔軟と言った。木曜日にディスカバリーコールが予約されている。

2 つ必要:
1. コール前に彼女に送る 10 質問のインテークフォーム。
2. コール後 24 時間で送れる 3 価格帯提案書。ディスカバリーで明らかになるものにはプレースホルダーを使う。

各々を 1 画面未満に保つ。私が編集する。
```

返ってくるべきは、クリーンなインテークフォーム（10〜12 質問、賢くグループ化）と、中間価格帯が `(ほとんどのクライアントがこれを選択)` とマークされた 3 価格帯提案書 — 価格は約 CAD $5K / $8K / $14K、コールからの具体性のプレースホルダー付き。

企業テキストの壁または単一価格提案書が返ってきたら、最適化パックが正しく読み込まれていない。再貼り付け。
