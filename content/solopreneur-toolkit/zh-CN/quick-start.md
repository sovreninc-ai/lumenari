# 快速开始 —— 60 秒上手

三段，每平台一段。挑你的，粘贴，测试。

---

## Claude（claude.ai 或 API 中的 Claude）

在 Claude 中新建 Project（左侧 "Projects" → "New Project"）。命名 "Solopreneur Co-Pilot"。在 Project 的 **Instructions** 字段粘贴 `optimization-pack.md` 全部内容。保存。该 Project 中你开的每个对话都跑在 solopreneur 模式下。不想用 Project 的一次性使用：把 optimization pack 作为新对话的首条消息粘上。

**测试：** 在该 Project 中新开对话，粘贴下方测试 prompt。

---

## ChatGPT（Custom GPT 或一次性对话）

Custom GPT（有 Plus 或 Team 推荐）：到 "My GPTs" → "Create a GPT" → "Configure" 标签。在 **Instructions** 字段粘贴 `custom-gpt-instructions.md` 内容。命名 "Solopreneur Co-Pilot"。简短描述："为一个人的生意做提案、SOW、发票与可见度帖。" 保存并开始。一次性使用：在任意 ChatGPT 普通对话首条粘 `optimization-pack.md`。

**测试：** 打开你的新 GPT，粘下方测试 prompt。

---

## Gemini、Cursor、Codex（或任何其他 AI）

**Gemini Advanced**：新建 Gem（"Gems" → "Create new Gem"）。把 optimization pack 粘进 Gem 指令字段，保存，用该 Gem 做 solopreneur 工作。**Cursor**：本套件相关度低（Cursor 偏代码），可把 optimization pack 粘进 `.cursorrules`，让代码编辑器里也有业务侧帮助。**Codex / GitHub Copilot Chat / 其他**：把 optimization pack 作为新对话首条消息粘上，并在每开一条新对话时再粘一次。

**测试：** 用下方 prompt 验证。

---

## 可粘贴的测试 prompt

把这段原样粘进配置好的 AI：

```
I'm a freelance brand designer. Mostly SaaS startups, 5 years in. 一位多伦多 Series A 金融科技（15 人团队）的创始人 Priya 刚邮件我，想做"brand refresh"。她提到预算"around $8K CAD"，但若 scope 合理也灵活。周四已约了 discovery call。

我需要两样：
1. 一份在通话前发给她的 10 题 intake 表单。
2. 一份在通话后 24 小时内可发的三档提案，未在 discovery 中明确的部分用占位。

每个不超过一屏。我会改。
```

你应该收到一份干净的 intake 表单（10-12 题，合理分组）与一份三档提案，中间档标 `（多数客户选这个）` —— 定价约 $5K / $8K / $14K CAD，针对通话内容留占位。

如果回来一段企业腔大段文字或单一价提案，optimization pack 没加载好。重粘。
