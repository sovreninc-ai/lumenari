# Inicio rápido — setup en 60 segundos

Tres párrafos, uno por plataforma. Elige el tuyo, pega, prueba.

---

## Claude (claude.ai o Claude en la API)

Crea un nuevo Project en Claude (sidebar izquierdo, "Projects" → "New Project"). Llámalo "Solopreneur Co-Pilot". En el campo **Instructions** del Project, pega todo el contenido de `optimization-pack.md`. Guarda. Cada chat que inicies dentro de ese Project ahora corre en modo solopreneur. Para uso puntual sin Project, solo pega el optimization pack como primer mensaje en un nuevo chat.

**Pruébalo:** Inicia un nuevo chat en el Project y pega el prompt de prueba de abajo.

---

## ChatGPT (Custom GPT o chat puntual)

Para un Custom GPT (recomendado si tienes plan Plus o Team): ve a "My GPTs" → "Create a GPT" → tab "Configure". En el campo **Instructions**, pega el contenido de `custom-gpt-instructions.md`. Llámalo "Solopreneur Co-Pilot". Dale una descripción corta como "Propuestas, SOWs, facturas y posts de visibilidad para negocios de una sola persona". Guarda y empieza a chatear. Para uso puntual, pega `optimization-pack.md` como primer mensaje en cualquier thread estándar de ChatGPT.

**Pruébalo:** Abre tu nuevo GPT y pega el prompt de prueba de abajo.

---

## Gemini, Cursor, Codex (o cualquier otra IA)

Para **Gemini Advanced**, crea un nuevo Gem ("Gems" → "Create new Gem"). Pega el optimization pack en el campo de instrucciones del Gem, guarda y usa ese Gem para trabajo solopreneur. Para **Cursor**, este kit es menos relevante (Cursor es para código), pero puedes pegar el optimization pack en `.cursorrules` si también quieres ayuda del lado de negocio dentro de tu editor de código. Para **Codex / GitHub Copilot Chat / cualquier otra IA**, pega el optimization pack como primer mensaje en una conversación nueva y vuelve a pegarlo al inicio de cualquier hilo de conversación nuevo.

**Pruébalo:** Usa el prompt de prueba de abajo para confirmar que el setup funciona.

---

## Prompt de prueba para pegar

Pega esto exactamente en tu IA configurada:

```
Soy diseñador de marca freelance. Sobre todo SaaS startups, 5 años en esto. Una founder llamada Priya en una fintech Serie A (equipo de 15 personas, Toronto) acaba de mandarme email — quiere un "brand refresh" para su producto. Mencionó un presupuesto de "alrededor de $8K CAD" pero dijo que es flexible si el scope tiene sentido. Tenemos una llamada de discovery agendada para el jueves.

Dos cosas que necesito:
1. Un intake form de 10 preguntas para mandarle antes de la llamada.
2. Una propuesta de tres tiers que pueda mandar 24 horas después de la llamada. Usa placeholders para cualquier cosa que descubramos en discovery.

Manténlo en menos de una pantalla cada uno. Yo edito.
```

Deberías recibir un intake form limpio (10-12 preguntas, agrupadas de forma sensata) y una propuesta de tres tiers con el tier intermedio marcado `(la mayoría de clientes elige este)` — pricing alrededor de $5K / $8K / $14K CAD, con placeholders para los detalles de la llamada.

Si recibes un muro de texto corporativo o una propuesta de un solo precio, el optimization pack no está cargado correctamente. Vuelve a pegarlo.
