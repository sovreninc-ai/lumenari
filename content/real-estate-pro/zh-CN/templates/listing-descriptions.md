# 按房型的 Listing 描述

五种房型、五个 prompt 模板、五个示例输出。直接用或在此基础上改。示例帮你在生成自己的内容前先看到好的样子。

---

## 如何使用本文件

1. 找到匹配你 listing 的房型
2. 复制 prompt 区块
3. 替换方括号中的输入
4. 粘到你的 AI 工具（先加载 `optimization-pack.md` 为系统提示词）
5. 对照示例做直觉检查

系统提示词处理结构、语气与公平住房合规。这些模板只负责给 AI 每种房型所需的具体输入。

## 1. 独栋住宅（SFH）

### Prompt

```
为这套独栋住宅写 MLS public remarks。

房产：
- 地址或社区：[名称]
- 卧：[#] / 卫：[#] / 面积：[#] / 地块：[尺寸]
- 建成年份：[年]
- 风格：[Craftsman / Colonial / ranch / contemporary / 等]
- 状态：[拎包入住 / 微更新 / 全装修 / 需修缮]

真正重要的特点（买家会注意到的事）：
- [特点 1 —— 具体，不要"amazing"]
- [特点 2]
- [特点 3]
- [特点 4]
- [特点 5]

机械 / 更新（有年份就写）：
- [HVAC、屋顶、窗户、电气、水管 —— 列出近期项]

户外：
- [院子、露台、车库、停车、围栏]

位置具体：
- [步行可达 X、Y 分钟到市中心、学区名]

最可能的买家：
- [具体 —— "改善型夫妇带一娃一狗、混合 WFH"]

平台：[美国 MLS / Realtor.ca / Zillow / Redfin]
字符限制：[数字]
```

### 示例输出

**所用输入：** 4 卧 / 2.5 卫 / 2180 sqft Craftsman，位于 Bridgeland（Calgary），2009 年建，厨房 2023 年微更新，0.14 英亩。Wolf range、屠夫板岛、可独立出入的全装修地下室、朝南甲板、双独立车库。步行 7 分钟到 LRT。改善型家庭从联排升级。

**输出（Realtor.ca，~250 词）：**

一套 2009 年 Craftsman，维护用心，坐落于 Bridgeland 一条安静的街上，步行 7 分钟到 LRT。2023 年的厨房更新做了真正有用的事 —— Wolf 燃气灶、屠夫板岛、缓冲合页柜门 —— 又没破坏原始动线的温度。硬木贯穿主层，视线从厨房一直能延伸到朝南甲板。

楼上四间卧室，含主卧带步入式衣柜与三件套套卫。地下室全装修，侧面有独立入口，按需可作 nanny suite 或长住客房。

地块略超 6000 平方英尺，全围栏，后巷出入的双独立车库。屋顶较新（2021），高效炉，中央空调。后院朝南，从上午晚些时候到傍晚都有阳光 —— 对狗好、对花园好、对周六的一杯咖啡也好。

Bridgeland 无需多介绍：步行可至 OEB、Lukes 和河边步道；十五分钟内进市中心。Inglewood 与 East Village 骑车可达。学区为 Langevin 与 Crescent Heights —— 买家请向 CBE 核实当前边界。

---

发布前需要核实：
- 屋顶年份（2021）
- HVAC 年龄
- 当前学区边界与 CBE

## 2. 共管 / 联排

### Prompt

```
为这套公寓或联排写 MLS public remarks。

房产：
- 楼盘/小区：[名称]
- 单元类型：[condo / townhouse / loft / penthouse]
- 卧：[#] / 卫：[#] / 面积：[#]
- 建成年份：[年]
- 楼层：[# / 共 #]
- 朝向：[N/S/E/W]

特点：
- [特点 1]
- [特点 2]
- [特点 3]
- [特点 4]

楼栋设施（只列买家真正关心的）：
- [健身房 / 泳池 / 礼宾 / 屋顶 / 停车 / 储物 / 允许宠物含限制]

费用：
- HOA / 共管费：$[金额] / 月 —— 含什么
- 房产税：$[金额] / 年（有则给，否则 [CONFIRM]）

位置：
- [步行可达 X、公交、社区氛围]

最可能的买家：
- [首次置业、缩房、投资人、城市职场人]

平台：[MLS]
字符限制：[数字]
```

### 示例输出

**输入：** 2 卧 / 2 卫 / 985 sqft 公寓，14 楼，东南向，奥斯汀市中心 2017 年大楼。新不锈钢家电、石英台面、户内洗衣。楼栋含健身房、屋顶泳池、24 小时礼宾。HOA $640/月含水、燃气、设施。买家：城市职场人，首套市中心公寓，步行通勤。

**输出（美国 MLS，~150 词）：**

14 楼朝东南的两居 —— 卧室清晨阳光，客厅望市区，季节合适时同时拥有。开放式格局，石英台面、不锈钢家电、岛台可坐三人。两间卧室都是真正卧室，不是"一加一灵活"；第二间有窗、有正经衣柜。

户内洗衣、一位车库车位、独立储物间。楼栋设施常规配置 —— 屋顶泳池、健身房、24 小时礼宾 —— 位置上步行 6 分钟到 Congress，8 分钟到 Whole Foods，15 分钟到 Lady Bird 步道入口。

HOA $640/月含水、燃气与设施。允许宠物含体重限制。

---

发布前需要核实：
- 房产税（未提供）
- 宠物体重限制
- 储物间尺寸

## 3. 豪宅

### Prompt

```
为这套豪宅写 MLS public remarks。

房产：
- 地址或社区：[名称]
- 类型：[estate / penthouse / waterfront / 新建]
- 卧：[#] / 卫：[#] / 面积：[#] / 地块：[尺寸]
- 建成年份：[年]（或"定制建成于 [年]"）
- 建筑师 / 建造方：[名称，若知名]

让此房成为这套房的那一个特征：
- [那一件事 —— 景观、建筑师、地段、私密性、湖岸线]

3-5 个其他显著具体项：
- [特点 + 品牌或细节]
- [特点]
- [特点]
- [特点]

户外 / 土地：
- [英亩、水岸、景观、花园、泳池、附属建筑]

智能 / 机械：
- [家居自动化、地源热泵、太阳能、EV 等]

位置具体：
- [私密性、距机场、学校、镇上]

最可能的买家：
- [二套度假买家、高管派驻、从 $X 升到 $Y]

平台：[MLS / 豪宅门户 / 公司站点]
字数目标：250-400 词（豪宅较长）
```

### 示例输出

**输入：** 5 卧 / 5.5 卫 / 6200 sqft 定制住宅，Whistler Cadenza，建筑师 Patkau Associates，2021 年完工，0.42 英亩，临 Whistler Creek。地源热泵、Lutron 全屋灯控、室内泳池、四车位车库带 EV、Creekside ski-in。买家：温哥华或美西海岸的二套度假买家。

**输出（豪宅门户，~350 词）：**

Patkau Associates 设计、2021 年完工，坐落于一块 0.42 英亩 Cadenza 地块上，直接背靠 Whistler Creek，并可 ski-in 接入 Creekside。这是一份当代山地住宅可以如何被定义的范本 —— 长跨度雪松、面向河谷与山脊的全高玻璃、主套卧通向一处临水的私人露台。

跨三层共六千两百平方英尺。五间卧室，每间套卫。厨房以 Sub-Zero 立柱冰箱与冷冻、双烤箱 Wolf 灶为核心，并配带第二台洗碗机与备餐池的 butler's pantry。带 20 英尺挑高与 Stuv 木柴壁炉的 great room。

下层包含临河玻璃幕的室内泳池、四件套池畔卫浴、调好 Atmos 的影音房，以及可宿六人的儿童套房。门厅旁的酒窖。Lutron 全屋灯控、Crestron AV、地源热泵 + 地暖，以及为海拔做了调试的 HRV。

四车位恒温车库、双 EV 充电、带顶接送区。带烘鞋的 ski room 与直通储物层的专用入口。三面成熟绿化，即便在 Cadenza 也属罕见的私密度。

Creekside Gondola 沿后院步道步行 4 分钟可达。Whistler Village 车程 6 分钟，机场两小时，温哥华一小时四十五分。

为那些希望建筑本身成为资产组成部分的买家而设计。

---

发布前需要核实：
- 建筑师署名表述是否可发布（部分事务所有署名规定）
- 适用时 HOA / strata 费用
- 房产税（未提供）
- ski-in 通道（季节性？）

## 4. 待修缮

### Prompt

```
为这套待修缮房产写 MLS public remarks。

房产：
- 地址或社区：[名称]
- 卧：[#] / 卫：[#] / 面积：[#] / 地块：[尺寸]
- 建成年份：[年]
- 状态：[需软装更新 / 需系统更新 / 有结构问题]

什么是好的（不要藏起来）：
- [基础、屋顶、骨架、地块、位置、近期机械]

需要修什么（直接，买家反正看得见）：
- [诚实列出]

ARV 信号：
- [本区近期已装修房成交价 $X / sqft —— 用于买家算账]

最可能的买家：
- [flipper、自住翻新、建造商、承包商家庭]

平台：[MLS]
字符限制：[数字]
语气：就事论事，不要委婉。"需要刷漆与换地板"可以。"带上想象力"不行。
```

### 示例输出

**输入：** 3 卧 / 1 卫 / 1150 sqft 1958 平房，东温哥华，33 × 122 地块。原始厨房、原始卫浴、燃油热（地面油箱新近）、屋顶 2019、地基干燥。本街近期翻新房成交 > $1.8M。买家：建造商或自住翻新人。

**输出（美国 MLS，~180 词）：**

一套 1958 年平房，坐落于平整的 33 × 122 地块，等待下一任投入工作。屋顶 2019 年换。地基干燥。燃油热，地面油箱去年检过。厨房与卫浴均为原始。主层房间地毯下为原始硬木。

楼上三间卧室、未装修的地下室有独立入口潜力、单 carport。地块为 RT-7，便于侧院进出。

骨架是这里的价值。同一街区近期翻新房成交在 $1.8M 之上。下一任要么是从头到脚的建造商、要么是把它当作东温首套项目的承包商家庭、要么是 scope 清晰的 flipper。三种算账都行得通，前提是带着清醒进来。

带承包商一起看房。欢迎做 inspection。

---

发布前需要核实：
- 油箱拆除时间表（BC 有规定）
- RT-7 细则与市政
- 产权上是 carport 还是 garage

## 5. 多户型

### Prompt

```
为这套多户型 / 投资性房产写 MLS public remarks。

房产：
- 地址或社区：[名称]
- 类型：[duplex / triplex / fourplex / 5+]
- 总单元数：[#]
- 总面积（建筑）：[#]
- 地块：[尺寸]
- 建成年份：[年]

单元构成：
- 单元 1：[卧/卫/面积/当前租金或"空置"]
- 单元 2：[卧/卫/面积/当前租金或"空置"]
- （列完所有单元）

财务（仅在卖家同意分享时）：
- 月毛租：$[金额]
- 年支出：$[金额]
- NOI：$[金额]
- 按挂牌价 cap rate：[%]

资本性支出 / 状态：
- [近期更新、延迟维护、系统年龄]

租约：
- [按月 / 固定期 / 空置 / 混合]

最可能的买家：
- [自住 house-hack / 投资人 / 1031 buyer / 组合扩张]

平台：[MLS / 商业多户门户]
字符限制：[数字]
语气：投资人导向。数字在前。跳过生活方式文案。
```

### 示例输出

**输入：** Hamilton, ON 的三户型。1962 建。三套两卧约 750 sqft。当前租金：$1,400 / $1,650 / 空置。屋顶 2020、炉 2018（每户单独计量）、四停车。买家：本地已有组合的投资人。

**输出（MLS 商业，~180 词）：**

Hamilton 市中心 1962 年砖三户型，三套两卧、各约 750 平方英尺，燃气与电力分户计量。屋顶 2020 年更换；三套均在 2018 年更换炉具。后巷接入四车位户外停车。

当前单元与租金：单元 1 在租，$1,400（长租客）；单元 2 在租，$1,650（2025 续约）；单元 3 空置，按相近两卧 comp 估市租 $1,750-1,850。

按市租稳定后月毛租约 $4,900。卖家可通过 listing agent 提供完整 T12 与租金册。

楼栋由业主自管十一年。维护记录可查。三套中两套近五年内做过软装更新；单元 1 仍为原始状态。

目标人群：本地组合扩张的投资人，或愿承担轻度房东职责的自住者。AGI / N12 动态：咨询 listing agent。

---

发布前需要核实：
- 卖家是否同意在 remarks 中分享财务
- T12 数字（未核实的 NOI 不要写）
- 各单元当前 Ontario LTB 状态
- 后巷停车合法性（部分 Hamilton 后巷有限制）

## AI 会接受的常见微调

草稿拿回来想调时：

- "去掉形容词，每个换成具体说法。"
- "压到 [X] 字符。保留 lead 与 close。"
- "更直接，少生活方式。"
- "加一行关于 [你忘提的特点]。"
- "Close 再柔一些 —— 不要感叹号。"
- "用一种昨天和买家一起走完这套房的口气来写。"

每条都会带来明显更好的第二稿。AI 在"向具体性编辑"上比"从单薄首 prompt 凭空生成"强得多。
