# クイックスタート — 不動産リスティング + 市場分析

60 秒以内に稼働するはずです。ツールを選んでください。

## Claude ユーザー

Claude を開く。新しいプロジェクトを作成（Pro または Team プランがプロジェクトに必要だが、プロンプトは通常のチャットでも動く）。プロジェクトの「カスタム指示」または「プロジェクトナレッジ」欄に `optimization-pack.md` の全内容を貼り付ける。`templates/` 内のファイルをプロジェクトナレッジにアップロード、Claude が参照として持てるように。プロジェクト内で新しい会話を開始。最初のメッセージ: 管轄（州または県）を Claude に伝え、欲しい成果物を記述 — 「[近隣] の 3 ベッドコンドの MLS パブリックコメントが必要」または「この物件で CMA を実行、コンプは次のメッセージで送る」。

## ChatGPT ユーザー

ChatGPT を開く。「GPT を探す」 → 「GPT を作成」をクリック（Plus プラン必要）。「Instructions」欄に `custom-gpt-instructions.md` の全内容を貼り付ける。「Conversation starters」には、そのファイル末尾にある 5 つを使う。「Knowledge」に `templates/` フォルダの markdown ファイルをアップロード。GPT を保存（自分専用で OK）。開いて始める: 「こんにちは、[州 / 県] のエージェントです。今日必要なものはこれ: [成果物]。」

ChatGPT Plus がなければ、`optimization-pack.md` を通常のチャットの先頭に貼り付ける。動く — 永続的な GPT とファイルアップロードを失うだけ。

## Gemini、Codex、Cursor、その他の AI ツール

ツールを開く。新しい会話を開始。`optimization-pack.md` の全内容を最初のメッセージとして貼り付ける。追加: 「これを読み込んだことを確認し、管轄と成果物タイプを聞いてほしい。」 それを行ったら準備完了。

Gemini Gems 専用: 新しい Gem を作成、instructions 欄に `optimization-pack.md` を貼り付け、保存、そのデフォルトチャットの代わりにその Gem を使う。

## 動作確認

システムプロンプトを読み込んだら、これを貼り付ける:

```
テスト実行。[あなたの州または県] の免許エージェント。戸建ての MLS パブリックコメントが必要: 4 ベッド、3 バス、2,400 sqft、2018 年築、[あなたの近隣] の 0.18 エーカーコーナーロット。特徴: アイランド付きシェフキッチン、仕上がった地下、囲まれた庭、EV 充電器付き 2 台ガレージ。可能性の高いバイヤー: タウンハウスからのステップアップ家族、屋外スペースが欲しい。900 文字制限。
```

返ってきたリスティングが構造（リード → レイアウト → 特徴 → 立地 → クロージング）に従い、900 文字未満で、末尾に「公開前に確認すべきこと」ブロックがあれば、キットは正しく読み込まれています。出力のどこかに「Welcome home!」または「This stunning property boasts」が出てきたら、システムプロンプトが読み込まれていない — もう一度貼り付ける。
