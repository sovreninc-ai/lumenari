# バイヤー + セラーのフォローアップメールケイデンス

Day 0、3、7、14、30。アウトラインではなくフルコピー。新しいバイヤーリードは「来春考えている」セラーとは違うケイデンスを必要とするため、2 つのパラレルトラック。

下記のメールは編集されるように書かれている。括弧で囲まれた入力を置き換え、各メールの 2 文目をパーソナライズ — それが人間のように読まれるかシーケンスとして読まれるかを決める文。

---

## これらのケイデンスの使い方

1. AI ツールに `optimization-pack.md` を読み込ませた後、下記の関連ケイデンスを貼り付け、「これをケイデンスの形として使う。[リードコンテキスト] にパーソナライズして」と言う。
2. AI にリードの名前、エンゲージした物件またはコンテキスト、彼らが伝えたこと（「州外から引っ越し中」「成約日制約あり」「2 つのエリアで迷っている」）、サインオフスタイルを与える。
3. AI がそのリードにパーソナライズされた 5 つのメールを返す。
4. 各々を約 30 秒でスキャン、あなたらしく聞こえない 1〜2 行を編集、キューに入れる。

これは CRM のテンプレート化より速く、より良くコンバートするメールを生成する、各ケイデンスがメールマージではなく 1 度のショットでパーソナライズされるから。

---

## バイヤートラック

バイヤートラックはリードが積極的な関心を示したと仮定する — 検索に登録、オープンハウスに参加、リスティングの質問、紹介された。今月買う準備ができていることは仮定しない。

### Day 0 — 問い合わせ同日

**件名:** [近隣] の家 — 検索を保存しました

```
こんにちは [名前]、

[特定の物件または「[近隣] の家」] についてご連絡ありがとうございます。検索を初日から有用にするためのいくつかの簡単なこと:

1. [MLS ポータル / Zillow / Realtor.ca] で保存検索を設定しました。1 時間以内にリンクのメールを受け取るはずです。新しいリスティングが公開された瞬間に届く、Zillow をリフレッシュするより良い。

2. お話を聞いて、今週見る価値があると思う 3 つのリスティングを引きました。下のメールにあります。

3. 今週 15 分の電話の時間があれば、OK なバイヤー体験と素晴らしいバイヤー体験を分ける 4 つの質問をしたい — 予算範囲、タイムライン、必須 vs あったら良い、すでに何があなたを離れさせたか。

いつ良いですか? [2 つの特定の時間帯] があります。

[サインオフ]
```

**AI のチューニング注記:**
- 過去のクライアントから紹介された場合: 「[過去のクライアント名] があなたが探していると言っていました — 彼らは軽く紹介する人ではないので、つなぎに感謝します」で始める。
- オープンハウスから来た場合: 「[住所] で [曜日] にお会いできてよかった。あの家の裏の光が本当にレイアウトに私を売り込んだ」で始める。
- 州外: あなたがどのようにリモートバイヤーを扱うかについての段落を追加（FaceTime ツアー、あなたの検査者ネットワークなど）。

### Day 3 — 勢いチェック

**件名:** 今朝 2 つの新しいリスティングを見ました

```
こんにちは [名前]、

お話に合う 2 つの新しいリスティングが今朝 MLS にヒットしました。各々への私の率直な意見と共に下に置きました — 2 つ目が強い適合ですが、両方見て較正できるようにしたい。

[リスティング 1]
[リスティング 2]

どちらかの案内を設定しますか? [曜日、時間帯] が空いています。

もう一つ — Day 0 に [エンゲージした物件] を保存したとき、レイアウト、価格帯、近隣のどれが目を引きましたか? 何を送るかのノイズから信号を選別するのに役立ちます。

[サインオフ]
```

**チューニング注記:**
- Day 0 にまだ返信していなければ、Day 3 は最大 3 文に短く、単一質問で終える。
- AI が持っていない実際のリスティング詳細を含めない。実際のリスティングを埋めるためのプレースホルダーを残す。

### Day 7 — 較正メール

**件名:** いくつかの率直な質問

```
こんにちは [名前]、

1 週間経って、気づいたことを共有したい。私が送っているリスティングは [特定の特徴 — 古い魅力、新しいビルド、特定の価格帯] に傾いています — それが正しい読みか、シフトすべきか教えてください。

通常バイヤーに 2〜3 か月の検索を節約する 3 つの質問:

1. 家が完璧なら書く最高の価格は何か — そして変えたい 3 つのことがあれば書く最高は何か?
2. 改装に慣れているか、入居可能な状態が絶対不可譲渡か?
3. 特定のタイムライントリガー（リース終了、学年、仕事開始）があるか、オープンエンドか?

これらに急ぐ必要なし。だが各々に 1 文くれれば、検索が劇的に良くなる。

[サインオフ]
```

**チューニング注記:**
- 反応が良ければ、質問をする。静かになったら、1 つだけ聞く。
- 質問は常に「時間を節約する」とフレームする — 決して「助けるためにこれを知る必要がある」ではない。

### Day 14 — 市場コンテキストメール

**件名:** 今月の [近隣] の様子

```
こんにちは [名前]、

[近隣 / ターゲットエリア] の素早い市場アップデート:

- 過去 14 日間で [#] 件リスト
- [#] 件が契約に
- 中央値リスト対売却比: [%]
- 平均市場日数: [#]

短い版: [実際に起きていることの 1 文 — 「在庫はタイト、競争を予期」 / 「先月より在庫が多い、レバレッジがある」 / 「あなたの価格帯特有に、[観察]」]。

今月価格帯で何が動いたかのフルウォークスルーが欲しければ — カレンダーに 30 分喜んで置きます。

[サインオフ]
```

**チューニング注記:**
- AI は実際の市場数字を知らない。プレースホルダーを残す。これは MLS 市場統計から手で埋める 1 つのメール。
- 遅いフェーズ（「探しているが秋まで」）にいるなら、このメールをこうシフト: 「タイムラインを変える、次の 60 日間で見るべきこと」。

### Day 30 — 長期ピボット

**件名:** 準備ができたらまだここに

```
こんにちは [名前]、

簡単なチェックイン。市場アップデートは今後月次で出ます — 先週のものと同じ形式、何かが目を引かなければアクション不要。

フラグを立てる 2 つ:

1. タイムラインがシフトしたら（早くまたは遅く）、教えてください。検索とペースがそれと共に変わります。
2. 今が正しい時期でないと決めたら、知っておきたい。あなたが削除しているメールを送るより、検索を一時停止して [3 / 6 / 12] か月後にピックアップする方が良い。

どちらにせよ — 私はどこにも行きません。正しい時期に連絡してください。

[サインオフ]
```

**チューニング注記:**
- 「買わないなら知りたい」行がケイデンスで最も重要な文。圧力を解放し、ほとんど常に返信を得る。
- Day 30 以降、月次市場アップデートメールと四半期チェックインに切り替え。日次ケイデンスの感覚を完全に外す。

## セラートラック

セラートラックはリードがリストに関心を示したと仮定する — ホーム価値見積もりを要求、リスティングプレゼンに参加、過去のセラーから紹介された、「家を売る」ページで質問。今月リストする準備ができていることは仮定しない。

### Day 0 — 問い合わせ同日

**件名:** [住所] — いくつかの数字を引きました

```
こんにちは [名前]、

可能な売却についてご連絡ありがとうございます。ミーティングに入る前に、ほとんどのエージェントが最初のメールでスキップするものを送りたかった — 実際の数字。

[住所または近隣] のコンプを引きました。過去 90 日に売れたものと現在アクティブなものに基づき、会話を始める範囲は [低] から [高]。それは出発点であり最終的な数字ではない — 最終的な数字は公的データから見えない 3 つのことに依存: 状態、タイムライン、家に投入したもの。

実際の CMA — リスティング面談で前に置くようなもの — が欲しければ、[曜日] までに準備できる。適切に行うのに約 2 時間かかるので、実行する前にあなたに有用かを確認したい。

始めるための 2 つの質問:
1. 「考えている」段階か、「次の 90 日でリストしたい」段階か? 両方 OK — 会話が違うだけ。
2. タイムライントリガー（仕事、ダウンサイズ、転勤、遺産）があるか、「数字が正しければ」の売却か?

[サインオフ]
```

**チューニング注記:**
- 「実際の CMA を準備できる」行が、Zestimate を送るエージェントとあなたを区別する。スキップしない。
- 防御できない範囲を引用しない。まだコンプがなければ、「コンプを今引いていて、[明日] までに範囲を持つ」と書く。

### Day 3 — ホーム価値メール

**件名:** あなたの家の価値範囲

```
こんにちは [名前]、

[住所] のコンプを実行しました。見つけたこと:

最近の売却（過去 90 日）の周辺地域: [3〜4 行で要約]

現在アクティブとペンディング: [1〜2 行]

私の読み: あなたの家の防御可能なリスト価格範囲は [低] から [高]、最も可能性の高い売却価格は [中] 付近に着地。

幅は 3 つのものに依存:
1. コンプに対する状態 — コンプ [X] は改装、コンプ [Y] はオリジナル。あなたの家はどこに座る?
2. タイミング — 次の 30 日でのリストは [春 / 秋 / 市場コンテキスト] にヒット。90 日では違う。
3. プレリスト準備 — 通常、費用の 2〜4 倍を返す 3〜5 つの低コストの動きがある。公開から 30 日以上離れているなら議論する価値あり。

今週 45 分カレンダーに置いてフル CMA を対面でウォークスルーしますか? あなたの所に行きます。

[サインオフ]
```

**チューニング注記:**
- このメールは実際のプロダクト。実際のコンプで埋める。AI はデータを貼り付ければフォーマットできる — `cma-prompt.md` 参照。
- 3 日で実際のコンプが取れなければ、「まだコンプを引いている、もう 1 日かかる理由はこれ」の短いノートを代わりに送る。

### Day 7 — プレリスト準備メール

**件名:** リスト前に針を動かす 5 つのこと

```
こんにちは [名前]、

次の 30〜90 日でリストを考えているなら、費用を一貫して上回るリターンを出すプレリストの 5 つの動きがここに。投資収益率の順:

1. **ペイント** — 全体に明るいニュートラル、最初に見える部屋に焦点。[市場] での平均費用: $[範囲]。典型的なリターン: $[範囲]。

2. **フロア** — ハードウッドなら、再仕上げ。カーペットなら、最悪の 1〜2 部屋を交換。すべてではない。

3. **照明器具とハードウェア** — キッチン、プライマリーバス、エントリ。小さな費用、認識される状態への不釣り合いな効果。

4. **片付けとストレージ** — 時にリスト最大の動き。60 日間のストレージユニットがしばしば 5〜10 倍を返す。

5. **歩道での造園** — 最初の写真は前。トリム、マルチ、刈り、エッジ。予算がタイトなら庭の残りはスキップ。

[近隣 / 市] でこれらの各々に信頼するトレードを持っています。喜んで紹介します。誰も私に紹介料を払いません — 私のセラーを悪い仕事をする人に送らないだけ。

これのいずれかを対面でウォークスルーしたければ、[特定の時間帯 2 つ] があります。

[サインオフ]
```

**チューニング注記:**
- 市場の特定のドル範囲を持つ。知らなければ、送信前に 3 人のコントラクターに聞く。
- 「誰も紹介料を払わない」行は信頼の行。本当でなければ含めない。本当なら、毎回言う。

### Day 14 — 市場タイミングメール

**件名:** [彼らの市場] — これが正しいウィンドウか?

```
こんにちは [名前]、

あなたの価格帯と近隣特有の素早い市場の読みを送りたかった。

[彼らのエリア] の過去 30 日:
- [#] 件新規リスト
- [#] 件契約に
- 平均 DOM: [#]
- リスト対売却比: [%]

あなたにとっての意味: [1〜2 文]。

考えるべき 3 つのタイミングシナリオ:

**次の 30 日でリスト:** [現在の市場特有の長所 + 短所]
**60〜90 日でリスト:** [長所 + 短所]
**[季節] まで待つ:** [長所 + 短所]

普遍的に「正しい」答えはない — タイムライン、状態、価格帯に依存する。実際の数字付きで 3 つのシナリオをウォークスルーしたければ、30 分を設定しましょう。

[サインオフ]
```

**チューニング注記:**
- 3 シナリオフレーミングが最も価値ある部分。セラーはデフォルトで「春まで待つ」。時にそれは正しい；しばしばそうでない。
- MLS 市場統計から実際の数字を埋める。AI は持っていない。

### Day 30 — 長期ピボット

**件名:** リストする準備ができたらまだここに

```
こんにちは [名前]、

1 か月経って、2 つ:

1. 市場アップデートは月次で続きます。同じ形式、何かが目を引かなければアクション不要。

2. タイムラインが固まったら（早くまたは遅く）、教えてください。各タイムラインで戦略が違います。

今年売らないと言ってもらう方が、あなたが削除しているメールを送るより良い。どちらでも私には機能 — どちらにいるかを知りたいだけ。

準備ができたら、CMA とプレリスト計画は 1 時間先にあります。

[サインオフ]
```

**チューニング注記:**
- バイヤー Day 30 メールと同じリリースバルブ。「売らないなら教えて」の率直さがこのケイデンスをドリップから区別する。
- Day 30 以降、四半期チェックイン付きの月次市場アップデートに切り替え。

## 返信率を倍にする単一の編集

AI がケイデンスを生成した後、各メールの 2 文目を見つけ、リードに特定の何かを参照するように書き直す。「お便り嬉しいです」ではない — 「[近隣] で 3 件のリスティングを保存したのに気づいた、これは私の最後の 2 人のセラーが出てきた同じエリア」または「あなたのメモでシアトルから引っ越し中と書いていた — 交通比較だけで良い意味でショック」のような。

その 2 文目が「この人は私にソフトウェアを使っている」と「この人は実際に書いたものを読んだ」の違い。メールごとの 30 秒の価値あり。
