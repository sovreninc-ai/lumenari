# Quick Start — Trades & Construction Workflow Pack

You'll be running in under a minute.

## ChatGPT, Claude (web), or Gemini

1. Open the tool
2. Paste the contents of `optimization-pack.md` into the system prompt / custom instructions / project knowledge field
3. Start asking it to write toolbox talks, JHAs, fit-for-duty letters, or onboarding checklists

## Claude Code, Cursor, or Codex (SKILL.md path)

1. Open Terminal (or your code editor)
2. Drop the kit folder into `~/.claude/skills/trades-construction/` (Claude Code) or paste `SKILL.md` at your project root
3. Type what you want — Claude picks up the skill automatically

## Test it works

Paste: "Write a 500-word toolbox talk for my pipefitting crew about hot work near a live medical gas line. Alberta jurisdiction, Foothills Hospital site, 5-person crew, Tuesday."

If you get back a talk with: today's hazard, site-specific context, controls in hierarchy order, 3 discussion questions, and a sign-off line block — the kit is loaded right.
