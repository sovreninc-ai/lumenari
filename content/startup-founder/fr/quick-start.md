# Quick Start — Startup Founder Toolkit

Vous serez opérationnel en moins d'une minute.

## ChatGPT, Claude (web) ou Gemini

1. Ouvrez l'outil
2. Collez le contenu de `optimization-pack.md` dans le system prompt / custom instructions / champ de connaissance du project
3. Commencez à lui demander d'écrire des updates investisseur, pitch decks, JDs ou faire tourner un sanity check de runway

## Claude Code, Cursor ou Codex (chemin SKILL.md)

1. Ouvrez le Terminal (ou votre éditeur de code)
2. Déposez le dossier du kit dans `~/.claude/skills/startup-founder/` (Claude Code) ou collez `SKILL.md` à la racine de votre projet
3. Tapez ce que vous voulez — Claude récupère le skill automatiquement

## Vérifier que ça marche

Collez : « Écris l'update investisseur de ce mois. On est pré-seed, shippé onboarding v1 et le module field-resource, le MRR est passé de 2 840 $ → 5 620 $, le burn est 1 400 $/mois, 18 mois de runway. Je demande une intro à un senior TypeScript engineer. »

Si vous récupérez un update avec une ligne de sujet serrée, 5 sections (shippé/chiffres/30 jours suivants/la demande/un apprentissage), des chiffres spécifiques en gras ou monospace, et la demande tout à la fin — le kit est chargé correctement.
