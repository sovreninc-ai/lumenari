# Início Rápido — Startup Founder Toolkit

Você vai estar rodando em menos de um minuto.

## ChatGPT, Claude (web) ou Gemini

1. Abra a ferramenta
2. Cole o conteúdo de `optimization-pack.md` no campo de system prompt / instruções personalizadas / project knowledge
3. Comece pedindo para escrever investor updates, pitch decks, JDs ou rodar uma sanity check de runway

## Claude Code, Cursor ou Codex (caminho do SKILL.md)

1. Abra o Terminal (ou seu editor de código)
2. Coloque a pasta do kit em `~/.claude/skills/startup-founder/` (Claude Code) ou cole o `SKILL.md` na raiz do seu projeto
3. Digite o que você quer — o Claude pega a skill automaticamente

## Teste se está funcionando

Cole: "Escreva o investor update deste mês. Estamos em pre-seed, entregamos o onboarding v1 e o módulo de field-resource, MRR foi de USD $2.840 → USD $5.620, burn é USD $1.400/mês, 18 meses de runway. Pedindo uma intro para um engenheiro sênior de TypeScript."

Se você receber de volta um update com uma subject line apertada, 5 seções (entregue/números/próximos 30/o pedido/um aprendizado), números específicos em negrito ou monospace, e o pedido bem no final — o kit está carregado certo.
