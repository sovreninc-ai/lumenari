# Quick Start — Startup Founder Toolkit

You'll be running in under a minute.

## ChatGPT, Claude (web), or Gemini

1. Open the tool
2. Paste the contents of `optimization-pack.md` into the system prompt / custom instructions / project knowledge field
3. Start asking it to write investor updates, pitch decks, JDs, or run a runway sanity check

## Claude Code, Cursor, or Codex (SKILL.md path)

1. Open Terminal (or your code editor)
2. Drop the kit folder into `~/.claude/skills/startup-founder/` (Claude Code) or paste `SKILL.md` at your project root
3. Type what you want — Claude picks up the skill automatically

## Test it works

Paste: "Write this month's investor update. We're pre-seed, shipped onboarding v1 and the field-resource module, MRR went $2,840 → $5,620, burn is $1,400/month, 18 months runway. Asking for an intro to a senior TypeScript engineer."

If you get back an update with a tight subject line, 5 sections (shipped/numbers/next 30/the ask/one learning), specific numbers in bold or monospace, and the ask at the very end — the kit is loaded right.
