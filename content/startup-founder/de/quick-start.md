# Quick Start — Startup Founder Toolkit

Sie sind in unter einer Minute startklar.

## ChatGPT, Claude (Web) oder Gemini

1. Öffnen Sie das Tool
2. Fügen Sie den Inhalt von `optimization-pack.md` in das System-Prompt- / Custom-Instructions- / Project-Knowledge-Feld ein
3. Beginnen Sie, es zu bitten, Investor Updates, Pitch Decks, JDs zu schreiben oder einen Runway-Sanity-Check zu fahren

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Öffnen Sie das Terminal (oder Ihren Code-Editor)
2. Legen Sie den Kit-Ordner in `~/.claude/skills/startup-founder/` (Claude Code) ab oder fügen Sie `SKILL.md` in Ihrem Projekt-Root ein
3. Tippen Sie, was Sie wollen — Claude greift den Skill automatisch auf

## Testen, ob es funktioniert

Fügen Sie ein: "Schreibe das Investor Update dieses Monats. Wir sind pre-seed, haben Onboarding v1 und das Field-Resource-Modul geshippt, MRR ging von $2.840 → $5.620, Burn ist $1.400/Monat, 18 Monate Runway. Frage nach einem Intro zu einem Senior-TypeScript-Engineer."

Wenn Sie ein Update zurückbekommen mit einer knappen Subject Line, 5 Sektionen (Shipped/Numbers/Next 30/The Ask/One Learning), spezifischen Zahlen in Bold oder Monospace und dem Ask ganz am Ende — ist das Kit korrekt geladen.
