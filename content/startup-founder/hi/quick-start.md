# Quick Start — Startup Founder Toolkit

आप एक minute से कम में running होंगे।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. Investor updates, pitch decks, JDs लिखने, या एक runway sanity check चलाने को कहें

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/startup-founder/` (Claude Code) में drop करें या `SKILL.md` को अपने project root पर paste करें
3. जो चाहें type करें — Claude automatically skill pick करता है

## Test करें कि काम कर रहा है

Paste करें: "इस month का investor update लिखें। हम pre-seed हैं, onboarding v1 और field-resource module shipped, MRR $2,840 → $5,620 गया, burn $1,400/month, 18 months runway। एक senior TypeScript engineer से intro के लिए ask कर रहा हूँ।"

अगर आपको एक update वापस मिले एक tight subject line, 5 sections (shipped/numbers/next 30/the ask/one learning), bold या monospace में specific numbers, और very end में ask के साथ — kit right loaded है।
