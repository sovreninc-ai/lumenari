# Inicio rápido — Startup Founder Toolkit

Vas a estar corriendo en menos de un minuto.

## ChatGPT, Claude (web) o Gemini

1. Abre la herramienta
2. Pega el contenido de `optimization-pack.md` en el campo de system prompt / custom instructions / project knowledge
3. Empieza pidiéndole que escriba investor updates, pitch decks, JDs o que corra un sanity check de runway

## Claude Code, Cursor o Codex (camino SKILL.md)

1. Abre Terminal (o tu editor de código)
2. Suelta la carpeta del kit en `~/.claude/skills/startup-founder/` (Claude Code) o pega `SKILL.md` en la raíz de tu proyecto
3. Escribe lo que quieras — Claude levanta el skill automáticamente

## Prueba que funciona

Pega: "Escribe el investor update de este mes. Estamos pre-seed, shippeamos onboarding v1 y el módulo de field-resource, MRR pasó $2,840 → $5,620, burn es $1,400/mes, 18 meses de runway. Pidiendo una intro a un senior TypeScript engineer".

Si recibes un update con un subject line apretado, 5 secciones (shippeado/números/próximos 30/la petición/un aprendizaje), números específicos en bold o monospace, y la petición al final — el kit está bien cargado.
