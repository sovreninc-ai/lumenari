# 快速上手 —— 创业者工具包

不到一分钟就能跑起来。

## ChatGPT、Claude(网页版)或 Gemini

1. 打开工具
2. 把 `optimization-pack.md` 的内容粘到系统提示 / 自定义指令 / project knowledge 字段
3. 开始让它写投资人更新、pitch deck、JD,或跑 runway 理智检查

## Claude Code、Cursor 或 Codex(SKILL.md 路径)

1. 打开 Terminal(或你的编辑器)
2. 把工具包文件夹放到 `~/.claude/skills/startup-founder/`(Claude Code),或在你 project 根目录粘 `SKILL.md`
3. 直接说你想要什么 —— Claude 会自动加载这个 skill

## 测试是否生效

粘:"写本月投资人更新。我们 pre-seed,上线了 onboarding v1 和 field-resource 模块,MRR 从 $2,840 → $5,620,月烧 $1,400,18 个月 runway。需要资深 TypeScript 工程师的 intro。"

如果你拿回的更新有简洁主题、5 段(交付/数字/未来 30 天/ask/一个学到的事)、具体数字加粗或等宽显示,且 ask 在最末 —— 工具包加载正确。
