# Início Rápido — Pacote E-commerce / Shopify Owner

Você vai estar rodando em menos de um minuto.

## ChatGPT, Claude (web) ou Gemini

1. Abra a ferramenta
2. Cole o conteúdo de `optimization-pack.md` no campo de system prompt / instruções personalizadas / project knowledge
3. Cole os detalhes do seu produto + contexto de marca e peça uma descrição, conjunto de ads ou sequência de e-mail

## Claude Code, Cursor ou Codex (caminho do SKILL.md)

1. Abra o Terminal (ou seu editor de código)
2. Coloque a pasta do kit em `~/.claude/skills/ecommerce-pro/` (Claude Code) ou cole o `SKILL.md` na raiz do seu projeto (Cursor / Codex)
3. Digite o que você quer — o Claude pega a skill automaticamente

## Teste se está funcionando

Cole isto: "Escreva uma descrição de produto para um hidratante diário de ceramida de USD $32, 50ml, sem fragrância. A voz da marca é direta, sem fluff. Use o ângulo de eficácia."

Se você receber de volta uma descrição na estrutura de 5 partes (hook / benefício / 3-5 bullets / prova social opcional / CTA), com menos de 150 palavras, sem uso de "transforme", "eleve", "luxuoso" ou "descubra" — o kit está carregado certo.

Se você receber um parágrafo abrindo com "Transforme sua rotina de skincare com..." o kit não está carregado — cole o `optimization-pack.md` de novo.
