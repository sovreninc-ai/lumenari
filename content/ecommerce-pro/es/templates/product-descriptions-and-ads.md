# Descripciones de Producto + Ad Copy

Descripciones de producto por categoría, ad copy por plataforma, límites de caracteres impuestos. Diseñado para shippear en una sesión — escribe el PDP, después corre el ad set en la misma hora.

---

## Prompt de descripción de producto

```
Estás escribiendo una descripción de producto para un PDP de Shopify.

Producto:
- Nombre: [nombre]
- Categoría: [apparel / hogar / belleza / comida / suplementos / kids / electrónicos / accesorios]
- Qué es (una frase): [pega]
- Materiales / ingredientes / specs clave: [lista 3-5 cosas que le importan al comprador]
- Tamaño / peso / info de variante: [si es relevante]
- Precio: [$X]

Contexto de marca:
- A quién le vendes: [audiencia en una frase]
- Notas de voz: [3-5 notas de cómo habla la marca — frases cortas, directo, cálido, sin slang, etc.]
- Cualquier cosa off-limits: [claims que no puedes hacer, palabras que tu marca no usa, etc.]

Ángulo: [eficacia / lujo / valor / produce-los-tres]

Largo: [corto 50-80p / estándar 80-150p / largo 150-300p]

Restricciones:
- Incluir: [certificaciones específicas, materiales, cualquier cosa mandatoria]
- Evitar: [palabras prohibidas para tu marca]

Saca la descripción en la estructura estándar:
1. Hook (10-25 palabras)
2. Beneficio clave (1 frase)
3. Features (3-5 bullets)
4. Línea de prueba social (opcional)
5. CTA (1 línea)
```

**Contexto de marca:** Marca de suplemento funcional. Voz directa, sin fluff. Audiencia: adultos 28-50 que leen etiquetas.

**Ángulo de eficacia (y un ejemplo trabajado de disciplina de claims):**
> 400mg de glicinato de magnesio quelado. Sin filler.
>
> Un suplemento diario de magnesio en la forma más gentil con la digestión — glicinato, totalmente quelado para absorción. Dos cápsulas entregan 400mg de magnesio elemental.
>
> - 400mg de magnesio elemental (como glicinato) por porción de 2 cápsulas

## Plantillas de ad copy

Construidas para las plataformas que la mayoría de los dueños de Shopify realmente corren.

### Prompt de ad set de Meta

```
Estás escribiendo un ad set de Meta (Facebook + Instagram) para:

Producto: [nombre + descripción de 1 frase]
Marca: [3-5 notas de voz de marca]
Goal: [tráfico frío / retargeting / launch / promo]
Promo (si la hay): [pega oferta]
Audiencia: [la persona a la que este ad apunta — una frase]

Saca:
- 3 variantes de primary text (125 caracteres óptimo cada uno — declara conteo de caracteres)
- 3 variantes de headline (40 caracteres máximo cada uno — declara conteo)
- 1 variante de description (30 caracteres máximo — declara conteo)

Restricciones:
- Sin palabras prohibidas (transform, elevate, unlock, luxe, etc.)
- Hook en las primeras 7-10 palabras (sobre la línea "See more" en mobile)
- Un próximo paso claro
```

## Cuando la marca necesita un ángulo distinto

Si el primer draft aterriza plano, cambia el ángulo y re-promptea. Un patrón común:

- El ángulo de eficacia se sintió demasiado clínico → prueba lujo
- El ángulo de lujo se sintió sobre-trabajado → prueba valor
- El ángulo de valor se sintió barato → prueba eficacia con framing confiado-pero-específico

El mismo producto puede shippearse bajo tres ángulos distintos y puedes A/B testear cuál convierte mejor en una sola plataforma antes de escalar.

---

## Lo que el buen ad copy no hace

- **Mete el headline con el nombre de la marca.** "El Nuevo Humectante Premium de Marca" desperdicia 30 caracteres.
- **Termina cada línea con un signo de interrogación.** Los ads de TikTok especialmente — las declaraciones directas out-convierten a "¿Cansado de piel seca?".
- **Usa signos de exclamación como sustituto de vibe.** Una exclamación por ad es plenty.
- **Promete outcomes sin sustanciación.** Pégate al lenguaje descriptivo a menos que tengas la citación.
- **Corre el mismo ad copy en las tres plataformas.** Cada plataforma tiene un ritmo distinto — Meta es permisivo, Google es impulsado por keyword, TikTok es voice-y.
