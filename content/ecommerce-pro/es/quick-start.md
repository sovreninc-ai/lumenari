# Inicio rápido — E-commerce / Shopify Owner Pack

Vas a estar corriendo en menos de un minuto.

## ChatGPT, Claude (web) o Gemini

1. Abre la herramienta
2. Pega el contenido de `optimization-pack.md` en el campo de system prompt / custom instructions / project knowledge
3. Pega los detalles de tu producto + contexto de marca y pide una descripción, ad set o secuencia de email

## Claude Code, Cursor o Codex (camino SKILL.md)

1. Abre Terminal (o tu editor de código)
2. Suelta la carpeta del kit en `~/.claude/skills/ecommerce-pro/` (Claude Code) o pega `SKILL.md` en la raíz de tu proyecto (Cursor / Codex)
3. Escribe lo que quieras — Claude levanta el skill automáticamente

## Prueba que funciona

Pega esto: "Escribe una descripción de producto para un humectante diario de ceramidas de $32, 50ml, sin fragancia. La voz de marca es directa, no fluffy. Usa el ángulo de eficacia".

Si recibes una descripción en la estructura de 5 partes (hook / beneficio / 3-5 bullets / prueba social opcional / CTA), de menos de 150 palabras, sin uso de "transform", "elevate", "luxe" o "discover" — el kit está bien cargado.

Si recibes un párrafo abriendo con "Transforma tu rutina de skincare con..." el kit no está cargado — vuelve a pegar `optimization-pack.md`.
