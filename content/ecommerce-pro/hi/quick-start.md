# Quick Start — E-commerce / Shopify Owner Pack

आप एक minute से कम में running होंगे।

## ChatGPT, Claude (web), या Gemini

1. Tool open करें
2. `optimization-pack.md` के contents को system prompt / custom instructions / project knowledge field में paste करें
3. अपने product details + brand context paste करें और एक description, ad set, या email sequence के लिए ask करें

## Claude Code, Cursor, या Codex (SKILL.md path)

1. Terminal (या अपना code editor) open करें
2. Kit folder को `~/.claude/skills/ecommerce-pro/` (Claude Code) में drop करें या `SKILL.md` को अपने project root पर paste करें (Cursor / Codex)
3. जो चाहें type करें — Claude automatically skill pick करता है

## Test करें कि काम कर रहा है

यह paste करें: "एक $32 daily ceramide moisturizer, 50ml, fragrance-free के लिए एक product description लिखें। Brand voice direct है, fluffy नहीं। Efficacy angle use करें।"

अगर आपको 5-part structure (hook / benefit / 3-5 bullets / optional social proof / CTA) में एक description वापस मिले, 150 words के नीचे, "transform," "elevate," "luxe," या "discover" का use नहीं — kit right loaded है।

अगर आपको एक paragraph मिले "Transform your skincare routine with..." से opening, kit loaded नहीं है — `optimization-pack.md` re-paste करें।
