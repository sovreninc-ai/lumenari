# Quick Start — Pack E-commerce / Propriétaire Shopify

Vous serez opérationnel en moins d'une minute.

## ChatGPT, Claude (web) ou Gemini

1. Ouvrez l'outil
2. Collez le contenu de `optimization-pack.md` dans le system prompt / custom instructions / champ de connaissance du project
3. Collez vos détails de produit + contexte de marque et demandez une description, un set d'ad ou une séquence email

## Claude Code, Cursor ou Codex (chemin SKILL.md)

1. Ouvrez le Terminal (ou votre éditeur de code)
2. Déposez le dossier du kit dans `~/.claude/skills/ecommerce-pro/` (Claude Code) ou collez `SKILL.md` à la racine de votre projet (Cursor / Codex)
3. Tapez ce que vous voulez — Claude récupère le skill automatiquement

## Vérifier que ça marche

Collez ceci : « Écris une description de produit pour une crème hydratante quotidienne aux céramides à 32$, 50ml, sans parfum. La voix de marque est directe, pas fluffy. Utilise l'angle efficacité. »

Si vous récupérez une description dans la structure à 5 parties (hook / bénéfice / 3-5 puces / preuve sociale optionnelle / CTA), sous 150 mots, sans usage de « transformer », « élever », « luxe » ou « discover » — le kit est chargé correctement.

Si vous récupérez un paragraphe ouvrant avec « Transformez votre routine de soin de peau avec... » le kit n'est pas chargé — recollez `optimization-pack.md`.
