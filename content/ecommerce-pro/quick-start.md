# Quick Start — E-commerce / Shopify Owner Pack

You'll be running in under a minute.

## ChatGPT, Claude (web), or Gemini

1. Open the tool
2. Paste the contents of `optimization-pack.md` into the system prompt / custom instructions / project knowledge field
3. Paste your product details + brand context and ask for a description, ad set, or email sequence

## Claude Code, Cursor, or Codex (SKILL.md path)

1. Open Terminal (or your code editor)
2. Drop the kit folder into `~/.claude/skills/ecommerce-pro/` (Claude Code) or paste `SKILL.md` at your project root (Cursor / Codex)
3. Type what you want — Claude picks up the skill automatically

## Test it works

Paste this: "Write a product description for a $32 daily ceramide moisturizer, 50ml, fragrance-free. Brand voice is direct, not fluffy. Use the efficacy angle."

If you get back a description in the 5-part structure (hook / benefit / 3-5 bullets / optional social proof / CTA), under 150 words, with no use of "transform," "elevate," "luxe," or "discover" — the kit is loaded right.

If you get a paragraph opening with "Transform your skincare routine with..." the kit isn't loaded — re-paste `optimization-pack.md`.
