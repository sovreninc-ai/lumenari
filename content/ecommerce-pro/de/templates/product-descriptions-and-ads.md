# Produktbeschreibungen + Ad-Copy

Produktbeschreibungen nach Kategorie, Ad-Copy nach Plattform, Zeichenlimits durchgesetzt. Designed, um in einer Session zu shippen — schreiben Sie die PDP, dann fahren Sie das Ad-Set in derselben Stunde.

---

## Produktbeschreibungs-Prompt

```
Sie schreiben eine Produktbeschreibung für eine Shopify-PDP.

Produkt:
- Name: [Name]
- Kategorie: [Apparel / Home / Beauty / Food / Supplements / Kids / Electronics / Accessories]
- Was es ist (ein Satz): [einfügen]
- Key-Materialien / Ingredienzen / Specs: [3-5 Dinge listen, die dem Käufer wichtig sind]
- Größe / Gewicht / Varianten-Info: [falls relevant]
- Preis: [$X]

Brand-Kontext:
- An wen Sie verkaufen: [Audience in einem Satz]
- Voice-Notes: [3-5 Notes, wie die Brand spricht — kurze Sätze, direkt, warm, kein Slang, etc.]
- Alles off-limits: [Claims, die Sie nicht machen können, Wörter, die Ihre Brand nicht verwendet, etc.]

Angle: [Efficacy / Luxury / Value / Produce-all-three]

Länge: [kurz 50-80w / Standard 80-150w / lang 150-300w]

Constraints:
- Einschließen: [spezifische Zertifizierungen, Materialien, alles Verpflichtende]
- Vermeiden: [verbotene Wörter für Ihre Brand]

Geben Sie die Beschreibung in der Standard-Struktur aus:
1. Hook (10-25 Wörter)
2. Key-Benefit (1 Satz)
3. Features (3-5 Bullets)
4. Social-Proof-Zeile (optional)
5. CTA (1 Zeile)
```

## Ad-Copy-Templates

Gebaut für die Plattformen, die die meisten Shopify-Owner tatsächlich fahren.

### Meta-Ad-Set-Prompt

```
Sie schreiben ein Meta-Ad-Set (Facebook + Instagram) für:

Produkt: [Name + 1-Satz-Beschreibung]
Brand: [3-5 Brand-Voice-Notes]
Ziel: [Cold Traffic / Retargeting / Launch / Promo]
Promo (falls vorhanden): [Offer einfügen]
Audience: [die Persona, auf die diese Ad zielt — ein Satz]

Output:
- 3 Primary-Text-Varianten (125 Zeichen optimal je — Zeichen-Count nennen)
- 3 Headline-Varianten (40 Zeichen max je — Zeichen-Count nennen)
- 1 Description-Variante (30 Zeichen max — Zeichen-Count nennen)

Constraints:
- Keine verbotenen Wörter (transform, elevate, unlock, luxe, etc.)
- Hook in den ersten 7-10 Wörtern (über der "See more"-Zeile auf Mobile)
- Ein klarer nächster Schritt
```

## Wenn die Brand einen anderen Angle braucht

Wenn der erste Draft flach landet, wechseln Sie den Angle und prompten erneut. Ein häufiges Pattern:

- Efficacy-Angle fühlte sich zu klinisch an → versuchen Sie Luxury
- Luxury-Angle fühlte sich überwrought an → versuchen Sie Value
- Value-Angle fühlte sich billig an → versuchen Sie Efficacy mit confident-aber-spezifischem Framing

Dasselbe Produkt kann unter drei verschiedenen Angles shippen, und Sie können A/B testen, welcher auf einer einzelnen Plattform am besten konvertiert, bevor Sie skalieren.

---

## Was gute Ad-Copy nicht tut

- **Den Headline mit dem Brand-Namen stopfen.** "Brand Name's New Premium Moisturizer" verschwendet 30 Zeichen.
- **Jede Zeile mit einem Fragezeichen beenden.** TikTok-Ads insbesondere — direkte Statements out-converten "Tired of dry skin?"
- **Ausrufezeichen als Vibe-Ersatz verwenden.** Ein Ausrufezeichen pro Ad ist genug.
- **Outcomes ohne Substantiation versprechen.** Bleiben Sie bei deskriptiver Sprache, es sei denn, Sie haben die Citation.
- **Dieselbe Ad-Copy auf allen drei Plattformen fahren.** Jede Plattform hat einen anderen Rhythmus — Meta ist permissive, Google ist Keyword-getrieben, TikTok ist voice-y.
