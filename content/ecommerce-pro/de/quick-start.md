# Quick Start — E-commerce / Shopify Owner Pack

Sie sind in unter einer Minute startklar.

## ChatGPT, Claude (Web) oder Gemini

1. Öffnen Sie das Tool
2. Fügen Sie den Inhalt von `optimization-pack.md` in das System-Prompt- / Custom-Instructions- / Project-Knowledge-Feld ein
3. Fügen Sie Ihre Produkt-Details + Brand-Kontext ein und fragen Sie nach einer Description, einem Ad-Set oder einer E-Mail-Sequenz

## Claude Code, Cursor oder Codex (SKILL.md-Pfad)

1. Öffnen Sie das Terminal (oder Ihren Code-Editor)
2. Legen Sie den Kit-Ordner in `~/.claude/skills/ecommerce-pro/` (Claude Code) ab oder fügen Sie `SKILL.md` in Ihrem Projekt-Root ein (Cursor / Codex)
3. Tippen Sie, was Sie wollen — Claude greift den Skill automatisch auf

## Testen, ob es funktioniert

Fügen Sie ein: "Schreibe eine Produktbeschreibung für einen $32 Daily Ceramide Moisturizer, 50ml, fragrance-free. Brand-Voice ist direkt, nicht fluffy. Verwende den Efficacy-Angle."

Wenn Sie eine Beschreibung in der 5-teiligen Struktur zurückbekommen (Hook / Benefit / 3-5 Bullets / optionaler Social Proof / CTA), unter 150 Wörter, ohne Verwendung von "transform", "elevate", "luxe" oder "discover" — ist das Kit korrekt geladen.

Wenn Sie einen Absatz bekommen, der mit "Transform your skincare routine with..." öffnet, ist das Kit nicht geladen — fügen Sie `optimization-pack.md` erneut ein.
