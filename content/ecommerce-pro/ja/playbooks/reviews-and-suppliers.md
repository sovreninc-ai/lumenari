# レビュー対応＋サプライヤー／卸売アウトリーチ

Shopify ストアで最も時間を吸い取る管理タスクのうちの2つ：毎週のレビュー対応と、成長を目指す際のサプライヤーまたは卸売メールの作成。このプレイブックは両方のパターンを提供します。

---

## レビュー対応

公開レビューは、書き手よりも将来の購入者によって読まれます。対応は書き手のためではなく、読み手のためのものです。

**3つのトーンが利用可能：**

- **フレンドリー** — 会話的、軽い、ブランドボイス前面。ライフスタイルおよびコンシューマーカテゴリに最適。
- **プロフェッショナル** — 慎重、礼儀正しい、スラングなし。B2B 寄りの DTC、サプリメント、高価格帯商品に最適。
- **ウォーム** — 共感的、具体的、わずかにパーソナル。ビューティ、ウェルネス、食品、関係が商品の一部であるブランドに最適。

ユーザーが指定しない限り、キットはフレンドリーをデフォルトとします。

### プロンプト

```
あなたは商品レビューに対応しています。

レビュー：
- 評価：[1〜5星]
- タイトル（あれば）：[貼り付け]
- 本文：[貼り付け]
- レビュアー名：[ファーストネームのみ]
- 商品：[名前]

ブランドボイス：[3〜5のノート]
トーン：[フレンドリー／プロフェッショナル／ウォーム]

ブランドのボイスで対応を出力（40〜100語）。

ルール：
- レビューに長さと感情的レジスターを合わせる
- 5星レビュー：短く、暖かく、彼らが言ったことに固有
- 4星：暖かい＋5にするのに何が必要だったかについての好奇心のフォローアップ
- 3星：正直さに感謝、1つの明確化質問を尋ねる、助ける提案
- 2星：謝罪、問題に固有、サポートメールへのルーティング
- 1星：謝罪、具体的、サポートメールへのルーティング＋是正の提案
- 公の場で防衛的にならない
- レビュアーと議論しない
- 「気分にさせて申し訳ありません」を決して使わない — それは防衛的
- レビューが欠陥商品、壊れた配送、サービスの失敗を言及している場合、直接対処する
- 否定的レビューの場合：適切なところで責任を取り、解決のためにプライベートチャネルにルーティング
- 可能であれば、実際の名前（創業者、カスタマーサクセスリード）で署名
```

## 良いレビュー対応が行うこと

- **レビュアーが実際に言ったことに対処する。** 一般的な「フィードバックありがとうございます」は缶詰のように読める。対応はレビューの具体的な詳細を引用または参照すべき。
- **否定的レビューで素早く責任を取る。** それを読む将来の購入者は、ブランドが防衛するか所有するかを観察する。所有する方が勝つ。
- **解決をプライベートチャネルにルーティングする。** レビュースレッドで返金を交渉しない。公に承認し、プライベートに解決する。
- **名前で署名する。** 名前は説明責任を示す。「ブランドチーム」は「Sarah、創業者」より信頼性が低く読める。
- **長さをレビューの長さに合わせる。** 2行のレビューは2行の対応を得る。段落のレビューは段落を返す。

## 良いレビュー対応が行わないこと

- **「気分にさせて申し訳ありません。」** 純粋に防衛的言語。やらない。
- **議論する。** レビュアーが商品の事実について間違っている場合、優しく訂正し、プライベートに話す提案をする。公の場で訴訟しない。
- **対応でアップセルする。** 不満に「他の商品を試してください！」は無神経に読める。
- **届けられない結果を約束する。** 「これが二度と起こらないようにします」 — 実際に計画がある場合のみ。
- **20のレビューに同じ行をコピペする。** 将来の購入者はスクロールする。同じさは気にしていないと読める。

## サプライヤーアウトリーチ

潜在的サプライヤーへの初回コンタクト用 — メーカー、原料ハウス、パッケージングベンダー、フルフィルメントパートナー。

### プロンプト

```
あなたは潜在的サプライヤーへの初回コンタクトメールを書いています。

ブランド：[名前＋1文の説明]
商品ライン：[販売しているもの、または作る予定]
現在のステージ：[ローンチ前／ローンチ済み、スケーリング／確立済み、サプライヤー切り替えを検討]
ボリューム見積もり：[予測月次または年次単位；大まかで構わない]
このサプライヤーから必要なもの：[2〜3の具体的なものをリスト — MOQ、リードタイム、サンプル利用可能性、認証]
経路：[トレードショー／Alibaba／紹介／ウェブサイト]

200語未満で初回コンタクトメールを出力。

ルール：
- 件名60文字未満
- 自分が誰か＋何を販売しているか＋なぜ連絡しているかでオープン
- ボリューム見積もりを正直に述べる（誇張しない）
- 2〜3の具体的な質問を尋ねる
- 丁寧、プロフェッショナル、プレッシャーなし
- 明確な次のステップで締めくくる（サンプル要求、MOQ 確認、ディスカッションのコール）
- 名前＋役割＋ブランドで署名
```

### ワークド・エグザンプル — 新しいボトルサプライヤーを調達する小規模スキンケアブランド

```
件名（52文字）：ガラスドロッパーボトルのお問い合わせ — 小規模 DTC ブランド

[名前] 様、

トロントを拠点とする小規模 DTC スキンケアブランド [Brand] の創業者、[Your name] です。月に [数] 単位を出荷しており、30ml アンバーガラスドロッパーボトルの新しいサプライヤーを探しています。

現在のボリューム：
- 四半期あたり約5,000ボトル
- 四半期ごとに約15%の成長
- 今後12か月の供給をロックインしたい

深掘りする前にいくつかの質問：

1. ガラスピペットとゴムバルブ付きの標準30ml アンバードロッパーの MOQ は何ですか？
2. PO からトロントへの配送までの典型的なリードタイムは？
3. サンプルは利用可能ですか、もしそうなら、コストはいくらですか？

それらが必要なものと合えば、仕様を確認するための20分間のコールを設定したいです。

ご検討よろしくお願いいたします。

— [Your name]
創業者、[Brand]
[電話]
```

それがパターン。具体的、ボリュームについて正直、明確な質問、簡単な次のステップ。

## 小売業者への卸売アウトリーチ

商品を扱う可能性のある実店舗小売業者、オンラインキュレーター、ディストリビューターにアプローチする場合。

### プロンプト

```
あなたは潜在的な卸売アカウントへのアウトリーチメールを書いています。

ブランド：[名前＋1文の説明]
商品レンジ：[卸売で提供するもの]
卸売マージン：[標準の卸売条件 — MSRP の50%オフが典型]
最小オープニング注文：[卸売の MOQ]
既存の卸売アカウント（あれば）：[2〜3をリスト — 名前を出すと信頼が構築される]
アプローチされる小売業者：[名前＋彼らがフィットする理由]

200語未満でアウトリーチメールを出力。

ルール：
- 件名60文字未満；可能であれば小売業者に固有
- なぜこの小売業者を特定したかでオープン（1文 — 彼らを見たことを示す）
- ブランドとカテゴリを1行で述べる
- マージン＋最小値を前面に（彼らに尋ねさせない）
- 既存アカウントがあれば1〜2を挙げる
- サンプルまたはラインシートを次のステップとして提供
- 名前＋ブランド＋ラインシートリンクまたは添付で締めくくる
```

### ワークド・エグザンプル — キュレートされたウェルネス小売業者にアプローチするスキンケアブランド

```
件名（59文字）：[Brand] for [Retailer] — 卸売のお問い合わせ

[名前] 様、

[Retailer] が [彼らがすでに在庫している特定のブランド] を扱っており、私たちが作るものとタイトにフィットするキュレートされた品揃えを構築していることに気づきました。

[Your name]、バンクーバー製の小バッチ無香料スキンケア [Brand] の創業者です。私たちのヒーローはセラミドモイスチャライザーで、最もリオーダーされる SKU です（4.8星、1,400+ レビュー）。

卸売条件：
- MSRP の50%オフ
- $500 最小オープニング注文
- 初回注文後 Net 30 条件
- リストックで12週間のリードタイム
- 現在カナダ全土の18小売店で展開、[Account 1] と [Account 2] を含む

ラインを試せるようにサンプルセットを送らせてください。ラインシート添付。

来週いつでも15分間のコールが容易であれば対応可能です。

— [Your name]
創業者、[Brand]
```

## サプライヤーアウトリーチがうまくいかないとき

- **より良い MOQ を交渉するためにボリュームを誇張する。** サプライヤーは検証する。発覚した嘘は、関係が始まる前にそれを沈める。
- **曖昧な要求。** 「あなたのサービスについてもっと教えてください」は彼らの時間を無駄にする。具体的な質問を尋ねる。
- **紹介をスキップする。** サプライヤーはスパムを受け取る。あなたが誰で、なぜ本物の見込み客であるかから始める。
- **明確な次のステップなし。** 常に「[基準] であれば、コールをスケジュールしたい」または「サンプルを送れますか？」で終わる。
- **セールスメールのように扱う。** サプライヤーはパートナーであり、顧客ではない。レジスターは協働的であり、取引的ではない。
