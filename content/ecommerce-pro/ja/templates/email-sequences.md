# メールシーケンス

すべての Shopify ストアが実行する必要のある5つのシーケンス。カート放棄、ウェルカムシリーズ、ブラウズ放棄、購入後、ウィンバック。それぞれ Klaviyo（または Mailchimp）向けにセットアップ — 構造はプラットフォーム非依存。

各メールには以下が含まれます：件名行（50文字未満）、プレビューテキスト（90文字未満）、本文。キットはユーザーのニーズに応じて、1つのプロンプトでフルセットまたは1メールずつ生成します。

---

## カート放棄シーケンス（3メール）

DTC で最高レバレッジのフロー。業界標準の回収率はカート放棄の10〜15%；よく調整されたフローは20%超に達します。

**送信タイミング：** 放棄から1時間後、24時間後、72時間後。

### プロンプト

```
あなたは3メールのカート放棄シーケンスを書いています。

ブランド：[3〜5のボイスノート]
平均 AOV：[$X — メール3にディスカウントを含めるべきかに影響]
商品カテゴリ：[アパレル／ホーム／ビューティ／食品／サプリメントなど]
よくある異議：[顧客がためらう2〜3のものをリスト — 送料、サイジングの不確実性、返品ポリシー、成分の質問]

3メールを出力：
- メール1（放棄から1時間後送信）：フレンドリーなナッジ、ディスカウントなし、残した商品に焦点
- メール2（24時間後送信）：最も可能性の高い異議に対処
- メール3（72時間後送信）：インセンティブ — ディスカウント、送料無料、または AOV に応じた社会的証明

それぞれ：件名行（50文字未満）、プレビューテキスト（90文字未満）、本文（120〜200語）。
禁止語なし。偽の緊急性なし。
```

## ウェルカムシリーズ（30日間に4メール）

初めてメール購読者に送信（ポップアップ、フッターフォーム、または購入後のサインアップ経由）。30日間に4メール。

**送信タイミング：** 即時、3日目、10日目、28日目。

### プロンプト

```
あなたは新規購読者向けの4メールウェルカムシリーズを書いています。

ブランド：[3〜5のボイスノート]
ブランドストーリー（1〜3文）：[貼り付け — このブランドが存在する理由]
商品レンジ：[3〜5のカテゴリまたはヒーロー商品]
サインアップインセンティブ：[約束したもの — 10%オフ、送料無料など]

4メールを出力：
- メール1（即時）：お礼＋初回購入インセンティブコード
- メール2（3日目）：ブランドストーリー — 最大1分の読み物
- メール3（10日目）：ベストセラーまたは何が自分に合うかの選び方
- メール4（28日目）：コミュニティ／レビュー依頼／紹介 CTA

それぞれ：件名行（50文字未満）、プレビューテキスト（90文字未満）、本文（150〜250語）。
禁止語なし。
```

## ブラウズ放棄（2メール）

商品を表示したがカートに追加しなかった購読者に送信。カート放棄より低意図 — トーンはソフト。

**送信タイミング：** 商品表示から4時間後、48時間後。

### コンパクトプロンプト

```
ブランド：[3〜5のボイスノート]
表示された商品：[商品名＋1文の説明]
誰かが追加せずにブラウズする一般的な理由：[貼り付け — 価格、サイジング、成分、時間がなかった]

出力：
- メール1（表示から4時間後）：軽い「リンクをお知らせ」メッセージ
- メール2（表示から48時間後）：1つの有用な情報（レビュー抜粋、よくある異議への1行の回答）

それぞれ：件名50文字未満、プレビュー90文字未満、本文80〜150語。
禁止語なし。このシーケンスにディスカウントなし。
```

## 購入後シーケンス（3メール）

注文完了後に送信。注文確認、配送通知、レビュー依頼。

**送信タイミング：** 即時、配送確認時、配送から10〜14日後（消耗品）または配送から21〜30日後（検討型購入）。

### パターン

最初の2つ（注文確認、配送）はほとんど取引的ですが、キットはデフォルトの Shopify テンプレートよりも暖かくします。3つ目（レビュー依頼）はライティングが重要です。

```
ブランド：[ボイスノート]
配送された商品：[名前]
レビュープラットフォーム：[Judge.me / Yotpo / Loox / ネイティブ Shopify]
インセンティブ（あれば）：[次回購入のディスカウント、抽選への参加、なし]

レビュー依頼メールを出力：
- 件名（50文字未満）
- プレビュー（90文字未満）
- 本文（100〜180語）
- レビューを残すための単一の明確な CTA
- レビューが小さなお願いで、実際の助けであることを認める
- 禁止語なし
- レビューが公開されることや5星であるべきだと約束しない
```

## ウィンバック（2メール）

60〜120日（カテゴリに応じて — 消耗品 = 短い、検討型 = 長い）注文していない顧客に送信。

**送信タイミング：** 休眠60日、休眠90日。

### プロンプト

```
ブランド：[ボイスノート]
このブランドの平均注文頻度：[消耗品で X 週間ごとなど]
最もリオーダーされる商品：[2〜3をリスト]

2メールを出力：
- メール1（60日）：プレッシャーなしのチェックイン、すべてが良いか尋ねる
- メール2（90日）：低摩擦インセンティブ — 15%オフ、送料無料、または再ストックリマインダー

それぞれ：件名50文字未満、プレビュー90文字未満、本文100〜180語。
禁止語なし。顧客が遅れていると暗示しない。自律性を尊重。
```

## 良いメールシーケンスが行わないこと

- **メール1でディスカウント。** 顧客にディスカウントを待つことを訓練すれば、定価で支払わないことを訓練したことになる。
- **カテゴリに関係なく同じ一般的なコピーを送信する。** サプリメントのカート放棄は、キャンドルのカート放棄とは違って聞こえるべき。
- **偽のカウントダウンタイマーを使用する。** 顧客は見抜き、信頼が侵食される。
- **購読解除リンクを埋める。** 見つけやすくする。クリーンな購読解除からのリスト品質の向上は、小さなリストサイズのヒットに見合う価値がある。
- **顧客があなたに何かを借りているかのようにウィンバックメールを送信する。** 自律性を尊重。顧客には戻らない権利がある。
