# 商品説明＋広告コピー

カテゴリ別の商品説明、プラットフォーム別の広告コピー、文字制限を強制。1セッションで出荷するように設計 — PDP を書き、同じ時間内に広告セットを実行。

---

## 商品説明プロンプト

```
あなたは Shopify PDP のための商品説明を書いています。

商品：
- 名前：[名前]
- カテゴリ：[アパレル／ホーム／ビューティ／食品／サプリメント／キッズ／電子機器／アクセサリー]
- 何であるか（1文）：[貼り付け]
- 主要な素材／成分／仕様：[購入者にとって重要な3〜5のものをリスト]
- サイズ／重量／バリアント情報：[関連する場合]
- 価格：[$X]

ブランドコンテキスト：
- 誰に販売するか：[オーディエンスを1文で]
- ボイスノート：[ブランドがどう話すかの3〜5のノート — 短い文、ダイレクト、暖かい、スラングなしなど]
- 制限事項：[できない主張、ブランドが使用しない言葉など]

角度：[効能／ラグジュアリー／バリュー／3つすべて生成]

長さ：[短い 50〜80語 / 標準 80〜150語 / 長い 150〜300語]

制約：
- 含める：[特定の認証、素材、必須のもの]
- 避ける：[ブランドの禁止語]

標準構造で説明を出力：
1. フック（10〜25語）
2. キーベネフィット（1文）
3. 特徴（3〜5箇条書き）
4. 社会的証明行（任意）
5. CTA（1行）
```

## ブランドが異なる角度を必要とするとき

最初のドラフトがフラットに着地した場合、角度を切り替えて再プロンプトしてください。一般的なパターン：

- 効能角度が臨床的すぎる → ラグジュアリーを試す
- ラグジュアリー角度が過剰 → バリューを試す
- バリュー角度が安く感じる → 自信のある具体的なフレーミングで効能を試す

同じ商品は3つの異なる角度で出荷でき、単一プラットフォームでどれが最良にコンバートするかを A/B テストしてからスケールできます。

## 良い広告コピーが行わないこと

- **ヘッドラインにブランド名を詰め込む。** 「ブランド名の新しいプレミアムモイスチャライザー」は30文字を無駄にする。
- **すべての行を疑問符で終わる。** 特に TikTok 広告 — ダイレクトステートメントは「乾燥肌に疲れた？」より優れたコンバート。
- **エクスクラメーションマークをバイブの代わりに使用する。** 広告あたり1つのエクスクラメーションで十分。
- **裏付けなしに結果を約束する。** 引用がない限り、記述的言語に留まる。
- **3つのプラットフォームすべてで同じ広告コピーを実行する。** 各プラットフォームには異なるリズムがある — Meta は寛大、Google はキーワード駆動、TikTok はボイス的。
