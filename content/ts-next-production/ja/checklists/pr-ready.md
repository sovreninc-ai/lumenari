# PR レディチェックリスト

PR を出す前に通してください。ゴールは「シニアエンジニアが一読で +1 できるか?」です。

## コード品質

- [ ] `npm run typecheck` クリーン
- [ ] `npm run lint` クリーン
- [ ] `npm run build` クリーン
- [ ] 残された `console.log` がない（ロガーを使うか削除する）
- [ ] コメントアウトされたコードブロックがない
- [ ] 新規ファイルはすべて、冒頭に目的を説明するドキュメントブロックを持つ

## 型安全性

- [ ] `any` がない（代わりに `unknown` + ナローイングを使う）
- [ ] コメントで正当化されない `as Type` キャストがない
- [ ] コンポーネントの props は明示的な interface を持つ。インラインの `{a, b}: {a: string; b: number}` は使わない
- [ ] async 関数はすべて await するか Promise を return する。コメントなしの fire-and-forget は禁止

## データレイヤー

- [ ] スキーマ変更は `supabase/migrations/` 配下のマイグレーションファイル内にある
- [ ] 新規テーブルは RLS が有効化され、明示的なポリシーがある
- [ ] service-role クライアントはルートハンドラー / サーバーアクション内でのみ import されている
- [ ] 機密カラムを含むテーブルに対して `select *` を使っていない

## セキュリティ

- [ ] ユーザー入力は DB に到達する前に Zod スキーマを通る
- [ ] 金額は整数セントとして保存・計算される
- [ ] クライアントコードや `NEXT_PUBLIC_*` 環境変数にシークレットがない
- [ ] CSRF 面（サーバーアクション、ルートハンドラー）は認証ゲートがある

## UX

- [ ] フォームはアクセシブルなラベル + `aria-invalid` + 可視のエラーを持つ
- [ ] 300ms を超えるあらゆるアクションにローディング状態がある
- [ ] 空になり得るリストには空状態がある
- [ ] 320px ビューポートで動作する（DevTools で確認）
- [ ] モバイルでタッチターゲットが 44pt 以上

## テスト

- [ ] RLS を変更した? クロステナントの境界を証明する統合テストがある
- [ ] 決済や金額のパスを変更した? webhook 冪等性のテストがある
- [ ] 認証を変更した? 未認証リクエストが拒否されるテストがある

## 運用

- [ ] PR タイトルがセマンティックコミット（`feat:`、`fix:`、`refactor:` …）
- [ ] PR の説明に: 何を、なぜ、テスト方法 がある
- [ ] アーキテクチャの選択を変えた場合は DECISIONS.md を更新
- [ ] プロジェクト状態を進めた場合は STATE.md を更新
