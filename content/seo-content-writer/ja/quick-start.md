# クイックスタート — 60 秒セットアップ

3 つの段落、プラットフォームごとに 1 つ。自分のものを選び、貼り付け、テストしてください。

---

## Claude (claude.ai または API 上の Claude)

Claude で新しい Project を作成します。「SEO Content Strategist」と名付け、Project の **Instructions** 欄に `optimization-pack.md` の全内容を貼り付けます。保存。その Project 内のすべてのチャットが、シニア SEO ストラテジストとして動作します — アウトライナー、記事ライター、メタ + スキーマジェネレーター、リフレッシュアドバイザー。単発利用なら、新しいチャットの最初のメッセージに最適化パックを貼り付けてください。ボーナス: 既存の好調記事を Project のナレッジベースに投入すると、AI は内部リンク提案時にあなたの実際の URL 構造とトーンを参照します。

**テスト:** Project 内で新しいチャットを開始し、下のテストプロンプトを貼り付けてください。

---

## ChatGPT (Custom GPT または単発チャット)

Custom GPT 用（Plus または Team）: 「My GPTs」→「Create a GPT」→「Configure」へ。**Instructions** 欄に `custom-gpt-instructions.md` を貼り付けます。「SEO Content Strategist」と命名。説明:「アウトライン、ロングフォーム、メタ、スキーマ、リフレッシュ・プレイブック — フリーランス級ではなくストラテジスト級」。ライブ SERP を読ませたいならウェブブラウジングを有効化（無効なら上位 10 件を手動で貼る）。保存してチャット。単発利用なら、通常のスレッドの最初のメッセージに `optimization-pack.md` を貼り付けてください。

**テスト:** 新しい GPT を開き、下のテストプロンプトを貼り付けてください。

---

## Gemini、Cursor、Codex (またはその他の AI)

**Gemini Advanced** では新しい Gem を作成。Gem の Instructions 欄に最適化パックを貼り、保存し、その Gem を SEO 作業に使います。Gemini のライブウェブアクセスはここで役立つ — 依頼時に現行 SERP を引き出させてください。**Cursor** では、静的サイトコンテンツ（MDX、Hugo 等）でコードエディタ内 SEO 支援が欲しい場合、最適化パックを `.cursorrules` に貼り付けてください。**Codex / GitHub Copilot Chat / その他の AI** では、新しい会話の最初のメッセージに最適化パックを貼り、新しいスレッドの開始時に再度貼り付けてください。

**テスト:** 下のプロンプトでセットアップを確認してください。

---

## 貼り付け可能なテストプロンプト

```
私は SaaS 比較ブログを運営しています。中位 6 桁台 / 月の流入、DA は約 52。

主要キーワード:「best CRM for solopreneurs」
推定ボリューム: 約 1,900/月
SERP 上位 3 件:
1. Zapier のブログ (商業型リスト記事、4,200 ワード、12 ツールをレビュー)
2. HubSpot のブログ (情報型 + ソフト販促、2,800 ワード)
3. ある Substack ライターの個人レビュー (1,400 ワード、90 日かけて 5 ツールをテスト、非常に強い視点)

特に #3 を上回りたい — 個人レビュー視点がギャップです。

ください:
1. インテント分類 + SERP リード
2. H1、H2、内部リンク提案を含む完全アウトライン
3. メタタイトル + メタディスクリプション
4. スキーマ推奨
5. E-E-A-T 視点に関する一段落: 誰がバイラインを担うべきか、どんな経験注入が必要か？

必要ならプレースホルダーを使ってください。
```

返ってくるはずのもの: 商業型と分類されたインテント（#3 の個人レビュー視点が差別化要因だという注記付き）、引き締まったアウトライン（おそらく H2 が 7〜9 個、強調スニペット対応のセクション冒頭）、3〜5 個の名前付き内部リンク提案、仕様内のメタ、推奨される Article + FAQPage スキーマ、そしてこれは **あなたが実際に** CRM を 90 日間テストした場合にのみ機能するという率直な注記 — そうでなければ、テストしたライターを雇うか、証拠を持つライターと組むことを提案します。

インテント分類も SERP リードもない汎用リスト記事のアウトラインが返ってきたら、最適化パックは読み込まれていません。再度貼り付けてください。
