# Lumenari Launch + Sales Prep Kit

Everything Chris needs to fire the moment Lumenari is live at lumenari.io. Sits
next to `DEPLOY-NOW.md` at the project root. Pure content + marketing
artifacts — nothing in `/src`, `/content`, or any code path was touched.

This folder is the playbook. Each subfolder is a self-contained kit with a
README or OVERVIEW that explains how to execute. Read this index first, then
open the folder for the play you're running.

---

## If you only do 5 things

Time-strapped launch week and can't run the full playbook? Run these in order.
Everything else is upside.

1. **Ship the Show HN post** — `hackernews/show-hn-post.md` + `hackernews/timing.md`.
   Tuesday or Wednesday 9-11am PT. One shot. The post + first OP comment are
   already drafted; you just need to publish at the right minute. Highest
   leverage of any single channel for a builder-tools launch.
2. **Email the 5 priority newsletters** — `newsletter-outreach/OVERVIEW.md`
   surfaces the Monday batch (Ben's Bites, Superhuman, The Rundown AI, TLDR
   AI, AI Tidbits). 120-word emails are pre-written. One inclusion in any of
   these compounds for 30+ days.
3. **Submit to TheresAnAIForThat + Futurepedia** — `directory-submissions/`
   has the pre-filled packets. ~20 minutes total. Compounding SEO traffic
   forever.
4. **Send the 3 Tier-1 API outreach emails** — `api-outreach/lovable.md`,
   `api-outreach/v0.md`, `api-outreach/bolt-new.md`. One signed deal pays for
   a year of every other channel here combined.
5. **Run the ProductHunt launch** — `producthunt/launch-day-checklist.md` is
   hour-by-hour. PH alone produces 200-1500 visitors and 1-5 paying customers
   when run well. Stage it 1-2 weeks AFTER Show HN to double-tap the press.

That's the floor. The rest of this kit is the ceiling.

## When to do what — the launch calendar

The 90-day schedule. Run sequentially, not in parallel — channels compound
each other when timed right.

### T-10 to T-1 (pre-launch)

- **T-10:** Read `producthunt/README.md`. Set up your PH account. Identify 1-2
  hunters. Build the 60-100 person supporter list.
- **T-7:** Polish gallery assets per `producthunt/gallery-copy.md` and
  `press-kit/screenshots.md`. Capture all screenshots in the dimensions table.
- **T-5:** Submit to all 10 AI directories per `directory-submissions/`. Some
  take 1-2 weeks to review — start now so listings go live near launch.
- **T-3:** DM PH hunter friends per `producthunt/outreach-message.md`. Final
  asset check.
- **T-1:** Stage launch-day Tweet thread + LinkedIn post + email blast. Set
  alarms for 12:01am PT.

### Launch day (T-0 — pick Tuesday or Wednesday)

Two-stage launch — Hacker News first (one Tuesday/Wednesday), ProductHunt
1-2 weeks later. Don't stack them on the same day; you split your attention
and the press.

**Show HN day** (week 1):
- Follow `hackernews/timing.md` (Tuesday 9:15am PT recommended, Wednesday
  9:30am PT backup)
- Use `hackernews/show-hn-post.md` for body + first OP comment
- Have `hackernews/response-playbook.md` open in another tab — you'll be
  responding to comments for 6+ hours

**ProductHunt day** (week 2-3):
- Follow `producthunt/launch-day-checklist.md` hour-by-hour
- Email the personal network at 9am PT per `producthunt/email-blast.md`
- Tweet thread at 10am per `producthunt/tweet-thread.md`
- LinkedIn post at 11am
- Use `producthunt/comment-templates.md` for every PH comment response

### T+1 to T+30 (sustain)

This is where most launches die — they treat launch as a one-day event
instead of the start of a 30-day momentum window.

- **Daily:** Post the day's tweet + LinkedIn from `social/30-day-calendar.md`.
  ~20 minutes per day, batch on Sunday if needed.
- **Weekly (Mondays):** Send 5 newsletter outreach emails per
  `newsletter-outreach/OVERVIEW.md`. Mon batch = easiest cracks, Wed batch =
  mid-tier, Fri batch = stretch goals.
- **Weekly (Tuesdays):** Send 3-5 API platform cold emails from
  `api-outreach/`. Start with Tier 1 (Lovable, v0, Bolt) week 1, Tier 2 weeks
  2-3, Tier 3 week 4.
- **Bi-weekly:** Recruit 2-3 affiliate partners from `affiliate/partner-targets.md`.
  Use the `affiliate/email-template.md` cold variant.
- **Monthly:** Review `directory-submissions/OVERVIEW.md` quarterly maintenance
  list. Update screenshots, pricing, descriptions.

### T+30 onward

- Run the post-launch results thread per `producthunt/tweet-thread.md`
- Re-load `social/30-day-calendar.md` and adapt for month 2 — replace any kit
  references with kits that sold best in month 1
- Press outreach (week 4-6 — once you have traction numbers to lead with).
  Use `press-kit/boilerplate.md` + `press-kit/founder-bio.md` for inbound.

## Brand voice — read once, internalize forever

Every file in this folder respects Chris's voice. If you're rewriting or
augmenting any of these, hold the line on:

- **Premium but accessible.** Apple-clean even in markdown.
- **Builder-direct.** First-person Chris. Confident, not bragging.
- **Specific over hand-wavy.** Numbers, kit names, real scenarios.
- **No marketing-speak.** No "revolutionary," no "AI-powered," no
  "transform your workflow."
- **Push back on hype.** Push back on bad ideas. Disagree honestly.
- **Brief is better.** If you can cut a word, cut it.

If a file in this folder ever sounds like a SaaS landing page, it's wrong.
It should sound like Chris talking to a smart friend.

## What to update post-launch

The kit is built for launch day. After T+30, it needs maintenance:

- **Traction numbers** — every file with a `[placeholder]` or `[X paying
  customers]` line. Update once a week for the first month, then monthly.
- **Screenshots** — re-capture every 90 days as the site evolves. Especially
  the homepage hero, wizard results, and any pricing-page changes.
- **Newsletter outreach `[verify recent issue]` markers** — a 30-second
  check before sending each email. Don't skip.
- **API outreach prospects** — research hooks go stale in 60-90 days. Refresh
  the "specific recent thing they shipped" line per email before sending.
- **Affiliate partner-targets** — handle changes, audience growth, niche
  pivots. Re-verify quarterly.

## Files that are good but could go deeper

Flagged for Chris's review when there's time:

- **`affiliate/partner-targets.md`** — 20 creators with personalized DM
  openers. Some `[verify handle / research recent post]` markers because the
  agent couldn't independently confirm every recent post. Worth a 5-minute
  pass before sending DMs.

  markers for the personalization line. Don't send without confirming the
  reference is real.
- **`directory-submissions/*.md`** — submission URLs are best-guess
  (`/submit`, `/submit-tool`, `/add-tool`). Confirm each before submitting.
  Some directories may have moved to typeforms or Notion-hosted forms.
- **`api-outreach/*.md`** — recipient emails are placeholders. Use
  Hunter.io / Apollo / their public Twitter to find the founder's actual
  email before sending.
- **`social/30-day-calendar.md`** — case study posts use [hypothetical] tags.
  Once Chris has 5+ real customer stories, swap them in.

Nothing here is half-built. These are just the spots where 5-15 minutes of
human verification turns "good" into "ship-ready."
