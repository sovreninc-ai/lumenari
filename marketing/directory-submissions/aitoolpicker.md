- **AIToolPicker's quiz is keyword-matched.** When filling the description and tags, think about what a user would *type into a quiz* — phrases like "find AI for [role]", "[role] AI tool", "best [outcome] AI."

- **Be specific in the "ideal user" field.** Generic "everyone" pitches get downranked; "sales reps, real estate agents, devs, marketers" performs better.
